# 用户手工测试 — 网购扣款与退款核对专家团 1.0.0

使用 [中文原生 ZIP](test-packages/online-order-payment-review-team-1.0.0-native.zip)。其 SHA-256 为 `d0c5f772c91e44ccb2e895c91c2887a810099b8e87371755d96c36ff48d6fe79`。通过专家团上传入口导入。使用兼容 WorkSwarm、可用的文件和命令工具、Python 3.10 以上及你授权的模型。

1. 在 WorkSwarm 打开 **专家 → 我的专家 → 专家团 → 创建 → 上传文件创建**，选上述 ZIP 并确认中文名称与 1.0.0。通过 `agent_groups.import_local` 本地导入亦受验证。若手工解压或从源目录指定案例，找到直接包含 manifest.json、agents、examples 的实际内层目录。
2. 以专家团模式开始新对话，粘贴下方测试提示。只更换包目录和工作父目录。工作父目录可以新建；每阶段使用此前不存在的子目录。
3. 查看队伍、任务和交接。独立核验员先只收到原始资料和日期，生成基线后才核对匹配结果。三名成员应分别运行真实阶段工具、保留回执并交接。主理人读取核验回执后交付三份文件。

```text
交付中文 review.md、reconciliation.csv、audit.json，说明样例的分拆扣款、部分退款、

```
