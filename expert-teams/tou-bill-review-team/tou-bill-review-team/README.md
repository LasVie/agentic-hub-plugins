# 分时用电账单复核专家团

用于复核单个电表、单个账期的分时电量费。导入后在 WorkSwarm 的「专家管理 → 我的专家 → 专家团」打开本团，确认主理人、电表读数核查员、分时费率计算员及独立费用复核员。运行需要现有的团队任务、受信目录内的本地读写和 Python 3.10 或以上版本。

## 输入与计算

把以下三个 UTF-8 文件放在用户批准的原案目录。当前账期最长 31 天。时段每天相同，使用固定 UTC 偏移和统一货币。所有时段采用左闭右开区间。跨度必须与约定读数边界对齐。

- `readings.csv` 的列依次为 `start,energy,unit`。区间起点用本地 `YYYY-MM-DDTHH:MM`，单位为 `Wh` 或 `kWh`。电量非负，Wh 最多三位小数，kWh 最多六位。每个区间须恰有一行。
- `tariff.json` 字段为 `version`、`utc_offset`（例如 `+08:00`）、`interval_minutes`（30 或 60）、`currency`（如 `CNY`）、`rounding`（`half_up` 或 `half_even`）、`rates`（分段编号到非负单价字符串）和 `windows`（`start`、`end`、`band` 的列表）。时段须覆盖全天；跨午夜拆段，末端用 `24:00`。单价为每 kWh，最多六位小数。
- `bill.json` 字段为 `start`、`end`、`currency`、`lines`。每个分段都要提供 `kwh`、`amount` 的非负数字字符串，零值也明列；金额最多两位小数。

所有读数与账单使用同一固定本地时钟。重构时按分段汇总一整个账期内的 kWh，乘以单价，再舍入至两位。当前不处理按日舍入、工作日或季节变化、夏令时切换、计量表底数、估读、税、固定费、阶梯电价、需量费或反向电量补贴。

## 使用示例

「请用安装的 v1.0.0 核查已授权的本地三文件。仅在我指定的全新目录保存报告。先委派电表核查和原案独立复算，保存回执后才委派候选计算。最后核验档案并给出差额和 HTML 路径。」

合成例：16:30、17:00、17:30、18:00 四个半小时各用电 1 kWh。17:00 至 18:00 每 kWh 为 ¥0.30，其余 ¥0.10。复算为 ¥0.80。若账单汇总为 ¥1.00，差额为 ¥0.20。18:00 应属于非峰段。汇总差额本身不能指出供电方错记的是哪一行。

## 交付

`review.html` 展示分段账单和复算金额；`intervals.csv` 追溯实际读数行；`evaluation.json` 供复查；`artifact.json` 记录包括原件副本与交接在内的逐文件 SHA-256。只在授权的全新目录生成。原件副本仍含输入数据，请留在获授权的环境。
