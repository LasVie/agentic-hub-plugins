# 用户手工测试 — 家校通知变更与待办核验专家团 1.0.0

使用 [中文原生 ZIP](test-packages/school-notice-action-review-team-1.0.0-native.zip)。SHA-256 为 `4f34070f46787c9c57fc421d3ad736d76d9c73c70e023bc3b5ec007c5a1964c0`。

1. 在兼容 WorkSwarm 打开 **专家 → 我的专家 → 专家团 → 创建 → 上传文件创建**，选此原生 ZIP。确认中文版名称和 1.0.0。以专家团模式开启新对话，选择你获授权使用的模型和现有文件、命令工具。需要 Python 3.10 或以上。
2. 找到安装目录或本 ZIP 解压后直接含 manifest.json、agents 与 examples 的目录。指定该目录和一个可写的测试父目录。每阶段应使用此前不存在的新子目录。
3. 复制下方提示。检查真实任务、独立通知核验员的基线回执、只有基线交回后才传递的初稿，以及三份实际交付文件。

```text
请使用家校通知变更与待办核验专家团 1.0.0。
我授权只读随包 examples/weekly-notices.json 这份虚构案例，按文件给定范围执行。
实际包目录为 <实际包目录>；工作父目录为 <可写测试目录>；各阶段使用不同的新子目录。
请主理人实际分派通知与变更分析员和独立通知核验员。两名成员各自阅读原文，
分别写自己的逐通知摘录并运行相应脚本。独立核验员先只收原文并封存基线，
再接收分析员初稿核对遗漏、日期、适用对象和明确的更正或取消。
主理人根据实际核验回执交付中文 checklist.md、changes.csv 和 audit.json。
请说明甲班和乙班的接送时间、取消事项及待确认项，并给出实际输出路径。
```
