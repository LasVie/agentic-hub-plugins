# 多机器人路径规划复核专家团：原生设计

任务 `AH-20261117-robot-route-review-team`；负责人 Cai Zhenze；候选 Not Applicable。
2026-11-17 用户批准的范围：离线、离散网格、2–4 个模拟机器人，不涉及真实设备。

## 模型与职责

- 2–12 列、2–12 行，静态障碍；整数坐标 `[x,y]`，左上为原点。
- 每步移动到上下左右相邻格或等待；禁止同刻同格、反向交换同一边。允许跟随进入刚空出的格以及长度至少为 3 的轮换；不模拟连续几何碰撞。
- 首次到达终点后永久停留；起点、终点分别不得重复。不得自行改图、换目标或放宽规则。
- 有限时域 1–40 步；CBS 高层至多 2,000 次展开，所有低层合计至多 100,000 次展开，墙钟上限 5 秒。用户可进一步降低限额。
- 原生 Python 标准库 CBS：高层按路径总到达步数搜索，低层是带顶点/有向边约束的时空 A*。只有完整搜索结束才报告“给定时域内无解”；触达任一限额则“搜索未完成”。不声称全局无限时域无解、物理安全或经过实验的求解性能。
- 独立回放器不导入规划器或其冲突检测函数；从原始案例重新检查边界、障碍、每步移动、终点停留、顶点冲突和反向换边，独立复算到达时间与费用。

## 真实协作

Leader 冻结用户案例和输出授权；地图约束员输出输入检查；规划员生成候选；复核员先对原始案例保存模型审查，再接收规划结果逐步复算。Leader 检查案例与各文件摘要、保留分歧，最多允许一次有依据的修正。成员通过宿主原生任务与文件交接，不由 Leader 代写成员记录。脚本中角色字段不证明真实参与或盲审。

模型审查确认的是编码规则与输入，不保证用户场景已正确建模。复核员可在结构化 `issues` 中提出真正阻断事项，`notes` 仅记录说明。交付保留阻断项与独立回放结果，不得用文字说明覆盖碰撞、缺失输入或陈旧证据。实际成员行为、语义审查效果仍须用户用授权模型测试。

## 证据与交付

输入 JSON 不允许外部文件引用；输入大小、类型、未知字段与范围严格检查。原文案例字节 SHA-256 是权威绑定；等价但重新排版的输入也须重新运行，避免偷偷替换输入。计划、模型审查与复核包含当前版本及摘要；交付再次独立回放，并检查复核绑定、摘要和结果完全一致。输出只能写入明确指定的新文件/新目录，不覆盖旧结果。

交付为中文离线 HTML 动画、逐时刻 CSV、计划/审查 JSON、中文复核说明和输入快照/文件摘要。未完成或无解时不伪造路径；非法计划保留错误而不显示为通过。HTML 不使用网络、外部脚本、字体、账号或宿主服务。

功能参考 Stern 等人的 MAPF 术语（arXiv:1906.08291v1）及 Sharon 等人的 CBS（DOI 10.1016/j.artint.2014.11.006）。不复制论文、图像、基准数据、上游算法实现或提示词。已见 whoenig/libMultiRobotPlanning 固定提交的 README/许可，仅用于来源/依赖评估；未阅读或翻译其 C++ 算法文件。仓库已有团队的打包和本机宿主测试机制可在本目录内改编，具体记入 SOURCE_REVIEW.md。

## 验收

带会车位的对向通道得到经独立验证的解；去掉会车位后只能给出有限时域结论或未完成。负例含同格、换边、穿墙、跳步、遗漏机器人、终点后离开、篡改费用、陈旧摘要、模型分歧与限额耗尽。小网格与独立联合 BFS 对照最优成本；实际宿主测试只用本机脚本响应证明真实任务/工具/文件通道，不把它当作付费模型语义协作或人工通过。
