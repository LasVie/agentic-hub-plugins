# 多机器人路径规划复核专家团 v1.0.0

这是原生 AgentGroup：规划复核主理人、地图与规则核对员、同步路径规划员、独立路径复核员。不是一个角色清单，也不控制真实机器人。用户提供原始模拟案例和新的输出目录；地图员核对模型、规划员进行有界CBS搜索、复核员先审原始模型再逐步回放，主理人保留证据与分歧后交付。

## 安装与使用

在 WorkSwarm 的「专家管理 → 我的专家 → 专家团 → 创建 → 上传文件创建」上传原生 ZIP。需要支持 AgentGroup 的宿主、已有文件/命令工具、Python 3.10+ 和用户授权的模型。无需ROS、GPU、C++、额外软件包、账号或网络。导入成功不证明团队协作或人工通过。

新建专家团会话，指定本包 `examples/passing-bay.json` 的实际绝对路径和一个不存在的输出目录。可说：

> 只读我给定的合成案例；先核对版本与运动模型，再用真实成员任务分别检查地图、规划路径、先独立审查原始模型再回放候选。最多一次有依据的修正，不改输入或规则，不覆盖旧文件。交付中文离线HTML、逐时刻CSV、JSON、复核说明和证据摘要。展示实际成员、任务与报告路径，等待我核对；不要替我宣布人工通过。

四成员必须实际参与；角色字段、示范报告、固定脚本响应都不是参与证明。独立复核先保留只读原始模型审查，再读取真实候选，不能由主理人代写。宿主不提供盲审隔离保证。

## 输入边界

JSON：`schema_version:1`、`title`、`model:"grid-4-wait-stay-v1"`、`grid:{width,height,obstacles}`、`robots:[{id,start,goal}]`、`horizon`。2–12行列，2–4机器人，整数坐标 `[x,y]`；障碍不得包含起点/终点，起点及终点各自唯一。时域1–40步。每步移动上下左右一格或等待；禁止同刻同格与反向换边；允许跟随和至少三方轮换，首次到达终点后永久停留。

`limits` 可降低 `high_level_nodes`（最多2000）、`low_level_nodes`（所有低层合计最多100000）、`seconds`（墙钟最多5秒）。限额停止是未知，不是无解。完整有限搜索的无解声明不适用于无限时域或其他运动模型，独立回放不核证穷尽或最优性。

## 输出与核对

新的交付目录含 `routes.html`（离线动画、暂停/时间滑块、当前位置与错误）、`timesteps.csv`、`evaluation.json`、`review.md`、`artifact.json` 和 `inputs/` 原始字节快照。双击HTML用桌面浏览器打开，不联网。CSV包括0到horizon每个时刻、每个机器人以及终点停留；无路径时只有表头。

有会车位示例的独立最短路径会在中心格冲突；同步规划需要让行。实际路径由算法生成，不硬编码方向或动作。`no-bay.json` 移除会车位，用来观察有限时域无解/未完成状态，不得伪造路线。

地图、原始模型审查、候选与最终复核均须绑定本次案例字节SHA-256；修改案例或候选后重新运行下游，不能重用旧复核。任何真实 issues、路径违规、模型分歧或陈旧证据都不得宣布通过。notes只提供信息；不替代真实问题。所有输出拒绝覆盖已有文件；保留旧失败证据。

## 限制

小型离散示范，不含尺寸、连续轨迹、安全距离、动力学、定位误差、真实地图/设备控制或现场安全认证。允许跟随的规则可能不适用真实场景。求解器和回放器不替代模型语义审查、成员真实参与或用户验收；团队是否优于相同工具的单专家尚未实验。默认中文，用户明确要求另一语言时可遵循，但不改变规则或权限。

参考与实际复用见 `来源与边界.md`。没有外部图片、字体、数据或付费服务。
