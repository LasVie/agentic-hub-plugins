# 独立验解

运行 `python3 <成员根>/tools/review.py --input <learner.json绝对路径> --output <新的复核目录>`。该脚本从中文文本重建约束并使用独立搜索。读取 review.json，核对解数、来源哈希和逐条线索关系。另行给出“内容复核：通过/阻塞”和证据：未支持关系、标题隐含条件、词表/线索歧义、受众适宜性。不要只回复脚本通过；不得预先接受别人给出的答案作为依据。
