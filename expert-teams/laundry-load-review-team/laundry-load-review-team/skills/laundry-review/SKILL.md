# 一篮衣物分批复核

找到本技能安装的 `scripts/laundry_review.py`。用 Python 3.10 或更高版本。命令用绝对路径。所有输出路径都必须是全新的，且父目录已经存在。

| 步骤 | 实际成员 | 参数（均须加 `--case 案例 --output 新路径`） |
| --- | --- | --- |
| 独立初核 | 复核员 | `baseline` |
| 候选分批 | 规划员 | `plan` |
| 复核候选 | 同一位复核员在第二项任务中执行 | `verify --baseline 初核 --plan 候选` |
| 交付 | 主理人 | `deliver --baseline 初核 --plan 候选 --review 复核` |

独立初核先保存，随后才开始候选。除原案外禁止提前向复核员提供候选信息。保留原案首页、角色回执和所有交接原件。干燥条件不清时，明确写「先确认干燥标签」；只有机洗兼容性不清才将衣物移出所有机洗批次。阻断状态不会输出可用批次。件数分批只依据已声明的上限，实际机器装载仍按说明书核对。
