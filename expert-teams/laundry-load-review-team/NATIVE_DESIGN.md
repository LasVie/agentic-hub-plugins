# 原生设计

- 每次核查一篮衣物。已确认护理信息保存为用户控制的组别，可在下次复用。每篮只填写组别和数量，少量新衣可直接加组。机器程序的温度、动作强度和可选件数限制均来自用户确认的面板或说明书。
- 用冻结 JSON 保留原始标签短语。复核员先保存独立可用程序清单，规划员再编排候选，复核员最后核对分批与候选摘要。程序检查结构化限制；真实成员须将结构化字段对照用户原话。
- 优先使用用户按顺序列明且相容的程序。同程序同颜色组可合并，必须分洗的衣物各自成批，按已明确件数上限拆分。标签不能确定机洗时保留原因。未知干燥动作留待确认。
- 复核核对每组数量、温度、动作强度、颜色、独洗、件数和逐项干燥。主理人只允许一次有证据的修正，输出须写入新目录。冲突仍存在时只输出问题。合格批次清单可直接使用，待确认项写明缺什么。
