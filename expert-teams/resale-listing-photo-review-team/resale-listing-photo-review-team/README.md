# 二手商品上架照片复核专家团

v1.0.0。针对手头已有的二手商品照片，确认主图、证实卖家描述的细节并列出需要补拍或确认的项目。适合每周上架衣物、电子产品、工具等实际商品的卖家。

## 安装与输入

在 WorkSwarm「我的专家 → 专家团 → 创建 → 上传文件创建」导入原生 ZIP。需要已有 Python 3.10+、现有团队任务、文件和终端工具，以及已配置原生图片读取的视觉模型。请只提供你允许模型检查的图片。宿主可能压缩或缩小模型收到的照片。照片细节不清、不可读或视觉能力不可用时，需核实的商品会保持暂缓。

选择一个本机原照片目录和一个新的工作目录。逐款写一行商品标识、相关照片文件名，以及需要核实的可见事实。例如「C01 灰色相机；front.png、side.png、charger.png；灰色机身，右侧有划痕，随附一个充电器」。主理人可以据此整理说明 JSON，或直接使用你准备的说明。

```json
{
  "items": [{
    "id": "C01",
    "title": "灰色相机",
    "photos": ["front.png", "side.png", "charger.png"],
    "checks": ["灰色机身", "右侧划痕可见", "随附充电器同框"]
  }]
}
```

每轮 1–6 款，合计不超过 24 张 JPEG 或 PNG，每张最多 8 MiB。可用子目录相对路径。同一张照片不能归入不同商品。输入可见事实即可，序列号、住址等非必要信息请留在原始业务记录里。

## 怎么使用

1. 主理人预检源文件，分派整理员与独立复核员，各看同一份原图和说明。
2. 整理员逐款定位支持说明的原图，给出主图候选。独立复核员从原图选主图，核对款式归属、缩略可读性、瑕疵与配件。
3. 主理人核对两份真实任务及文件。通过的商品在 `checklist.html` 中列出主图与详情原文件名顺序。暂缓的商品收到具体补拍或待确认事项。可在 `report.json` 查看逐项结果。

效果以照片中可见内容为限。原照、商品说明及实际发布由用户管理。
