# 例会证据契约

随包 README 与 examples/clock-change.json 定义结构。案例只包含显式的参会时区、每周窗口与日期例外。所有时间以整分钟表达，会议长度按 UTC 实际经过的分钟计算，每个经过分钟均须落在当地允许窗口。能在窗口终点恰好结束；不能在当日终点开始。跨午夜可用窗口拆成两天。日期例外覆盖当地整日的周模板。

路径使用绝对路径。本次每个阶段使用新的回执、基线、规划、比对及交付路径。原始案例与上游交接不覆盖。核验员在收到规划文件前做独立基线。源码、原始 JSON 字节、时区文件摘要与实际交接记录共同说明范围；同一时区数据库的复算一致不能证明数据库无误。
