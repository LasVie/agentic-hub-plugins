# 问卷跳题逻辑核验专家团

审查已声明的单选问卷跳题：找出无法从起始题到达的题、指向未定义题的可达选项、以及可以通过一串答案回到同一题的可达循环。报告附可回放的选项序列。它不检查题目措辞、真实回答、分数或线上表单的实际设置，不连接问卷平台，也不修改源文件。

## 安装与使用

在 WorkSwarm 的“专家 → 我的专家 → 专家团队 → 新建 → 从文件创建”中导入原生 ZIP，不要选择带 `plugin.yaml` 的 Hub 外层包。宿主需要文件、命令及团队任务能力，且可运行 Python 3.10 或以上版本。原生包内的 `examples/演示问卷.json` 是虚构示例。运行时使用新建空目录保留交接产物。

可对团队说：“使用包内的演示问卷，结果写到我提供的空目录。请先让核验员给出独立基线，再让分析员列出问题，随后核验员回放，最后以中文交付报告。”使用自有问卷时，提供授权 JSON 文件和输出目录的绝对路径。

负责人先只读校验输入和空输出目录。校验失败时显示中文错误，不创建团队任务、不写文件。通过后逐步调度：核验员先独立计算，分析员从起始题正向搜索，核验员再核对证据。负责人只在三份回执齐备并相符后签发 `报告.md`。一致不等于无缺陷。

## 输入格式

UTF-8 JSON，不得有重复键。`start` 是已定义的首题编号；`questions` 对象的键为题号，值为“选项编号 → 目标题号”。`END` 专用于正常结束。题号用拉丁字母开头，可含拉丁字母、数字、下划线、连字符，最多 32 字符；选项可用中文、字母、数字、下划线或连字符，最多 32 字符。

```json
{"start":"Q1","questions":{"Q1":{"继续":"Q2","退出":"END"},"Q2":{"完成":"END"}}}
```

最多 120 题、每题 12 个单选选项，文件最多 128 KiB。不支持多选、自由文本、按早前答案计算的条件或动态脚本。可达题指向不存在的题会记为断链；不可达题只列清单，其内部跳转不被误报为可达缺陷。

## 产物

`baseline.json`、`analysis.json` 和 `verification.json` 是交接数据；`报告.md` 是中文核验报告。文件不会被覆盖。验证不同输入时使用新的空目录。
