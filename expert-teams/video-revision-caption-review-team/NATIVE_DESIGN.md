# Native design

Recurring review at each revised video export. Use the approved SRT, revised SRT, and optional edit notes in the original timeline. An edit replaces one known original interval with a supplied duration, so retained intervals have an arithmetic translation. An addition has zero old length. Empty edit notes supplied explicitly attest there are no timing changes. Missing edit notes allow comparison without suggesting timing changes.

The leader establishes file identity and edit scope. The verifier first freezes a baseline from approved captions and edit notes, before receiving the analyst's proposal. The analyst classifies cues by walking edits and applying accumulated offsets. The verifier independently constructs retained intervals and checks candidate placements against that baseline. Both use the same normalized input and deterministic one-to-one cue correspondence rules. Each revised and approved cue is accounted for. Use exact text/timing first, and only suggest an automatic timing edit when verbatim text is unique on both sides. Unpaired cues, altered speech, cut-crossing cues and ambiguous repeats go to targeted playback review. No word-level timestamps are inferred.

The leader hands over a Chinese review and cue table, including target times where known, plus a clean SRT only after the whole revised track is verifiable. Rounded or guessed times are avoided by integer milliseconds. Source and staged receipts are hashed. Each stage writes to a distinct new local directory. No media installation or provider connection is required beyond the existing WorkSwarm task, file, messaging and command tools.
