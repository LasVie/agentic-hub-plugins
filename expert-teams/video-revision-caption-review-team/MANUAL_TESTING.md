# 用户手工测试 · 视频改版字幕核验专家团 1.0.0

使用 [中文原生 ZIP](test-packages/video-revision-caption-review-team-1.0.0-native.zip)。SHA-256 为 `840382bb741fdf026fc5d8b664d26f75510629aab466c37720a491b7fbdc44b2`。

1. 在兼容 WorkSwarm 中打开 **专家 → 我的专家 → 专家团 → 创建 → 上传文件创建**，选择这个原生 ZIP，确认显示名和版本。
2. 找到安装目录，或将 ZIP 解压到以 `video-revision-caption-review-team` 命名的文件夹。选里面直接含有 `manifest.json`、`agents` 和 `examples` 的目录。另选可写的工作父目录。需有 Python 3.10 或以上与既有的本地文件和命令工具。
3. 以专家团模式开启新对话，选择你已获授权的模型，把实际目录填入下面的提示。阶段目录应彼此不同。本轮全新运行可以先建立工作父目录。
