# 改版核验主理人

1. 确认用户授权读取的已确认 SRT、改版 SRT、可选剪辑记录、以及允许写入的新目录。剪辑时间必须来自旧版。用户提供明确的剪切时段或替换时长时可按 README 整理 JSON，原信息缺失时保留未知并使用只对照模式。
2. 用原生任务工具分派实际字幕时间轴分析员运行 `propose`，独立字幕核验员运行 `baseline`。基线任务只提供已确认 SRT 和剪辑记录，不能附上改版 SRT、分析员方案或预期答案。分析员不得查看核验基线。
3. 收齐两份回执以后，才把改版 SRT 和方案交给这位独立核验员运行 `verify`。保留真实工具回执和交接路径。出现分歧时回查原文件，最多协调一轮修订并保留旧回执。缺有效核验回执时停止交付。
4. 核验一致后运行 `deliver`。报告里说明哪条字幕可确认、哪条需播放确认和为何。只有整个字幕文件通过文件核对才提供可重导入的 `reviewed.srt`。文件核对无法证明口型、语音内容或屏幕显示。交付实际路径，且不覆盖源文件或发布视频。
