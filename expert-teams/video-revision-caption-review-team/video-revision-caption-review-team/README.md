# 视频改版字幕核验专家团

每次剪完新版后，用已有的两份 SRT 检查哪些字幕应继续保留，哪些要调整时间，以及哪些需要播放成片确认。适合定期发布短视频、产品演示和教学录屏的编辑人员。

## 输入

- 已确认字幕 `approved.srt` 与当前改版字幕 `revised.srt`。支持 UTF-8 的 SRT，保留原文换行和字幕编号。
- 可选剪辑记录 `edits.json`。每段使用旧版时间的 `start` 和 `end`，并填写替换后时长 `new_duration_ms`。删掉三秒片头可写为 `{"start":"00:00:00,000","end":"00:00:03,000","new_duration_ms":0}`。插入时起止相同，并填写插入时长。同样长的改录也要登记。
- 可在记录中提供 `approved_duration` 和 `revised_duration`，两者使用 SRT 时间格式。只提供旧版时长时，脚本根据剪辑记录计算改版时长。明确没有时间轴改动时填写 `{"edits":[]}`。缺少剪辑记录时可直接对照两份字幕，时间差异留待确认。

剪辑记录可以由主理人按用户提供的准确旧时间和时长整理。每段以旧版为基准，覆盖删除、插入、替换。重排、变速、跨段文字断句和实际发音请在编辑器里确认。本组只检查本地字幕和提供的剪辑范围。

## 运行

在兼容 WorkSwarm 中创建专家团并上传原生 ZIP，选择你获授权使用的模型。需有本地文件和命令工具及 Python 3.10 或更高版本。发给主理人两份 SRT 的实际路径、剪辑记录（如有）和可写的输出父目录。

主理人分派时间轴分析员与独立核验员。核验员在接收改版字幕和分析方案前，只凭已确认字幕与剪辑记录封存基线。分析员根据剪辑记录对照两版。核验员取得方案后复核剪辑边界、遗漏与改版时间，主理人根据回执交付。阶段命令见 [共享证据技能](skills/caption-evidence/SKILL.md)。

## 拿到结果后

- `review.md` 提供需要查看的字幕编号与时间。
- `cue-review.csv` 逐条保留旧新版编号、时间和文字。文字完全相同且两版各只有一条时，才建议修正时间。未确定的新增、跨剪辑点或缺失字幕请到成片相应位置检查。
- `audit.json` 记录输入、方案、独立核验与交付文件摘要。
- 全部字幕通过文件核对时，另附 `reviewed.srt`，可直接导回编辑器复看。播放后再确认原声、画面和字幕同步。

可先运行 [虚构改版案例](examples/edits.json)。对照 `approved.srt` 与 `revised.srt` 可看到删片头、剪掉中间停顿与替换配音。如果只想演练导出完整 SRT，用同一份 `approved.srt` 搭配 `intro-only.srt` 和 `intro-only-edits.json`。每次使用一个新的阶段输出目录。
