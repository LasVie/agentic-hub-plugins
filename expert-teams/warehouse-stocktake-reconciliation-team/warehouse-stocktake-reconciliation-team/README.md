# 库存盘点差异复核专家团

用于把单次盘点的账面快照推算至各盘点记录实际发生的时刻，并区别流水能解释的差异和仍需复盘的差异。全程离线，只读取指定 CSV，不接入或修改库存系统。需要支持专家团的 WorkSwarm 及其任务、文件和命令工具，命令环境需要 Python 3.10 或以上版本。

## 输入

在一个目录中放入三份 UTF-8 CSV。文件名和表头固定：

- `book.csv`、`count.csv`：`sku,location,unit,at,quantity`。
- `moves.csv`：`id,sku,location,unit,at,delta`。收入用正整数、支出用负整数，流水编号唯一。

每份库存表对每个商品和库位只填一行，商品库位集合和单位须匹配；流水仅含这些商品库位。数量为整数，不换算单位。时点精确到秒，例如 `2026-11-20T10:00:00+08:00`；也支持 `Z`。账面和盘点都应包含恰在自身时点的流水。计算纳入账面时点之后、盘点时点及之前的流水。需要使用者明确确认该口径和流水已完整；没有证据不能把缺失数据视作零。每份文件最大 4 MiB。

## 在 WorkSwarm 使用

在「专家 → 我的专家 → 专家团」中导入原生 ZIP，选择有权使用的模型。向团队提供已授权的输入目录、一个全新的输出目录、时点口径与流水覆盖确认。样例在 `examples/`，请明确授权把虚构样例作为测试输入。

输入检查员验证材料；库存倒推核验员先仅从原始文件反算；库存正推员独立计算盘点时点账面量；负责人完成交接核查。最终输出中文 `review.md`、逐行 `exceptions.csv`、含原始指纹和流水的 `audit.json`。复盘提示不是调账建议；不支持批次、金额、实时扫描或数据写回。请用遵循 CSV 导入规范的工具读取商品编号，避免表格软件自行丢弃前导零。
