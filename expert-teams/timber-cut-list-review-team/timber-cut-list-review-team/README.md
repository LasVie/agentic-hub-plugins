# 木料定尺下料复核专家团 · 1.0.0

在用户给出的实际库存中分配已定尺寸的零件。主理人协调库存员、规划员与独立复核员。交付可折叠的中文离线排样图、CSV、JSON、复核说明、输入快照及摘要清单。

## 安装和运行

WorkSwarm「专家管理 → 我的专家 → 专家团 → 创建 → 上传文件创建」。选择原生 ZIP。启动团队会话，给出已授权的案例文件和尚不存在的工作目录，声明所有字段和占量已核对。使用本机 Python 3.10+ 和已授权的模型。默认中文。脚本、排样页面和导出均在本机运行。

## 案例格式

UTF-8 JSON。根字段为 schema_version（1）、title、kerf_mm、stock、parts。stock 每项含 id、material、length_mm、trim_start_mm、trim_end_mm。parts 每项含 id、material、length_mm、quantity。编号以英文字母开头；两组分别唯一。material 必须包含准确的材质与规格，完全一致才可分配。最多 12 块库存与 24 件零件，长度统一为整数毫米。

每个零件均占用其成品长度加一次明确给定的锯缝；两侧修边从库存长度中扣除。验算示例：2400 mm 原长扣除 5+5 mm 修边，剩 2390 mm；1200 mm 和 1185 mm 两件各加 3 mm，需 2391 mm，超出 1 mm。

结果是给定约束下的一份可行分配。规划有界搜索，找到候选后交给复核员；大规模无解主张可能无法独立确认。现场尺寸误差、缺陷、二维排版、切削顺序与设备安全超出模型。只有通过复核的档案提供下料 CSV 的有效行。
