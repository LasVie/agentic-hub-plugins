# 截图外发脱敏复核专家团

v1.0.0。给一批外发截图建议脱敏区域、保留必要上下文，生成扁平化 PNG 副本并逐像素复核。适用于工单、缺陷单和产品操作说明。

## 安装和使用

在 WorkSwarm 打开「我的专家 → 专家团 → 创建 → 上传文件创建」，上传原生 ZIP。需要 macOS、已经安装的 Swift 命令行工具、本地浏览器和现有文件、终端、团队任务工具。包内实现只使用 Apple 系统框架。

将 1 至 12 张静态 PNG 放在授权的本机目录，每张最多 1,600 万像素、每边最多 6,000 像素、文件最多 32 MiB。给团队目录路径、要查找的类别和可写的本轮新目录。不贴原图、实际编号或邮件地址。首轮可选识别邮箱、疑似电话、网址和常见账号前缀；用 `manual` 可直接手绘框。

主理人派脱敏员扫描后，在本地打开安装包 `skills/screenshot-review/confirm.html`。选扫描 JSON 与原 PNG。黄色框为识别建议，可以确认忽略误报，用鼠标拖动补画遮盖框或标出保留区域。每张图检查后勾选确认，其他图默认暂缓。保存确认 JSON，将其绝对路径交给主理人。团队生成新副本并由另一位成员核对，最后交付 `checklist.html`、`manifest.json` 和 `share/`。

例如准备客服截图时，选择邮箱类别，遮盖建议的客户邮箱并补画头像框。把需要展示的报错区域设为保留。团队核对批准区域被不透明像素覆盖，框外像素保持一致，输出 PNG 不带源元数据。无法确认的截图暂缓。

本机识别可能漏掉文字、头像、二维码或局部弹窗，请逐图检查。工具核验范围是已确认区域与文件结构，实际发送由使用者决定。
