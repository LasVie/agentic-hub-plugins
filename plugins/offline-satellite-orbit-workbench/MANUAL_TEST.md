## 浏览器操作与预期对照

| 测试 | 操作 | 预期，仅用于对照 |
| --- | --- | --- |
| 真实计算 | 载入历史 TLE 示例，保留历元附近的 UTC 和默认设置并运行 | 显示插件 1.0.0、引擎 7.2.0、星下点轨迹、仰角曲线、样点表和几何区间/无区间结果；无外部底图请求 |
| 样点检查 | 选择另一时刻的样点 | 页面日期、方位角/仰角/距离随样点变化；导出的 JSON / CSV 中可核对同一 UTC 的 TEME 位置/速度及单位 |
| 地点改变 | 改变观察地点，暂不运行 | 旧结果和三个导出立即失效；运行后站心仰角/距离改变，卫星本身的同一时刻 TEME 轨道不因观察地点改变 |
| 根数/时段改变 | 修改文本、UTC、采样或最低仰角，暂不运行 | 旧结果不可下载；不得迟到显示旧线程的结果；重新运行后内容对应新输入 |
| 格式错误 | 改坏 TLE 校验和、输入重复键 OMM、非法 UTC 或超过历元七天 | 实际显示中文错误及错误代码；旧结果不可导出；恢复有效输入后可重新运行 |
| 区间边界 | 改变最低仰角和窗口 | 几何区间随之变化；窗口边缘有截断说明；不把采样峰值称为精确过顶，也不承诺发现所有擦边区间 |
| 三种下载 | 下载 JSON、CSV、SVG 并打开 | JSON 保留版本、根数输入、地点与全部实际数值；CSV 保留全部样点、TEME 数值和中文单位；SVG 包含当前轨迹/曲线、版本、时间与观测点。分别核对相应字段，不能要求每种格式包含全部 JSON 元数据 |
| 取消/恢复 | 运行后立即取消或编辑，再重新运行 | 不导出已取消或已过期结果；后续合法计算仍能成功。小案例可能在点击前已完成，须如实记录 |

参考核验：CelesTrak AIAA 2006-6753 的卫星 `00005` 在根数历元的 TEME 位置约为 `[7022.46529266, -1400.08296755, 0.03995155]` km，速度约为 `[1.893841015, 6.405893759, 4.534807250]` km/s。开始时间精度、四舍五入与采样时刻须一致；不要把不同 UTC 的值直接比较。自动参考测试的 1 米/1 毫米每秒容差是指定模型实现对照，不是现实轨道精度承诺。
