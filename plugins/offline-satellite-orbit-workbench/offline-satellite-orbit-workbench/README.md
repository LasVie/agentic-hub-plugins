# 离线卫星轨道工作台 1.0.0

输入一颗卫星的 TLE 或 OMM 轨道根数、UTC 时段和观察地点，使用本地 Satellite.js 7.2.0 的 SGP4/SDP4 引擎计算轨道。页面提供星下点轨迹、仰角曲线、方位角与距离、受限几何仰角区间，以及 JSON、CSV、SVG 下载。

## 安装和打开

1. 在同一台电脑的 WorkSwarm「扩展」中上传原生安装 ZIP，安装并在会话中启用本插件。不要把用于市场交付的外层包装 ZIP 当作原生安装 ZIP。
2. 为**当前安装、本次测试**新建一个空目录，例如 `~/Downloads/satellite-orbit-test-1.0.0-user`。工具参数须使用该目录的完整绝对路径。不要复用开发自测、其他安装或其他插件的工作目录。
3. 让 WorkSwarm 实际调用 `satellite_orbit_workbench`，先传 `action="status"` 和 `workspace`。明确授权后，再传相同的 `workspace`、`action="start"`、`confirmed=true`。
4. 在同一台电脑的普通浏览器打开**工具实际返回**的完整 URL。地址使用自动分配的本机端口；不猜端口、不拼接链接、不使用历史地址。再次启动会安全复用当前安装已验证的服务。空闲 30 分钟后服务自动退出；再次调用工具获取真实地址。

启动只提供本插件自带的静态文件。轨道计算由浏览器工作线程完成，不上传轨道或观察地点，不连接轨道目录、地图服务或收费接口。运行需要支持 ES 模块和工作线程的现代浏览器，以及支持该原生插件接口的 WorkSwarm/Python 环境。启动工具面向 macOS/Linux；Windows 启动未获支持。

若返回 `invalid_runtime`，保留原始结果、记录和服务并停止对此目录重试。该目录可能含其他安装的记录，或记录已损坏。不要删除、覆盖、修改 `root` 或终止未知服务。确认归属后另建当前安装专用目录，再使用正常工具启动。

## 使用

- 载入公开历史示例，或导入/粘贴自己有权使用的一份 TLE/OMM 文本。历史示例只能用于所列历元附近的演示，不代表卫星当前状态。
- 设置以 `Z` 结尾的 UTC 开始时间、时长、采样间隔、观察地点的纬度、经度、WGS84 参考椭球高和最低仰角。椭球高使用米，不是海平面高程；经纬度使用度；不是自动定位。
- 点击「计算」一类的运行按钮。必须成功生成当前输入的结果后才能导出。任何输入或设置改变后，旧图表、旧结果与导出立即失效；重新计算后才能下载。
- 检查星下点与仰角曲线、卫星 TEME 位置/速度、观察者方位角/仰角/距离、几何区间和警告。图形不包含外部底图；跨越经度边界的轨迹分段显示。
- 下载 JSON 查看版本、根数、观察地点、单位、完整采样数值和警告；CSV 用于表格核对；SVG 保存当前图形。下载只写入浏览器选择的本机位置。

## 输入与结果边界

只处理一颗卫星；时长 0.25–24 小时，采样间隔 10–600 秒，整个时段距根数历元不超过 7 天。根数并不因在此范围内而保证新鲜或准确。TLE 须满足受支持的固定列、校验和及匹配编号；OMM 须使用受支持的单对象字段。无效格式、重复 JSON 键、未知或不支持的内容、非有限数字和超限输入会被拒绝。

SGP4 原始位置是 **TEME，千米**，原始速度是 **TEME，千米/秒**；界面另外给出几何经纬度、高度和站心观察量。采样不能保证发现夹在两个样点间的极短或擦边区间；已发现的阈值穿越会细化，窗口边缘会标明截断。区间内最高仰角是采样估计，不宣称精确过顶时刻。

高于某个仰角不等于肉眼可见。没有计算阳光照射、地影、天气、地形、光污染、天线方向图或接收质量。没有联网更新根数、航天器控制、碰撞分析、导航、发射规划或工程安全认证。数值参考测试只说明指定案例与参考实现一致，不说明真实卫星的位置误差。
