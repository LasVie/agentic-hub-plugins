# 本地音乐库 1.0.0

把用户明确选定的已有音频目录变为中文本地曲库：搜索文件名、保存独立歌单、播放/暂停、上一首/下一首、跳转和续播。只读取音频，不编辑、移动或删除源文件。没有在线音乐、歌词、账号、TTS、新闻、转码或模型调用。

## 环境与安装

需要macOS或Linux、Python3.11+、兼容openJiuwen原生Plugin的WorkSwarm及桌面浏览器。核心仅Python标准库，无额外npm/pip包，无FFmpeg、CDN或模型下载。插件不更改宿主模型设置；在聊天中使用宿主模型仍由用户自行配置。

在WorkSwarm「扩展 → 我的扩展 → 创建 → 从文件创建」选择同版本 `local-music-library-1.0.0-workswarm.zip`，安装并启用。本仓规范市场ZIP有双层目录；此旧宿主使用根manifest原生测试ZIP，两者内层字节相同。

## 启动、查询与关闭

准备已有真实绝对路径：音频目录 `library_dir`，以及**位于音频目录之外**的独立状态工作目录 `workspace`。路径不能经过符号链接，也不能是磁盘根目录。不要选择整个主目录。首次启动需用户明确授权：

```json
{"action":"start","library_dir":"/你的音频目录","workspace":"/你的独立工作目录","confirmed":true}
```

请助手实际调用 `local_music_library`，展示返回的 `ok`、`version`、`scan.count`、扫描边界及完整 `url`。在桌面Chrome打开实际URL，点击曲目播放；不要使用WorkSwarm内嵌预览。播放器不自动打开浏览器。链接含会话凭据，仅给当前用户，不要放到公开截图、日志、PR或共享文档。

同样的路径配 `action=status` 查询；配 `action=stop, confirmed=true` 关闭该库服务。重复启动复用本库已核验会话，不终止其他进程。30分钟无请求自动关闭；关闭网页本身不关闭服务。服务关闭后重新start可恢复同一工作目录内歌单与进度，需手动点击继续。

无需模型也能测试，在内层目录运行：

```sh
python3 -B runtime/control.py --help
python3 -B runtime/control.py '{"action":"start","library_dir":"/你的音频目录","workspace":"/你的独立工作目录","confirmed":true}'
```

## 播放器操作

- 搜索按文件名筛选。勾选曲目，填写歌单名，点击「保存所选曲目」。最多16个歌单，每个最多500首；同名替换会先确认。删除仅删除歌单记录。
- 打开歌单后选择其中曲目播放；可切换顺序、单曲循环、随机。下一首按当前队列切换；搜索仅筛选界面。
- 原生音频控件可拖动进度条、调音量。点击「保存进度」并看到成功提示后再关闭。暂停、切歌或离开页面也会尽力保存，但不能保证页面被强制终止时保存成功。
- 重新扫描会暂停当前曲目并更新列表，保留歌单记录；已删除曲目显示缺失，不自动清理记录。

## 边界与隐私

最多500首、5000个枚举条目、4层子目录，每个文件必须大于0且不超过512MiB。忽略隐藏文件；拒绝符号链接、硬链接、库外路径、非普通文件。达到上限会明确标记列表可能不完整。扫描以有限子集排序，不保证越过上限的文件必被看到。

扩展名支持WAV、MP3、M4A/M4B、AAC、FLAC、OGG/OGA/Opus、WebM。能否实际播放取决于内容与浏览器编解码器；不支持时显示失败，不转码。格式/MIME标签只来自扩展名，不是音质或解码验证。浏览器通常要求手动点击后才允许发声，必须区分「工具启动成功」「HTTP读取成功」和「实际播放成功」。

状态保存在 `workspace/.local-music-library/<曲库路径摘要>/`：歌单及进度、私有会话地址、锁和每次启动日志；权限仅当前操作系统用户。歌单含相对文件名的摘要，工作目录仍可能暴露使用习惯。状态不是加密库或操作系统沙箱，不能抵御同一用户的恶意程序；自行备份、保管和清理。损坏状态不自动重置；服务不使用保存的PID去杀进程。私有状态目录不能放到音频库里。

只监听127.0.0.1动态端口，校验随机会话路径、Host与Origin，跨站请求被拒绝；不对外共享、不绕过浏览器限制。服务可同时处理8个请求，每次流式读取最多64KiB。不要把播放内容或文件名发送给外部模型；插件自身没有外网代码路径。

实际授权音频由用户提供。来源映射、完整MIT许可与修改说明见 `THIRD_PARTY_NOTICES.md` 和 `licenses/dsh-music-player/LICENSE`。测试结果由外层TEST_REPORT单独记录，用户手动测试尚需确认。
