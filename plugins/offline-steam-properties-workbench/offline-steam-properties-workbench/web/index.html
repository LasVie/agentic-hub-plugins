单位、计算范围与数据说明

工质固定为纯水，后端固定为 HEOS。界面使用 kPa、°C 和 kJ/kg；项目与 CSV 使用 Pa、K、J/kg 等 SI 单位。温度换算：K = °C + 273.15；绝对压力换算：Pa = kPa × 1000。

饱和曲线只计算有界液汽平衡区间；单相状态的干度显示为“不适用”。不接受上传脚本、HTML、样式或外部资源。修改输入后旧结果立即失效，必须重新计算才能导出结果。

仅在本机运行，不调用模型或付费接口。项目不会在输入时自动保存。请在关闭前保存需要保留的输入。
