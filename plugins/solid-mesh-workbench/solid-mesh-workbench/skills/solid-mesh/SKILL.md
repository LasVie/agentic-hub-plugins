# 立体网格布尔工坊

默认用简体中文说明步骤、结果和错误。用户明确要求其他语言时遵循用户要求。

## 何时使用

用户已有闭合三角网格，想合并两个实体、从主体挖去刀具或获得交叠区域；或希望用长方体、圆柱体做可重复的几何实验。必须调用真实工具得到结果，不得用模型估算值代替计算，也不得把可视化图片当作几何文件。

## 本机工作台

调用 `solid_mesh_workbench`：`action` 可为 `start`、`status`、`stop`，`workspace` 是用户选定、已存在且非符号链接的专用目录绝对路径。启动或关闭必须在用户明确授权后设置 `confirmed: true`。查询不要求确认。可选 `node_path` 指向已安装的 Node.js 22+ 绝对路径；不自动下载运行时或改动宿主依赖。

工作台只在本机回环地址开放。返回的专用 URL 含访问令牌，只交给当前用户，不放到公共日志或报告。用户可直接打开界面操作，无须额外模型调用。服务状态归当前插件安装及专用目录所有，不能关闭其他安装的服务。完成后用工具 `stop` 或界面“关闭工作台”结束会话。移除宿主插件工具不等于关闭已经启动的专用进程。

## 直接几何计算

调用 `calculate_solid_mesh`，输入 `project` 对象；可选 `node_path`。它不需要运行工作台，也不读取任意路径。

示例：两个边长 20 mm 的长方体，B 在 X 方向平移 10 mm。

```json
{
  "project": {
    "schema": "solid-mesh-workbench/v1",
    "units": "mm",
    "operation": "union",
    "a": {"kind": "box", "size": [20, 20, 20]},
    "b": {"kind": "box", "size": [20, 20, 20], "translate": [10, 0, 0]}
  }
}
```

成功结果中的 `metrics` 是引擎真实输出：`volume_mm3` 为体积，`area_mm2` 为表面积，`bounds` 为包围盒，`triangles` 为三角面数量，`empty` 表示有效空结果。示例并集应为 12000 mm³；差集与交集均应为 4000 mm³。`obj` 是导出文本，`project` 是可重载的规范化项目，`mesh` 与 `operands` 是几何检查数据。

`operation` 仅支持 `union`、`difference`（A 减 B）与 `intersection`。实体 `kind` 可为 `box`、`cylinder`、`obj` 或本插件项目使用的 `mesh`。变换用三维 `translate`（毫米）和 `rotate`（角度）；先旋转后平移。长方体从原点向正方向延伸，圆柱以 XY 原点为轴、从 Z=0 延伸。

## 格式与边界

- OBJ 仅接受 `v x y z`、正整数索引的三角 `f i j k` 和注释。明确按毫米解释，不自动推断单位。
- 不接受负索引、四边形、纹理/法线索引、材质、外部引用、脚本或附加项目字段。
- 每个实体和结果最多 10000 个顶点、20000 个三角面；OBJ 最多 1 MiB，项目最多 2 MiB。计算有 20 秒上限；超限时应减少复杂度，不扩大资源限制或修改宿主。
- 输入必须封闭、拓扑有效且整体朝向正确。输入自相交等几何问题并非都能自动识别；不会执行通用修复，也不认证制造安全或可打印性。
- 项目保留内部 Float32 网格及显式拓扑合并映射，不保证原始文件的任意数值精度。改变输入后旧结果失效，必须重算。
- 空交集是有效结果，不应编造几何。失败时如实说明工具错误，不生成替代的“成功”结果。
