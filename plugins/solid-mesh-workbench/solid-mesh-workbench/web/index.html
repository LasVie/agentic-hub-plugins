格式、精度与使用边界

支持正整数顶点索引的三角 OBJ（v / f），以及本插件导出的项目 JSON。OBJ 本身没有单位；导入即按毫米解释。项目保存经过校验的内部网格和变换，坐标采用 Float32。改变输入会使旧结果失效，须重新计算后导出。

不支持任意多边形、负索引、法线/纹理索引、材质、外链、动画或脚本。不承诺修复自相交、重复壳层、破洞或近重合面。空交集是有效结果。本工具不提供制造安全或可打印性认证。

计算不访问外网。关闭工作台会结束该插件的专用服务；请先保存项目。工作台与宿主界面相互独立。
