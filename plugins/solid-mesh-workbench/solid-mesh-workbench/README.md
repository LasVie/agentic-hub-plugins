# 立体网格布尔工坊 1.0.0

用 Manifold 3.5.4 的真实几何引擎，在本机离线完成闭合三角网格的并集、差集、交集及测量。可交互旋转查看输入和结果，导出 OBJ、项目 JSON 与中文测量报告。无需在线几何服务，也不调用模型进行数值计算。

## 安装要求

- macOS 或 Linux，支持原生 Plugin/Tool 的 WorkSwarm/openJiuwen；Python 3.11+。
- 已安装 Node.js 22+。工具会查找已安装的 Node；也可传 `node_path` 绝对路径。插件不安装软件或修改共享依赖。
- 支持 WebGL 的现代桌面浏览器；需要允许本机回环访问。Windows 生命周期未支持。
- 包含 Manifold 核心 JS/WASM 与许可证；不需要 `npm install`，不加载 CDN、外链或 ManifoldCAD 编辑器。

在 WorkSwarm 插件管理中导入原生测试 ZIP（根目录是 `manifest.json`），安装并在需要时选择此插件。市场封装 ZIP 则带外层 `plugin.yaml`，两者内层运行文件完全一致；不要把市场封装当成原生测试 ZIP。

## 使用

1. 选择已存在的专用工作目录，通过 `solid_mesh_workbench` 工具的 `start` 操作启动，明确授权后传 `confirmed: true`。
2. 打开工具返回的本机 URL。默认示例为两个部分重叠的 20 mm 方块；首次打开自动计算并集。
3. 选择“并集”“差集 A − B”或“交集”，修改尺寸、位置、旋转角度，再点“计算结果”。输入改变会立即使旧结果失效。
4. 拖动旋转、滚轮缩放，或将键盘焦点置于预览后使用方向键、加减键；双击或点“视图复位”居中。可切换输入轮廓。
5. 可以为 A/B 选择“导入三角 OBJ”。只支持下述严格子集；导入后须计算校验。
6. 成功后导出结果 OBJ、保存规范化项目 JSON 或下载中文测量报告。项目可通过“打开项目”重载。浏览器会尝试保存最近成功项目供同一地址刷新恢复；跨会话请使用项目文件。
7. 保存所需项目后点“关闭工作台”，或通过原生工具 `stop` 结束。仅卸载/停用宿主插件不会立即关闭专用服务；连续空闲 30 分钟后服务也会自行退出。

也可用 `calculate_solid_mesh` 直接传入项目 JSON，获得结构化几何输出，无须启动界面。输入格式与示例见 `skills/solid-mesh/SKILL.md`。

包内 `examples/` 提供两个可打开的项目、一个有效的 `闭合方块.obj`，以及用于验证拒绝行为的 `错误示例-破洞.obj`。后者应显示中文错误且无法导出结果。

## 支持的格式与限制

OBJ 仅含顶点 `v x y z`、三角面 `f i j k`（正整数索引）和 `#` 注释。顶点必须显式共享正确索引，不能依赖坐标近似焊接。无单位的 OBJ 按毫米解释。不支持多边形、相对负索引、带斜线的纹理/法线索引、材质、外部引用、动画或代码。

每个实体及结果最多 10000 个顶点、20000 个三角面；OBJ 最多 1 MiB；项目 JSON 最多 2 MiB；单次计算最多 20 秒。圆柱是有限分段三角近似，测量值对应网格，不是理想解析圆柱。坐标采用 Float32；近重合表面及过小特征可能产生数值问题。

输入必须是正确朝向的闭合三角实体。插件验证边与顶点拓扑，但无法自动识别所有自相交或重叠壳层，也不修补破洞。本工具不是 STEP 转换器、通用网格修复器、尺寸计量认证或可打印性认证。

空交集仍是成功结果：体积、面积与面数均为零，不能导出有几何内容的 OBJ，但可保存项目和报告。取消、非法输入或超限不会产生替代结果。

## 隐私、隔离与恢复

几何计算只使用插件内引擎。HTTP 服务只绑定 `127.0.0.1` 的空闲端口，使用每会话访问令牌、来源检查和有界请求；一次只运行一个计算。服务只能访问固定的包内资源，不提供任意文件读写接口。请勿公开包含令牌的 URL。

工作状态写入选定专用目录下的 `.solid-mesh-workbench/`。状态所有者、权限或安装路径不匹配时会拒绝接管；请选择新的专用目录，不要删除未知状态或关闭其他进程。刷新会重新校验恢复副本；失败时可点“重置示例”恢复。浏览器副本不是备份，请下载项目文件。
