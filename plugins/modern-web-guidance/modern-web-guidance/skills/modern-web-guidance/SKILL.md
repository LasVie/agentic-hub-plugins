# 现代网页技术指南

> 修改声明：2026-10-27，由 Gan Mingrui 维护的 JiuwenSwarm 适配版。依据 GoogleChrome Modern Web Guidance 0.0.196 的同名 SKILL.md 翻译改编；以原生离线工具替换 npx/latest，缩小到 12 篇精选指南，取消全局强制触发及联网安装。Apache-2.0，完整许可在插件根目录 `licenses/modern-web-guidance/LICENSE`。

补充前端实现和检查流程。后端、数据库、CI、普通文本编辑及本包未覆盖的功能不应强制使用此技能。

## 流程

1. 每次聚焦一个平台能力，调用 `modern_web_guidance`：`{"action":"search","query":"中文输入法回车误提交","limit":3}`。可用中文或 `container queries`、`LCP`、`closedby` 等 API 名称；多个能力分别查。
2. 按结果描述判断相关性，不把分数当置信度。用真实返回的 ID 读取：`{"action":"retrieve","ids":["ime-safe-enter-submit"]}`，一次最多三篇。必须读取内容后再引用，不能仅凭标题声称查过。
3. 未命中时可 `list` 一次。范围之外说明“本版未覆盖”，继续使用宿主已有能力，不虚构指南、不循环搜索、不自行下载全量包。
4. 按用户现有浏览器要求判断方案；未指定时采用渐进增强，保留核心功能降级。版本来自固定快照，获取日期不等于实时验证。`:has()` 与 `:user-invalid`、`dialog` 与 `closedby` 等能力需分别判断。
5. 框架适配时保留语义，检查 SSR 中 DOM API 时机、实例 ID 唯一性、焦点及减少动态效果。不要添加用户未要求的功能。
6. 默认中文说明：问题、实际指南 ID、建议、降级、验证方法和来源快照。区分“建议检查”与“已实际测试”；没有执行就不能报告通过。修改代码后说明该指南具体影响了哪个决定。

## 边界

- 工具只读包内静态内容，不联网、不访问项目目录、不执行示例。
- 这是 12 篇中文精选改编，不含全量 192 条上游目录、Chrome 扩展开发、内置 AI、身份认证或语义模型；以 `list` 为准。
- 不自动安装依赖、更改浏览器或注册后台进程。找不到 Node.js 时说明运行环境要求，不改用 npx 在线执行。
- 未获任务授权，不更改用户的浏览器支持策略、项目规则或依赖。用户指定其他输出语言时遵从。
- 已有 frontend-design 时沿用其设计流程，本插件补充技术依据，不替代视觉设计、真实浏览器调试或完整无障碍审计。
