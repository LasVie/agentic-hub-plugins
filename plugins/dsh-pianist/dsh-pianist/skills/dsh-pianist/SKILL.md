name: dsh-pianist
description: 离线钢琴演奏；在 WorkSwarm 中本地运行，无需外部账号，默认中文。
---

当用户需要不依赖账号的钢琴练习、简单旋律、和弦或离线音频导出时，使用原生工具 `dsh_pianist`，默认简体中文。先确定已有工作目录，按 README 的 MIDI/节拍格式生成音符，再调用工具。

如果只要求演示，使用原创短旋律或简单音阶，不把尚未生成的内容说成已完成。说明本包使用合成备用音色，不下载录音音色包。工具返回实际 WAV、JSON、HTML 路径后提供可点击产物链接，提示手动打开 HTML 并点击播放。不要只提交静态界面冒充可播放音频，不要把浏览器自动播放限制当作生成失败。

尊重256个音符和60秒上限；越界或失败时根据中文错误修正输入。默认标题和说明为中文。不要连接在线音乐服务或索取账号。
