# 行动优先表达 1.0.0

明确开启、关闭和查询行动优先表达模式，状态保存在用户指定的工作目录内；不作医疗效果承诺。

## 安装与使用

WorkSwarm 桌面端：扩展 → 本地上传，选择本包的 native ZIP；安装后点击使用，在新会话按下文调用。Agentic Hub 外层 ZIP 由项目负责人后续提交，不能与 native ZIP 混淆。

运行环境：WorkSwarm 原生 Python 工具 SDK；Python 3.11 或以上，无新增第三方 Python 包。

明确用户指定的工作目录；用户说开启时调用 action_first_mode on，关闭时 off，查询时 status。未明确要求不得代为开启。每轮使用同一个工作目录查询 status，以真实返回状态为准；状态只作用于该工作目录，不跨项目猜测。用户关闭后立即恢复普通表达，不再套用本模式。
开启后按 references/rules-zh.md：第一句给出动作或答案，多步编号，每项一个可执行动作，最多5项当前步骤；先交代进度和可验证结果，再给必要原因；还有工作时只留一个可立即执行的下一步。时间估计说明依据，不编造精确耗时。用户明确要求解释时提供充分解释。模式不覆盖宿主权限、工具调用和确认规则，也不提供医疗诊断或治疗承诺。
