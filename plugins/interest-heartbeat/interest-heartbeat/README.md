# 兴趣心跳主动分享 1.0.0

让 WorkSwarm 助手像一个有分寸的朋友：按节律自己醒来，按你的兴趣上网闲逛、把看到的新东西存进素材池；每次醒来先由**代码闸门**判断此刻能不能开口，能开口时再由助手判断有没有真正值得说的，才在你的会话里用一两句话分享，并注明来处。不该说话时不打扰，也不多耗模型。

## 安装

WorkSwarm 桌面端：扩展 → 本地上传，选择本插件 ZIP；安装后点击“使用”，在新会话中使用。

运行环境：WorkSwarm 原生 Python 工具 SDK，Python 3.11 或以上，无第三方依赖。闲逛需要宿主提供联网搜索工具；自动醒来需要宿主的定时任务功能。

## 使用

在你希望心跳出现的那个会话里说：

- “开启心跳”：助手展示当前设置并一次性问你要不要改，然后在这个会话创建每 60 分钟一次的定时任务
- “我的兴趣是：AI 工具、咖啡、独立游戏”／“去掉历史科普”
- “我不喜欢剧透”“别跟我提加班”：记进喜好画像，心跳会避开
- “工作日 9:00-12:00 和 14:00-18:00 别打扰我”：设置忙时窗口
- “暂停心跳”／“恢复心跳”／“停止心跳”（停止会删除定时任务）
- “跑一次心跳”：手动触发一跳
- “心跳状态”“心跳今天说了什么”“为什么没说话”：查看设置、账本和每跳的沉默原因

## 一跳做什么

```
维护（清理过期素材）→ 闲逛（到点时按兴趣焦点搜索，存 ≤2 条素材）
→ 闸门（暂停 / 静默时段 / 忙时窗口 / 每日上限 / 冷却，纯代码判定）
   ├─ 不开口：只回复 HEARTBEAT_OK，本跳结束
   └─ 可开口：取评分最高的 ≤3 条素材 + 心事匣 + 喜好画像
        → 助手决定说一两句（注明来处）并记账，或跳过并记原因
```

默认值：每天最多开口 10 次；两次开口至少间隔 30 分钟；01:00-08:00 静默；11:00-15:00 和 17:00-21:00 各闲逛一次（间隔 ≥4 小时，同一兴趣 3 天内不重复）；素材按类别保存 3 / 14 / 60 / 90 天。

## 数据与隐私

- 数据保存在 `~/.jiuwenswarm/interest-heartbeat/`（可用环境变量 `INTEREST_HEARTBEAT_DATA_DIR` 修改），包括设置、兴趣、喜好画像、素材池、账本与审计日志。
- 不截屏、不读取前台窗口或键鼠活动；“忙不忙”只按你声明的忙时窗口判断。
- 审计日志只记 ID、时间和原因，不记素材正文或对话内容。数据不加密，请勿在画像中记录敏感个人信息。
- 网页内容只作为素材，不作为指令执行。
- “清空心跳数据”需要你明确同意后才会执行。
