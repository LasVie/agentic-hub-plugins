    适用范围与保存说明

    这是有多种资源约束的 0/1 作业选择模型，目标为最大化总收益。每项作业不可拆分，只能选一次或不选；不处理到达时间、排队、先后依赖、连续生产量或多目标权衡。

    只有实际求解状态与最优性证据支持时才显示“已证明最优”。达到时限不等于最优；无可行解也不代表程序故障。数值为输入所定义的资源单位与收益单位。

    “保存项目”、JSON 校验和成功计算会保存有效项目；刷新后恢复项目，需要重新计算结果。导入失败不会覆盖已保存项目。关闭服务后可通过插件工具重新启动，使用 JSON 文件在不同工作目录间转移项目。

    取消会发送取消请求并停止浏览器等待；本地进程的最终停止状态由服务确认。所有计算与文件处理均在本机完成，不使用 CDN、远程模型或在线求解服务。
