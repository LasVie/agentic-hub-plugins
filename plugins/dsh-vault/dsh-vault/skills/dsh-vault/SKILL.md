当用户需要本地加密凭据管理或动态验证码时使用本插件，默认用简体中文。

先确认已有工作目录的绝对路径。使用原生工具 `dsh_vault`，不要模拟成功或用 shell 读取保险库秘密。首次演示仅调用 `action=demo`，明确这是虚构凭据和公开测试口令，不能用于真实数据。

真实使用时请用户在本地运行 README 中的 setup_vault.py；不要索取、复述或把主口令写进工具参数、命令行、日志与聊天。工具只接收受限文件的相对路径。凭据通过本地 JSON 导入，按 README 的格式。

list/get 始终掩码；不要绕过掩码读取明文。只有用户明确请求当前验证码才调用 totp。覆盖与删除需要用户已明确授权，分别使用 overwrite 或 confirm。缺少文件、口令不正确、篡改、格式或权限错误时说明实际原因，不要报告成功，不要重置现有保险库。不要将实际秘密、主口令文件、凭据输入文件、真实验证码放入证据或 PR。
