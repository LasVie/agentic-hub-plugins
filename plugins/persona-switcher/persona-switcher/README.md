# 会话人设切换 1.0.0

在会话中随时切换 AI 的人设与说话风格。角色是普通的 `ROLE.md` 文件，切换只改变“谁在说话、怎么说”，工具、技能、模型和权限保持宿主默认不变。

## 安装

WorkSwarm 桌面端：扩展 → 本地上传，选择本插件 ZIP；安装后点击“使用”，在新会话中使用。

运行环境：WorkSwarm 原生 Python 工具 SDK；Python 3.11 或以上，无第三方依赖，不联网。

## 使用

先告诉助手一个已存在的工作目录（绝对路径；在 WSL 上运行时可直接给 `D:\\...` 这样的 Windows 路径），然后用自然语言或类似 `/role` 的说法：

- “给我几个示例角色”：添加「茶馆掌柜」「严谨评审官」两个示例（不覆盖已有文件）
- “有哪些角色” / `/role list`
- “切换成茶馆掌柜” / `/role tea-master`
- “退出角色” / `/role none`：回到宿主默认人设；此后该工作目录（包括新会话）不使用任何角色，默认角色也不会自动装回，直到你再次切换
- “以后默认用严谨评审官” / `/role default strict-reviewer`
- “新建一个角色……”：助手整理 id、名称、描述和人设正文后保存；覆盖同名角色前会先询问
- “删除角色 X”：助手先请你确认，你同意后才真删除，不可恢复（工具层强制要求确认）
- “现在是什么角色”

每次切换后，助手会在回复中说明当前角色，并按新人设继续对话。

## 会写入的文件

只写工作目录下的 `.persona-switcher/`：

- `roles/<id>/ROLE.md`：角色文件（新建、覆盖、删除仅在你明确要求时发生）
- `state.json`：当前角色、默认角色与修订号；文件损坏时改名为 `state.json.corrupt` 保留，不直接删除

## 角色文件格式

```markdown
---
id: tea-master
name: 茶馆掌柜
description: 说话慢条斯理、爱打比方的老掌柜
---

人设正文……
```

id 只能用小写字母、数字和连字符，最多 64 字符；文件最大 32 KiB。只读取 id、name、description 和正文，`tools`、`model` 等字段一律忽略。

## 与上游的差异

- 状态按工作目录保存，而不是按 DSH 会话保存。
- 不包含 DSH 网页端的角色选择器、设置页、屏幕吉祥物立绘与翻纸动画，也不提供 `role_probe` 诊断工具。
- 人设通过固定提示段 + 每轮查询 status 生效，而不是动态注册 DSH prompt section。

## 已知限制

人设由模型遵循提示执行，不是硬性约束；长对话中如语气漂移，可让助手重新查询当前角色。人设不能授权越权操作，也不会让助手冒充真实个人欺骗他人。
