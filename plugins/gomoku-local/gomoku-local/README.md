# 本地五子棋 1.0.0

15×15 自由五子棋的本地状态、合法落子、胜负判定和中文棋盘导出；用当前会话模型对弈，无需额外账号。

## 安装与使用

WorkSwarm 桌面端：扩展 → 本地上传，选择本包的 native ZIP；安装后点击使用，在新会话按下文调用。Agentic Hub 外层 ZIP 由项目负责人后续提交，不能与 native ZIP 混淆。

运行环境：WorkSwarm 原生 Python 工具 SDK；Node.js 22（可使用桌面端内置版本）。

用户开始对弈后调用 gomoku_local new，或用 state 继续已有对局；不要覆盖已有对局。棋盘15×15、黑先行、五颗或以上连线获胜，无禁手。对话中的行列可显示1至15，但调用工具 row/col 必须减一转成0至14，并说明坐标。
每次落子先读取 state；调用 move 必须携带当时的 revision 和当前 turn。用户先手时用户走黑、当前 WorkSwarm 会话模型走白。模型只提供自己的坐标和简短战术说明，不暴露内部思维链。不要自己修改 JSON 或把不合法落子说成成功；冲突时重新读取并选择。获胜或和棋后不再落子。
export 导出中文 HTML 棋盘快照，可看到每手顺序和当前局面。棋盘是只读快照，继续对弈通过对话调用工具；没有后台服务、独立模型账号和 Jev。用户需要新局时使用新 game_id，保留旧局。
