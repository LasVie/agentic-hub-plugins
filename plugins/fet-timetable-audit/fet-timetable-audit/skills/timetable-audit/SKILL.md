# 课表校验与导出

默认用简体中文回答；用户明确要求其他语言时遵从。使用真实工具输出，不猜测文件内容，不声称未执行的检查通过。

1. 获取后端可访问的 `.fet` 绝对路径，调用 `inspect_fet` 检查输入引用、网格和工作量。缺少路径时说明需要的输入；不安装 FET 或 OR-Tools。
2. 用户提供已有活动安排 XML 后，调用 `verify_fet_timetable`，汇报版本、问题、活动 Id、教师/学生/时段及未检查范围。`ok` 表示执行成功；`passed` 仅覆盖已实施检查，软约束和未支持约束不能当作通过。
3. 用户要求导出时调用 `export_fet_timetable`，提供 `csv` 或 `json`、不存在的新输出路径及可选精确教师/学生名称。目录须已存在，两个筛选条件取交集。文件存在时停止并请求新名称，不能自行删除或覆盖。
4. 保留导出伴随的校验问题，显示真实文件位置、行数和 SHA-256。导出不修复冲突。CSV 公式样式文本被中和，JSON 保留原值。
5. Duration 和工作量是时段数量，不应自行称为实际小时。解释学生层级的冲突与 100% 不可用时段的继承关系。

本插件不生成、求解、优化或修复课表，不证明完整 FET 可行性，不检查教室容量/冲突和所有空间/时间约束。不得以“无已检查问题”代替完整合规或排课证明。核心不联网、不发起模型调用；遇到错误如实展示中文说明，不编造结果。
