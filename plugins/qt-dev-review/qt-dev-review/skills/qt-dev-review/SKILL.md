# Qt 开发审校

先确认用户已有工作目录和要审查的文件。实际调用 qt_dev_review 的 review；不得自行脚本替代工具。文件相对路径最多20个，每个最多1MiB。工具只读代码并写入单独的中文报告，不修改源代码。
检查结果来自上游启发式规则，不是编译器诊断。向用户报告文件、行号、规则编号、代码上下文及中文建议；区分已发现的问题、可能误报、需要人工核实的部分。用户要求更深入审查时再结合代码上下文提出中文修改建议，经用户确认后才修改代码。不要声称完成了 Qt 编译、GUI、性能测试或商用服务验证。
