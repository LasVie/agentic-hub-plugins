# 离线排队容量实验台

版本 **1.0.1**，引擎 **SimPy 4.1.2**。在本机运行有限、单阶段 FIFO 队列，比较服务台数量，回放事件，并导出可核对的 CSV 与场景 JSON。无需插件账户、网络或额外 Python 包；不会修改宿主文件或共享依赖。

## 安装与启动

- 需要支持原生 Plugin 的 WorkSwarm、已有 Python **3.11+**、macOS/Linux 与现代桌面浏览器。工作台使用 POSIX 文件锁和私有目录，不声明 Windows 兼容。
- 在 WorkSwarm 的「插件包」中导入 `queue-capacity-workbench-1.0.1-workswarm.zip`，安装并在会话中选择本插件。此 ZIP 根目录包含 `manifest.json`。另一个标准封装 ZIP 供后续交付，不能与原生安装 ZIP 混淆。
- 创建一个本插件专用空目录，例如 `/Users/你的用户名/Downloads/queue-capacity-manual-test`。告知助手这个绝对路径，并明确授权启动工作台。可调用 `queue_capacity_workbench`：`{"action":"start","workspace":"你的专用目录绝对路径","confirmed":true}`。只使用返回的本机链接，勿公开链接中的随机访问令牌。
- 无需模型的直接计算工具为 `simulate_queue_capacity`，输入 `{"project":场景对象}`。工具返回引擎真实结果，不是语言模型估算。会话选中插件不保证模型每次自动调用；可明确要求使用此工具。
- 浏览器关闭不等于服务停止。使用页面「关闭工作台」或生命周期工具的 `action=stop` 关闭本插件服务；30 分钟无活动也会关闭。禁用插件不会改写宿主或自动扫描/终止其他进程，禁用前请停止工作台。

## 精确对照示例

打开工作台，点击「计算并比较容量」。默认四项作业分别在第 0、1、2、3 分钟到达，每项服务 4 分钟。

| 容量 | 开始服务时刻 | 全部完成 | 平均等待 | 最大队长 | 利用率 |
| --- | --- | --- | --- | --- | --- |
| 1 台 | 0、4、8、12 | 16 分 | 4.5 分 | 3 | 100% |
| 2 台 | 0、1、4、5 | 9 分 | 1 分 | 2 | 88.889% |

切换「1 台 / 2 台」，点击下一步、播放或拖动事件进度，检查等待、服务与完成数。时间线金色为等候，蓝色为服务，红线为回放时刻。指标始终是完整运行的指标；回放只移动观察位置。事件轨迹保留引擎同时刻事件的实际顺序。

保存场景 JSON、导出 CSV，刷新页面后重新计算。场景在成功计算后保存在当前浏览器本地；结果不保存。工作台重启会更换端口/令牌，本地存储可能不共享；使用 JSON 跨工作台恢复。修改或导入时先清除旧结果，只有成功校验的计算才覆盖保存场景。无效输入会显示中文错误，可重置示例恢复。

## 有界声明式格式

```json
{
  "schema": "queue-capacity-workbench/v1",
  "name": "四项作业容量对照",
  "units": "minutes",
  "capacities": [1, 2],
  "jobs": [
    {"id": "作业1", "arrival": 0, "service": 4},
    {"id": "作业2", "arrival": 1, "service": 4},
    {"id": "作业3", "arrival": 2, "service": 4},
    {"id": "作业4", "arrival": 3, "service": 4}
  ]
}
```

只接受这些字段；拒绝未知或重复字段、重复作业标识、空场景、NaN/无穷大、非数值时间、脚本、HTML 文件、外部资源和过大输入。名称最多 80 字，标识最多 40 字且不能含控制字符。允许 1–500 作业、1–8 个不重复容量，每种 1–32 台。时间 0–100000 分钟，服务至少 0.001 分钟；最多三位小数，内部使用整数千分之一分钟；总服务时间最多 500000 分钟。场景不超过 256 KiB。每次计算最多 15 秒，最多一个计算同时运行。

同一时刻到达按输入顺序服务。所有有限作业处理至结束，不用截断终止时刻。最大队长按正等待区间 `[到达,开始服务)` 统计，合并相同时刻变化；不计零时长申请/获准瞬间。平均队长 = 等待时间总和 / 最终完成时刻。利用率 = 服务时间总和 /（容量 × 最终完成时刻），从第 0 分钟起算，含初始空闲。CSV 包含全部容量的全部作业；可能触发表格公式的标识前加单引号，原始标识仍保存在 JSON 中。时间线最多绘制前 80 项，完整数据仍在 CSV 与事件表。

## 使用边界

这是确定性比较工具，不是现实业务预测、统计拟合或最优容量证明。仅单阶段、同质服务台、非抢占 FIFO、无限等候区、固定服务时长；不含随机分布、优先级、失败重试、弃队、多阶段网络和服务器性能压测。SimPy 上游的其他功能不会作为可执行导入入口开放。无需上传任何 Python、JavaScript、HTML 或 CSS。
