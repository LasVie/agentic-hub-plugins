SimPy 4.1.2 · 版本 1.0.1 · 本机计算

构造与导入

修改到达时间、服务时长与容量，比较同一批作业的真实排队过程。

1–500 项作业；最多 8 种容量（每种 1–32 台）。时间最多三位小数；相同时刻到达按输入顺序服务。

准备就绪。点击计算运行示例。

模型边界与数据说明

单阶段、同质服务台、非抢占 FIFO；无限等候区；固定到达与服务时长。仿真从第 0 分钟开始，处理到全部作业结束。无随机拟合、优先级、多阶段网络或自动最优解。

服务台利用率 = 总服务时间 ÷（容量 × 最终完成时刻）。最大队长按正等待区间统计，不计零时长的申请/获准瞬间。事件回放按 SimPy 同时刻事件顺序显示，瞬间申请状态可能高于最大队长。

本页自动保存有效计算的场景到当前浏览器；不保存结果。可导出 JSON 跨工作台重载。导入仅接受声明式 JSON，不执行脚本、HTML 或表达式。不要用演示场景推断真实运营预测。
