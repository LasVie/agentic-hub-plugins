# 离线分子结构工作台 1.0.1

输入或编辑 SMILES，使用随包附带的 RDKit.js 计算分子描述符，以 SMARTS 查询子结构并显示首个匹配的高亮二维结构。结果可在交互页面下载为 SVG 或 JSON。无需联网、账户或 API 密钥。

## 安装与入口

在 WorkSwarm 的“扩展”中导入本插件原生 ZIP，安装并启用。原生 ZIP 顶层应包含 `manifest.json`；仓库的 Agentic Hub 包含额外市场包装层，不应直接当作原生包导入。

插件通过现有 `Tool` / `ToolCard` 和 Skill 扩展接口提供两个工具：

| 工具 | 用途 |
| --- | --- |
| `analyze_molecule` | 解析 SMILES，计算描述符，返回 SMARTS 首个匹配和高亮 SVG |
| `molecule_workbench` | 启动、检查或停止本插件自己的本地交互页面 |

宿主需提供兼容的 openJiuwen 原生工具接口、macOS / Linux 和 Python 3.11+。原生工具使用 POSIX 文件锁，不支持 Windows。代理分析另需已安装的 Node.js 18+；本插件不会自动安装它。交互页面在支持 WebAssembly 和 Web Worker 的现代浏览器中计算，不依赖 Node.js。

Node.js 默认从宿主进程的 `PATH` 查找；也可通过该进程的 `MOLECULE_WORKBENCH_NODE` 指定绝对路径。若宿主没有提供这两项配置，可仅在**已安装的本插件目录**创建 `settings.json`，内容为 `{"node_executable":"/可信Node可执行文件的绝对路径"}`。这是机器配置，不随发布包分发；不得修改其他插件或宿主文件。配置文件只能包含该字段，不能使用符号链接。路径必须由用户提供并确认可信，工具会检查 Node.js 版本。

给代理一个现有测试工作区的绝对路径，并授权它启动本插件页面。打开工具实际返回的 `http://127.0.0.1:端口/随机路径/web/index.html`。端口由系统分配，避免占用其他工作。请使用普通浏览器，宿主的静态附件预览可能不能运行脚本。

每个安装和版本使用独立的新工作区：先在运行 WorkSwarm 的电脑上新建空文件夹，再把其真实绝对路径交给代理。不要复制开发者的工作区路径，也不要复用另一安装或旧版本的 `.molecule-structure-lab` 记录。遇到 `invalid_runtime` 时保留原记录与服务，核对归属后另选新目录，不删除记录或绕过检查。升级时通过 WorkSwarm 的扩展导入/安装功能选择新版本；若仍返回旧版本，停止并核对该会话启用的插件。

## 示例

1. 输入阿司匹林示例 `CC(=O)Oc1ccccc1C(=O)O`，查询 `c1ccccc1`。
2. 分析后查看二维结构、匹配原子/键、分子量和其他描述符。
3. 将 SMILES 改为乙醇 `CCO`，重新分析；相同 SMARTS 应无匹配。
4. 分析成功后点击 SVG 或 JSON 导出按钮，由浏览器下载结果。
5. 输入 `C1CC` 应显示解析错误，而不是保留可导出的旧结果。

阿司匹林的 RDKit 平均分子量为约 `180.159`，精确分子量约 `180.042258736`，拓扑极性表面积约 `63.6 Å²`。这些是用于对照的预期值；以实际引擎返回为准，不得把预期值当作运行证据。

## 如何理解结果

- SMILES 表示带特定键和立体标记的分子图；规范化不证明真实样品身份。
- SMARTS 是子结构查询语言。高亮仅为首个匹配，不提供全部匹配数量。原子和键索引从零开始，对应 RDKit 规范化解析后的图，不是输入字符串位置。普通显式氢通常会被移除；例如 `[H]O[H]` 规范化为 `O`，原子计数为 1。
- 匹配采用 RDKit 默认参数，没有额外启用手性约束；不能据此宣称已验证立体选择性。
- 平均分子量与精确分子量使用不同定义；描述符名称、单位和原始键随结果保留。
- 描述符是算法结果；并非药效、毒性、反应可行性或实验安全结论。
- 输入变更会使旧结果失效，必须重新分析后才能导出。
- SVG 保存当前分子图并嵌入本次元数据，JSON 保存输入、引擎版本、规范 SMILES、描述符和匹配结果（不重复嵌入 SVG 图像）。浏览器下载文件不会自动写回宿主工作区。

单次输入限制为 SMILES 1024 字符、SMARTS 512 字符；分子最多 256 个显式原子和 512 条键，查询最多 128 个显式原子和 256 条键。分子 SMILES 不接受未知原子 `*` 或未指定键 `~`，避免对不完整结构给出误导性描述符；SMARTS 查询仍允许这些通配语法。仅支持单行 ASCII 结构语法，不接受名称、内部空白、反应表示和 CXSMILES。计算超时为 12 秒；超时不等于没有匹配。页面取消操作会释放当前计算线程。

## 离线与数据

化学引擎、界面、字体许可和脚本随插件分发；页面不使用 CDN、远程字体、统计或云服务。本地服务仅监听回环地址，服务范围限于插件自己的静态文件。随机 URL 不是多用户身份认证；不要把工作站或该 URL 当作共享化学数据库。

本插件不读取分子文件目录、不上传输入、不改写宿主源码、模型设置或其他插件。服务状态保存在所选工作区中本插件独占的目录中。请用插件的停止操作关闭其页面服务，不要手工终止不明进程。
