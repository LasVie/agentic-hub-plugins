# 离线管网水力工作台 1.0.0

编辑有限管网并使用 OWA-EPANET 2.3.5 计算真实的稳态水力平衡：管道流量、流速、节点水头和压力水头。支持双环示例、参数调整、方案比较以及 JSON / CSV / SVG 下载。

## 安装与启动

1. 在 WorkSwarm「扩展」中上传本版原生安装 ZIP，安装并启用「离线管网水力工作台」。安装不需要 Node 或额外 Python 包。
2. 为**当前安装、本次测试新建一个专用真实目录**，例如 `/Users/你的用户名/Downloads/pipe-network-test-1.0.0`。不要复用其他插件、其他 WorkSwarm 安装或开发自测留下的目录。
3. 请智能体实际调用 `pipe_network_workbench(action="status", workspace="目录绝对路径")`。明确授权后，再调用 `action="start", confirmed=true`。智能体须原样展示工具实际返回的完整 URL。
4. 在运行 WorkSwarm 的**同一台电脑的普通浏览器**点击 URL。再次 `start` 应安全复用相同 URL。工作台空闲 30 分钟退出；重新调用工具获取新地址，不猜测端口或使用历史 URL。
5. 可经明确授权调用 `action="stop", confirmed=true`，只停止身份核实的本插件服务。

若返回 `invalid_runtime`，保留原记录与服务并停止对此目录重试，为当前安装选择全新专用目录。不要删除、改写 root、覆盖记录或终止未知服务。本插件只在专用目录的 `.offline-pipe-network-workbench` 中保存本机服务身份，不在其中保存模型。

## 使用

- 载入「双环示例」，运行求解。查看箭头、每条管道的 L/s 和每个节点的压力水头。点击管道或节点选中参数，调整管径或需水量，再求解比较最低压力变化。
- 编辑 JSON 可改变节点、连接和参数；ID 使用最多 31 位英文字母、数字或 `_` 或 `-`，并以字母开头。模型名称可用中文。`x/y` 只控制绘图，不决定管长。
- 调整任何模型文本或数值会立即清除旧结果并禁用导出。必须重新运行后才能导出当前模型对应的结果。
- 「导出模型 JSON」保存可直接重新导入的模型。「导出结果 JSON」包含完整模型、原始数值、插件和引擎版本、单位与警告；它是报告对象，不是直接导入格式。CSV 保存完整计算数值；SVG 是本次网络图。
- 「恢复导入原文」恢复最近一次载入示例或成功导入文件的原始文本，不修改磁盘原件。

## 模型契约

仅接受 `schema_version: 1`、`headloss: "H-W"`、一个 `reservoir` 固定水头水库和至少一个 `junction` 固定需水节点。完整示例见 `web/one-pipe.json` 与 `web/loop.json`。

单位：`head_m/elevation_m/length_m` 为 m；`diameter_mm` 为 mm；`demand_lps` 和管道流量为 L/s；`roughness` 是无量纲 H-W C 系数。节点压力以 **m 水头**表示，不是绝对压强；水库显示总水头而非节点压力。管道全部开启，局部损失为零，不设需水时变模式。

64 KiB 文本、2–50 个节点、1–80 条管道；数值范围由页面校验。重复键、未知字段、断开连接、无效参数均拒绝，不静默忽略。每次计算在独立线程进行，12 秒超时或取消后终止线程；修改输入同样结束旧计算。

## 结果边界

负压力是警告，不代表现实中仍能满足需水量。固定需水模型会继续强制该需水量；导出会保留警告。未收敛或明显违反连续性的结果仅展示诊断并禁用导出。`analysis_complete` 只表示本模型求解完成，不证明模型正确或工程安全。

不含泵、阀、储水罐、水质、延时模拟、动态控制、任意 INP 导入、在线地图、真实公共设施资料或供水认证。仅供学习和有限方案探索，请独立核对单位、模型和结果。

## 环境与许可

原生启动工具要求 macOS / Linux、Python 3.11+ 和支持的 openJiuwen Tool/ToolCard 接口。Windows 不支持当前 `fcntl` / POSIX 文件校验路径。浏览器需支持 ES modules、Worker 和 WebAssembly SIMD，建议当前桌面 Chrome。计算只使用插件自带本地资源；不调用付费模型或外部分析服务。
