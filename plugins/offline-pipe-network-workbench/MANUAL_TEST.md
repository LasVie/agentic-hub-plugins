## 浏览器测试与预期

| 测试 | 操作 | 预期，仅供对照 |
| --- | --- | --- |
| 双环真实求解 | 载入双环示例，运行 | 7 个节点、8 条管道，总需水量 16 L/s；流向、节点压力与表格显示；正常样例无警告 |
| 参数改变 | 点击管道 P1，把管径改为 200 mm | 修改后旧图表和四个导出立即失效；重新运行后 P1 流量增加，显示与上一方案最低压力的比较 |
| 需水量 | 选中节点 B，将需水量从 3 改为 4 L/s | 再次失效；运行后总需水量 17 L/s、供水流量随之变化 |
| 单管解析核验 | 点击「单管校验」，运行 | 水库水头 100 m，J 需水 1 L/s，管长 100 m、管径 100 mm、C=100；流量约 1 L/s，损失约 0.04355 m，J 压力水头约 99.95645 m |
| 管径规律 | 单管管径改为 200 mm 后运行 | 流量仍约 1 L/s，损失约 0.00149 m；不是将流量翻倍 |
| 四种下载 | 分别导出模型 JSON、结果 JSON、CSV、SVG 并打开 | 模型 JSON 可直接重新导入；结果 JSON 含版本、引擎、单位、完整模型、原始数值与警告；CSV 数值一致；SVG 图形与当前图一致 |
| 重导入 | 重新导入刚下载的模型 JSON 并求解 | 模型和值保持一致；结果 JSON 是报告对象，不能当作直接导入格式 |
| 错误与恢复 | 重复键 JSON、未知字段、零管径、断开的节点 | 中文拒绝并显示错误代码，旧结果不可导出；恢复导入原文后可重新运行 |
| 负压力 | 单管模型中把 J 的 elevation_m 改为 101 | J 压力为负，明确显示警告6；结果不是实际供水能力证明，导出保留警告 |
| 取消/编辑 | 正在计算时取消或修改文本 | 旧线程结束，不得出现旧模型的延迟结果；没有当前有效结果时不能导出 |

独立核算参考：公制 H-W `h = 10.67 L Q^1.852 / (C^1.852 D^4.871)`，Q 为 m³/s、D 为 m；上述单管约 0.0435677 m。引擎系数的微小差异在本例 0.1% 容差内。页面四舍五入，结果 JSON / CSV 保留原始值。
