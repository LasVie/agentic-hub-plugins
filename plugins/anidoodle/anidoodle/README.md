# 手绘交互工坊 1.0.0

将鼠标跟随角色、表单伙伴和滚动逐笔绘画制作成独立的中文 HTML。打开作品后可离线互动，并保存当前画面为 PNG。基于 anidoodle 0.9.6 的实际绘图源码移植。

## 在 JiuwenSwarm 使用

安装原生插件包后，启用“手绘交互工坊”，开始新对话。说明需要的场景与输出目录，例如：

- “在我的工作区制作一个手绘互动伙伴，标题是‘和我一起开始’，点击按钮后欢呼。”
- “制作一个随滚动逐步画出来的插画页面，标题是‘一张插画的诞生’。”
- “生成一个输入演示密码时遮眼的表单伙伴。”

模型应调用 `anidoodle_art`，不能用文字回复冒充已经生成作品。工具返回真实绝对路径后，用 Chrome 或 Edge 打开 HTML。宿主可能将 HTML 显示为下载文件；对话内嵌预览不是本插件保证的能力。工具不自动打开浏览器。

`mascot`：鼠标跟随、按钮悬停、点击欢呼、挥手、点击角色。可用 Tab/回车操作按钮。

`form`：只用于交互演示。填写虚构称呼与至少四个字符的演示密码；遮眼、偷看和完成表情均在本地进行，不注册账号，不提交数据。

`scroll`：向下滚动画出结构、线稿、水彩与细节；向上滚动回看。系统开启减少动态效果时会展示完成的插画。

右下角的暂停按钮控制动画。页面下方“保存当前画面 PNG”导出画布，不是整页截图。首次绘制需要数秒；分辨率上限为逻辑尺寸的 1.5 倍。HTML 包含引擎与许可，不依赖 CDN、字体服务、音色下载或生成式图片 API。

## 能力边界

首版交付三个铅笔水彩场景以及可改编的绘图核心。标题与说明可由对话定制；角色外形和画风不会因为修改标题而自动改变。上游的全部 32 种画风、MP4/GIF、音乐和任意角色的一句话生成不在首版已验证范围。一般视频剪辑、分镜和配乐请交给现有 Remotion/分镜制作能力。

常规生成只需要宿主 Python 环境和浏览器，不需要安装 Node/npm。修改绘图源码并重新构建才需要 Node.js 20+ 和 esbuild 0.25.12。旧浏览器、手机和长时间持续运行尚未全面验证。

## 可编辑源码工程

要求“把可编辑源码导出到工作区”。工具 `action=source` 创建全新 `<name>-source` 目录，带绘图源码、构建脚本、运行脚本、说明和许可；已有目录不会覆盖。

1. 修改 `engine/src/entry.ts`、`engine/src/canvas-core/` 或 `runtime.py` 页面模板。角色绑定动作使用 `data-anidoodle` 标记。
2. 在导出的 `engine` 目录运行 `npm install --ignore-scripts --registry=https://registry.npmjs.org`，再运行 `npm run build`。首次构建需要联网下载编译器；不下载浏览器或音色包。
3. 回到源码工程根目录，将下面 JSON 通过 UTF-8 stdin 交给 `python runtime.py`（PowerShell 请确认输入输出编码为 UTF-8）：

```json
{"action":"create","scene":"mascot","workspace":"D:\\你的实际工作区","name":"my-art","title":"我的手绘伙伴"}
```

新角色需要实际编写 `Piece` 绘图与交互代码，再注册到 `entry.ts`。参考已有 `mascotHero.ts` 的 `meta/input/bake/draw` 结构。`draw` 应保持相同输入得到相同画面，不在绘图函数里读取网络、时钟或任意随机数。浏览器控制器提供 `setState`、`pause`、`play`、`destroy`。改编后应验证鼠标、键盘、减少动态效果和导出，并检查许可是否仍随作品保留。
