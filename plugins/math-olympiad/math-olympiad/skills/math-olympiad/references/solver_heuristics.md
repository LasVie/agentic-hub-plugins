# 求解启发法（Pólya + 奥赛实践）

供求解阶段使用（由同一智能体在求解阶段中执行）。这些是直接方法卡住时可以尝试的招式。

## Pólya 的核心招式（出自《怎样解题》"How to Solve It"）

**你见过相关的问题吗？** 不是同一个问题——而是有相同的**未知量**或相同**结构**的问题。用直线覆盖点的问题，与用等差数列覆盖格点的问题具有相同的形状。

**特殊化。** 如果解不出给定问题，就手算 n=3、n=4、n=5。规律往往就是证明。（但是：要越过第一个非平凡情形再测试——n≤3 可能是退化的。）

**一般化（发明者悖论）。** 更宏大的问题有时具有**更多**结构，反而更容易。如果整数情形有干净的归纳法，"对所有素数证明"可能比"对所有整数证明"更难。

**去掉一个条件。** 放宽一个假设会怎样？结论是否变得显然错误？在**哪里**出错？那个**哪里**往往就是关键步骤——条件真正起作用的地方。

**倒推。** 从你想证明的结论出发。什么能推出它？什么又能推出**那个**？如果这条链遇到了你能直接证明的东西，你就得到了证明（反过来写即可）。

**辅助元素。** 引入题目中没有的东西——新变量、一次反射、一个精心选择的函数。奥赛几何就靠这个生存（辅助点、辅助圆）。

## 奥赛专用招式

**找不变量。** 如果有一个过程（游戏、变换、迭代），什么量是保持不变的？奇偶性、和、某个模下的积。

**找极端。** 取**最大**、**最小**或**最左**的对象。极端选择往往具有一般选择所没有的额外性质。

**双重计数。** 用两种方式数同一个东西。关联数、边数、对所有点对求和。

**染色 / 奇偶性。** 能否把对象 2-染色，使断言变成一个奇偶性命题？

**磨光 / 调整。** 对于不等式：如果把两个变量调得更接近（或更远离），表达式是增大还是减小？取极值。

**对称性 → 不失一般性（WLOG）。** 如果问题关于 x,y,z 对称，可以假设 x≤y≤z。但前提是结论**也**是对称的。

## 几何专用招式

标准思路（归纳、不变量、极端）对奥赛几何往往不对路。改用以下方法：

**坐标暴算。** 把图形放进坐标系。选择坐标来消去自由度（原点放在圆心，坐标轴沿某条直线）。硬算代数。难看但可靠。

**辅助点。** 引入题目中没有的点——一个反射点、第二个交点、两条直线"应该"相交的点。关键构造往往就是找到正确的额外点。

**圆幂。** 对任意点 P 和圆 ω，对过 P 且与 ω 交于 A、B 的每条直线，PA·PB 都相同。用它把比例转化为等式。

**旋转相似 / 旋转。** 两个正相似三角形由一个旋转相似（绕某定点的旋转 + 缩放）联系。找到那个点——它常常落在你已有的某个圆上。

**反演。** 当有很多圆或相切关系时，以精心选择的点为中心反演。过中心的圆变成直线；相切变成更简单的相切。

**角度追踪。** 圆内接四边形给出相等的角。弦切角等于圆周角。沿图形追踪角度。

## 几何专用招式（这些是**不同的**）

标准思路（不变量、极端、归纳）不适合圆/外心/垂心问题。几何需要：

**坐标暴算。** 把一个点放在原点，另一个放在 x 轴上。显式计算一切。代数量大但很机械。对于圆心为 M、N、半径为 r、R 的两个圆：设 M=(0,0)，N=(d,0)，则交点的 x 坐标为 (r²+d²−R²)/2d，其余一切随之而来。

**辅助点。** 引入题目中没有的点——反射点、垂足、第二个交点。奥赛几何就靠找到正确的额外点生存。

**圆幂。** 对点 P 和圆 Γ：对过 P 且与 Γ 交于 A,B 的任意直线，PA·PB 为常数。这把圆转化为乘积。

**反演。** 过中心的圆变成直线。有时反演后的问题是平凡的。

**角度追踪 / 圆内接四边形。** 四点共圆当且仅当对角之和为 π。追踪角度，直到足够多的等式迫使四点共圆。

## 递推专用陷阱

对于形如 b\_{n+1} = P(b_n)、P 为 ≥ 2 次多项式的递推：**b_n 以双指数速度增长**。你无法精确计算 b_30——它有数万亿位数字。从一开始就在 ℤ/2^m（或 ℤ/p^m）中工作。对 n 归纳证明 b_n ≡ r_n (mod 2^m)，**不要**去计算 b_n。

## 当答案涉及 √n 或 log n 时

这类答案往往来自一个**并非**显而易见/对称的结构。对角线、恒等、"自然"的选择常常给出**最坏**情形而非最好情形——它把约束聚集在一起，阻止了大的子结构出现。

**对于纯推理求解**：在声称对称选择是最优之前，问"如果我故意打破对称会怎样？"对于网格/覆盖问题：如果把空隙**分散开**而不是聚集起来呢？对于序列：如果极值序列**不是**常数或线性的呢？

**对于深度模式（可使用代码执行工具时）**：先对 n=3..8 暴力枚举，再建立理论。如果拟合的公式是 n+c√n 而不是 cn，说明结构中有 √n 大小的块。

## 回顾阶段（得到证明之后）

- **你能检验它吗？** 代入小情形。n=3 是否给出你的公式所说的值？
- **你能用别的方法证明吗？** 第二个证明就是一次验证，而且往往更短。
- **你的界是紧的吗？** 如果你证明了 ≤ N 而答案恰为 N，找出极值情形。如果找不到，你的界可能是松的。
- **你实际用到了什么？** 有时你并没有用到全部假设——真正的定理更强。
