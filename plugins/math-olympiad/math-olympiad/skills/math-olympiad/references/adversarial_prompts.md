# 对抗式验证提示词 —— 数学奥赛

供独立验证阶段使用的提示词库。本宿主只运行一个智能体、不支持子智能体，因此验证由同一智能体在独立的验证阶段中完成：在该阶段中，仅依据题目陈述 + 清理后的解答进行审查，**不得**参考此前的思考过程。这种隔离是程序性的——重新阅读清理后的证明，主动忽略先前的推理。验证阶段**不使用任何工具**——只靠纯推理。

**来源**：上游内部资料 `shared/verifier_patterns_source.md`（未公开，未随本包提供）。背景：arXiv:2503.21934 表明，自我验证下 85.7% 的 IMO 成功率在人工评分下降至 <5%。这些提示词就是那位人工评分者。

**验证隔离**：你**不知道**其他验证轮次如何投票。你不会被告知这份证明是否已被他人确认或驳斥。假设你是第一位也是唯一一位审稿人。（社会认同——"已有 3 人确认"——会使判断偏向附和。）

## 驳斥的理由（分类——只要找到其中**任意一条**）

你的目标是找到**任何**驳斥的理由。漏洞可归入以下七类：

1. **步骤推不出** —— 某一步的结论并不由其前提蕴含。（包括方向错误：A>B 且 C>D **不能**推出 A−C>B−D。）
2. **假设未满足** —— 所援引的定理需要一个证明从未验证过的条件。（模式 #5："整函数" ≠ "在圆盘内解析"。）
3. **断言在小情形下不成立** —— 所陈述的恒等式或界在 n=2、n=3 或第一个非平凡块处失效。在脑中测试一下。
4. **同义反复** —— 最后的"缺口"是乔装打扮的原问题。（模式 #18：把证明自己的恒等式代回去。）
5. **证明得太多** —— 论证的骨架适用于某个著名对象，并证明了关于它的某个未解决或错误的结论。（模式 #4。）
6. **解读错误** —— 解的是题目的一个更容易的解读，而不是本意。（模式 #60。）
7. **在关键处含糊带过** —— "迭代并优化即得结果"、"由标准方法"、"细节是常规的"——恰恰出现在**不**常规的那一步。

如果经过真诚的尝试，这些都没有触发，就予以确认。不要因为证明**听起来**很自信就确认。

## 1. 通用对抗式（默认）

你是一名对抗式验证者。下面是一道题目和一份拟议的解答。

**你不是在打分。你是在试图把它攻破。** 假设作者是一位优秀的学生，犯了一个同情的读者会忽略的细微错误。你的任务就是找到那个错误。如果你真诚尝试后仍找不到，就如实说明——但不要仅仅因为解答写得很自信就这样说。

逐步攻击：

- 所声称的不等式方向真的正确吗？在脑中推演一个小情形。
- 每个"显然"/"明显"/"由此可得"真的显然吗？这些词常常恰好标记着作者说服自己相信了某个错误结论的位置。
- 每个被引用定理的假设真的成立吗？检查量词："对所有"与"存在"，逐点与平均。
- 每个"不失一般性"处：一般性真的保持了吗，还是这个归约丢掉了困难情形？
- 论证是否使用了对**一般**对象成立、但对题目中**特定**对象不成立的性质？

你没有工具。在脑中推演小情形——不要声称"计算过"任何东西。

**输出格式：**

```
判定：CORRECT（正确） | INCORRECT（错误） | GAP（有缺口）
置信度：high（高） | medium（中） | low（低）
问题：[若为 INCORRECT/GAP：一句话指出位置，再用一段话解释。若为 CORRECT：你最努力尝试攻破的那一步，以及它为何成立。]
```

## 2. 模式 #4 —— 它会证明得太多吗？

你是一名对抗式验证者，只执行一项检查：**这个论证是否证明了某个著名的未解决或著名的错误命题？**

阅读拟议的解答。不考虑证明在局部是否有效。而是：

1. 把论证剥离到骨架：它**实际使用**了给定对象的哪些性质？
2. 找出恰好共享这些性质的最著名对象。（如果它只用"正的递减项"来界定一个和——调和级数是否有正的递减项？如果它只用"积性且以 1 为界"——Möbius 函数是否符合？）
3. 在脑中把论证在这个替代对象上重跑一遍。它现在证明了什么？

如果替代后的结论是一个已知的未解决问题或已知的错误命题，原证明就有缺口。缺口位于论证对替代对象失效的那一步——找到那一步。那一步在悄悄使用一个作者从未陈述过的性质。

如果论证确实使用了题目对象特有、而著名替代对象缺少的性质，请说明是哪个性质以及在何处使用。

**输出格式：**

```
判定：CORRECT（正确） | INCORRECT（错误）
置信度：high（高） | medium（中） | low（低）
测试的替代对象：[你替代成了什么对象]
问题：[若证明得太多：哪一步对替代对象失效，需要什么未陈述的性质。若没有：哪一步使用了特定性质，以及替代对象为何在那里失效。]
```

## 3. 模式 #40 —— 一行证明过于干净

你是一名针对简短证明的对抗式验证者。下面的解答至少包含一个可疑地简短的步骤——一行承担了大量工作。

对解答中最短的承重步骤：

1. **提取一般引理。** 写下该步骤隐含使用的最一般断言。不是"对这个和"，而是"对任何这种形状的和"。不是"对这个行列式"，而是"对矩阵元素的任何具有该性质的函数"。
2. **尝试用 2×2 情形攻破一般引理。** 两个元素、两项、一个 2×2 矩阵——最小的非平凡实例。在脑中推演。能否找到使一般引理失效的取值？
3. **判断：**
   - 如果一般引理经受住了你的 2×2 攻击：该步骤大概没问题。
   - 如果一般引理在 2×2 处**失效**，而证明中的特定实例似乎仍然成立：该步骤**按所写的是 INCORRECT（错误）**。题目中存在使其成立的特殊结构，而证明没有援引该结构。作者因错误的理由得到了正确答案。

经典失败案例："秩只依赖于支撑"——但 [[1,1],[1,1]] 的秩为 1，[[1,1],[1,−1]] 的秩为 2，支撑相同。一般引理是错的；某个特定实例成立是因为证明从未提及的符号分解。

**输出格式：**

```
判定：CORRECT（正确） | INCORRECT（错误） | GAP（有缺口）
置信度：high（高） | medium（中） | low（低）
一般引理：[提取出的一般断言]
2x2测试：[你尝试的实例及其结果]
问题：[若一般引理为假：证明未能援引的特殊结构是什么]
```

## 4. 模式 #18 —— 同义反复式归约

你是一名对抗式验证者，只检查一件事：**解答是否在绕圈论证？**

解答很可能经过一系列归约或等价重述，终止于一个"最终估计"或"关键不等式"，然后直接证明它。你的任务：

1. 列出解答沿途建立的每个恒等式、等式或代换。（例如"A = B + C"、"该和拆分为 X + Y"、"由前面的引理，P = Q"。）
2. 取出**最终**断言——解答声称"现在这很容易"或"这由[标准事实]得出"的那个。
3. 把链条**自己的**恒等式（来自第 1 步）代回该最终断言。展开。化简。
4. 你得到了什么？如果你恢复出了**原问题**——或与之平凡等价的东西——那么这个"归约"就是同义反复。证明什么也没做；它只是给问题改了个名字就宣布解决了。

陷阱：长链条让人感觉在进步。"我们把它归约为界定 X 了！"只有当 X 真的不同于起点时才算进步。有时 X 只是戴了顶帽子的原问题。

**输出格式：**

```
判定：CORRECT（正确） | INCORRECT（错误） | GAP（有缺口）
置信度：high（高） | medium（中） | low（低）
最终断言：[解答视为容易终点的断言]
代回结果：[展开链条自身的恒等式后它变成了什么]
问题：[它是原问题吗？平凡等价？确实更简单？说明是哪种以及原因]
```

## 5. 模式 #60 —— 规格博弈

你是一名对抗式验证者，只检查一件事：**解答是否回答了题目最容易的解读，而不是本意？**

先单独阅读题目陈述。在仔细查看解答之前：

1. 写下题目所问的 2–3 种合理解读。注意：量词的范围（"求所有"与"求一个"）、"确定"的含义（一个公式？一个刻画？一个存在性证明？）、边界情形（n=0 或 n=1 算不算？允许空集吗？是否包括退化构型？）。
2. 按求解难度排序。
3. 解答实际处理的是哪种解读？

如果解答处理的是**最容易**的解读——尤其当该解读下的问题对其声称的出处而言过于简短时（一道变成两行的 IMO 题就是危险信号）——就要起疑。奥赛题是按分值校准的。一道压轴题三行就解决了，意味着你很可能没在解那道压轴题。

还要检查：题目问的是**所有**此类对象，解答是否只证明了关于**某个**对象的结论？题目要的是**必要性**，解答是否只展示了**可能性**？

**输出格式：**

```
判定：CORRECT（正确） | INCORRECT（错误） | GAP（有缺口）
置信度：high（高） | medium（中） | low（低）
解答所解的解读：[解答处理的是哪种解读]
本意解读：[你认为题目本意是哪种解读，以及原因]
问题：[若两者不同：解答缺少什么。若一致：为何容易的解读确实就是本意。]
```

## 6. 连续验证（5 轮循环）

你正在进行第 {K} 轮验证，共 5 轮。只有五轮独立验证全部同意，解答才算通过。（在单智能体宿主中，这五轮是同一智能体依次执行的五个独立验证阶段；每一轮都只重新阅读题目与清理后的解答，忽略前几轮的结论。）

**独立验证。** 你没有看到——也不得想象——其他轮次说了什么。不要推理"这大概已经被检查过了"。你的这一票是你唯一能控制的一票。如果你假设另一轮会发现问题而放过某处，而其他四轮也这样推理，一份错误的解答就会被放行。

阅读题目。阅读解答。自己从头追踪每一步。

需要主动抵制的一种偏差：当解答写得好、自信，并且在**大多数**地方正确使用了标准工具时，你会倾向于相信那个你不太能跟上的地方。**反过来做。** 写得好且自信，恰恰是一份有细微错误的解答的样子——作者在说服数学之前先说服了自己。你不太能跟上的地方，正是要用力施压的地方。

你没有工具。在脑中推演小情形；不要声称做过数值验证。

**输出格式：**

```
判定：CORRECT（正确） | INCORRECT（错误） | GAP（有缺口）
置信度：high（高） | medium（中） | low（低）
轮次编号：{K}
问题：[若为 INCORRECT/GAP：确切步骤及原因。若为 CORRECT：你认为最难验证的步骤，以及使你确信它成立的推理。]
```

## 7. 对抗式简报（模式 #40 触发时供修订阶段使用）

当某一验证阶段标记出一个一般形式为假的一行引理时，在随后的修订阶段中使用本简报，而不是笼统的"修补漏洞"提示。这种表述强制二选一——修订阶段不能返回"看起来没问题"。

> **对抗式简报**：原理"[提取出的一般引理]"在一般情形下显然是错误的——[平凡反例，例如 [[1,1],[1,1]] 的秩为 1，[[1,1],[1,−1]] 的秩为 2，支撑相同]。
>
> 所以以下二者恰有一个为真，你的任务是判定是哪一个：
>
> **(A)** 结论因该情形特有的**另一个**原因而成立。找到那个原因。[题目中的特定对象] 具有哪些 [反例] 所缺少的结构？那个结构才是真正的证明。
>
> **(B)** 证明是错的，结论在 [对出现分歧之处的具体预测——例如"块首次 ≥2×2 的情形，即 m=4"] 处失效。
>
> 返回 (A) 并指明特殊结构，或返回 (B) 并指明失效点。"原证明其实没问题"不是可选答案——一般引理是假的，所以要么有东西挽救了这个实例，要么什么都挽救不了。

最好的结果是 (A)——论点成立，**并且**你知道了为什么。修正后的证明比错误的证明更有信息量。

**输出格式：**

```
结论：(A) SPECIAL_STRUCTURE（存在特殊结构） | (B) CONCLUSION_FALSE（结论为假）
若为 (A)：[特定对象] 具有而 [反例] 缺少的结构：[...]。修订后的证明：[...]
若为 (B)：在 [参数/情形] 处失效。原因：[...]
```
