# 表述润色阶段——提示词与模板

**前提**：Aletheia 的 PDF 很漂亮；原始的 IMO 输出则不然。区别在于一个 _表述润色阶段_：在证明**经验证正确**之后，进入一个独立的新阶段——以“没有亲历发现过程”的视角——找到最简洁的表述方式。发现者对脚手架过于依恋。

那篇 Erdős 论文甚至批评了 Aletheia _自己_ 的输出：_“有些杀鸡用牛刀；任何反函数至多为 [X] 的 f 都足够，没必要取双重指数。”_ 表述润色阶段就是用来消灭“杀鸡用牛刀”的地方。

---

## 1. 表述润色阶段提示词

在同一智能体内，于验证通过后**单独开启一个表述润色阶段**，按顺序执行，并以下面的提示词和已验证证明作为该阶段的唯一输入。由于宿主只运行单个智能体、没有子智能体，这里的隔离是流程上的：本阶段只依据给定的已验证证明工作，忽略此前发现过程中的推理与草稿；这正是要点所在。

> 你拿到的是一份**已验证、正确的证明**。你的任务不是检查它——它是正确的。你的任务是找到**最简洁的表述**。它被发现的顺序几乎从来不是它应该被阅读的顺序。
>
> 按顺序处理以下问题：
>
> **事后捷径。** 既然已经知道答案，有没有 3 行的论证？发现者搭建机器是为了 _找到_ 关键步骤；而你已经 _拥有_ 关键步骤。这些机器能否丢掉？（经典情形：冗长的分类讨论，事后一旦发现不变量就整个坍缩。）
>
> **杀鸡用牛刀。** 有没有比所需更强的界？有没有比题目要求更一般的构造？如果双重指数可行而线性函数也可行，就用线性的——读者会怀疑双重指数在掩盖什么。让每个工具的强度与它所证明结论的强度相匹配。
>
> **删什么。** 哪些步骤只是 _验证_ 而不 _启发_？发现过程会留下一片残骸：合理性检查、退回来的死路、“注意 X（我们不会用到它）”。删掉它们。如果一个段落删去后证明仍能在读者脑中成立，就删掉它。
>
> **引理粒度。** 如果一个引理只用一次且证明 ≤3 行，就内联它。如果用了两次，或者其 _陈述本身_ 就能阐明结构（即使证明只有 1 行），则保持独立。为独立引理起描述性的名字——“组合维数界”，而不是“引理 2”。
>
> **顺序。** 先给出主要结论。然后是让它成立的那一个想法。然后是细节。把那个真正巧妙的步骤单独拎出来——几乎总是恰好只有一个——让其余一切 _相比之下_ 显然是常规的。
>
> **步骤命名。** 给步骤编号 _并且_ 命名：“**第 3 步：Fourier 反演与平移不变性。**” 名字是对读者的承诺，说明这一块要完成什么。明确标出归约：“我们归结为证明……”
>
> 使用下面的模板输出简洁的 LaTeX。目标：一位优秀的研究生能重建每个被省略的细节，一位教授只浏览步骤名就能点头认可。

## 2. LaTeX 输出模板

最简导言区——沿用 Aletheia 的环境，不要它的装饰。不用 `tcolorbox`，不用自定义颜色。

```latex
% 使用 ctexart 以支持中文，需用 xelatex 编译。
\documentclass[11pt]{ctexart}
\usepackage[margin=1.25in]{geometry}
\usepackage{amsmath, amssymb, amsthm, mathtools}
\usepackage[shortlabels]{enumitem}
\usepackage{hyperref}

\theoremstyle{plain}
\newtheorem{theorem}{定理}
\newtheorem{lemma}{引理}
\newtheorem{claim}{断言}
\newtheorem{proposition}[theorem]{命题}

\theoremstyle{definition}
\newtheorem{definition}[theorem]{定义}
\newtheorem*{remark}{注}

\begin{document}

\section*{题目}
% 原样重述题目。不要意译。

\section*{解答}

\begin{theorem}
% 完整陈述你将证明的内容。如果答案是“是”或“否”
% 或某个具体值，就在这里写明，不要让读者悬着。
\end{theorem}

% 如果某个引理被重复使用或在结构上承重，就在主证明之前
% 陈述它。一次性的验证在下文内联。
% \begin{lemma}\label{lem:key}
%   ...
% \end{lemma}
% \begin{proof} ... \end{proof}

\begin{proof}[定理的证明]
\textbf{第 1 步：[描述性名称——这一步完成什么]。}
% 例如“归约到紧情形。” / “关键不变量。”

% 重要等式用行间公式；常规等式用行内公式。
% 归约步骤以“我们归结为证明……”结尾。

\textbf{第 2 步：[名称]。}
% ...

\textbf{第 $n$ 步：结论。}
% 一两句话。让矛盾 / 归纳的闭合 / 最终计算
% 清晰地落地。
\end{proof}

\end{document}
```

**从 Aletheia 样例中借鉴的风格约定：**

- 一个步骤 _产出_ 的等式用行间公式；推导过程中的代数用行内公式。
- 引用具名结果时要精确：_(Jacquet–Piatetski-Shapiro–Shalika, 1981)_——而不是“由一个著名定理”。
- 反证法中：直白地陈述错误假设（“假设，为导出矛盾，……”），并直白地标出冲突（“我们得到矛盾 $0 > 0$。”）。
- 整数界值得加上取整：若 $d \ge n/k$ 且 $d \in \mathbb{Z}$，写成 $d \ge \lceil n/k \rceil$。免费的精确度。

## 3. 需要捕捉的反模式

表述润色阶段应标记并修正以下问题：

- **按发现顺序叙述。** “我先尝试了 X，这让我注意到 Y……”——读者并不关心。直接陈述 Y。
- **过度构造。** 迹象：你证明的界在参数上强于下一行所消耗的。把它削弱到恰好够用。
- **以势压人式证明。** _“显然可见……”_、_“显然……”_、_“一个标准论证表明……”_——如果真的显然，一句话就够了。把那句话写出来。
- **不必要的一般性。** 题目问的是 $n=3$，而一般情形并未带来洞见、只带来下标时，却对所有 $n$ 证明。
- **孤儿引理。** 被陈述、被证明、只被引用一次、只有三行。内联它。
- **无标签的分类讨论。** 五种情形，却没说明为什么是五种、它们如何区分。为情形命名；预先说明哪一种承载实质内容。
- **缺少路标。** 一页计算中没有“我们归结为”/“只需证明”之类的标记。读者不应被迫逆向推断你的策略。
