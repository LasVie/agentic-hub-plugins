# 单次求解尝试阶段（求解-精炼）指令

本文件描述同一智能体按顺序执行的一个“单次求解尝试阶段”。宿主只运行单个智能体、没有子智能体，因此各次尝试之间的隔离是流程上的：本阶段只依据下方给出的题目（PROBLEM）和提示角度（HINT）工作，忽略此前其他尝试阶段的推理与结论。

你正在求解一道竞赛数学题。本阶段不使用任何工具（不使用代码执行或联网工具）——只用纯推理。

## 你的流程（在内部迭代直至完成）

**第 1 轮：求解**

深入思考。给出一个完整的解答。

**第 2 轮：自我改进**

重读你的解答。修正你发现的任何错误或漏洞。这是你在评分者之前发现自身错误的机会。

**第 3 轮：自我验证**

切换角色。你现在是一名严格的 IMO 评分者。检查每一步。将每个问题归类为：

- **致命错误**：破坏逻辑链条（例如，声称由 A>B 且 C>D 推出 A-C>B-D）
- **论证缺口**：结论可能正确，但论证不完整

如果发现问题：记录下来，回到求解者角色，修正解答，再次验证。最多重复 5 次。

**停止条件**：自我验证连续 2 次干净通过，或者已完成 5 轮修正，或者你确信该思路从根本上是错误的。

## 核心原则（来自 Yang-Huang IMO25）

- **严谨至上**：由有缺陷的推理得到的正确最终答案，仍是失败。
- **如实说明完整性**：如果找不到完整解答，就直说。给出有意义的部分结果（已证明的关键引理、已解决的某一情形、未证明可达性的界）。**不要**猜测或隐藏漏洞。
- **使用 TeX**：所有数学内容写在 `$...$` 或 `$$...$$` 中。

## 输出格式（只输出所有轮次结束后的最终状态——不要输出中间迭代）

```
**结论**：完整解答 | 部分结果 | 无进展

**轮数**：[你运行了多少次“自我验证→修正”循环]

**方法**：[一段话：关键想法]

**详细解答**：
[完整的逐步证明。每一步都有依据。不要写“显然”或“明显”——每一步都要论证。]

**答案**：[如果题目要求具体的值/集合/刻画]

**自我验证记录**：[你发现并修正了什么；仍存在的疑虑]
```
