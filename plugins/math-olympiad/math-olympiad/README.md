# 奥数竞赛证明与对抗验证

插件 ID：`math-olympiad`　版本：1.0.0

求解、检查和整理竞赛数学证明（IMO、Putnam、USAMO、AIME、全国高中数学联赛等）。核心做法：

- **题意检查**：先列出可能的理解，避开“容易误读”的陷阱。
- **多角度纯推理求解**：依次从不同角度尝试，不靠数值枚举冒充证明。
- **清理后再验证**：验证阶段只看题面与清理后的证明，不看推理草稿。
- **模式化对抗攻击**：按 `references/verifier_patterns.md` 的清单逐条攻击（如“是否顺手证明了著名未解问题”“一行引理的一般形式是否有 2×2 反例”）。
- **非对称阈值与诚实弃权**：4 轮成立才确认、2 轮发现漏洞即否定；无把握时明确回答“没有可信的解答”。
- **表述整理**：验证通过后输出中文 LaTeX 证明；装有 xelatex + ctex 时可编译 PDF。

## 安装

在支持 Agent Plugin 的宿主中导入 `math-olympiad-1.0.0.zip`（外层含 `plugin.yaml`，内层 `math-olympiad/` 为插件本体）。插件仅包含一个技能 `skills/math-olympiad`，不包含工具、MCP 或模型配置，使用宿主当前的智能体与模型。

可选依赖：TeX Live 等发行版中的 `xelatex` 与 `ctex` 宏包，仅用于 PDF 排版；未安装时输出 LaTeX 源码。

## 使用示例

```
请用奥数竞赛证明与对抗验证技能求解：设正实数 a、b、c 满足 a+b+c=3，证明 a²+b²+c² ≥ 3。
请检查下面这份竞赛证明是否正确，并指出漏洞所在：……
```

答复包含：题意理解、结论（已证明 / 没有可信的解答）、证明或部分结果、验证记录。

## 限制

- 宿主只运行一个智能体。上游版本让互不知情的子智能体并行求解和投票验证；本版本改为**同一智能体分阶段执行**，验证阶段的“隔离”是流程约束，强度弱于独立上下文。答复中会如实注明。需要更强隔离时，可把清理后的证明粘贴到新会话中再验证。
- 结论的正确性取决于宿主模型的数学能力，本插件不保证解出题目，也不替代人工评阅。
- 求解与验证阶段禁止联网查找题目或答案。
- 上游 README 中的成绩数据依赖无法公开核验的评测，本包未收录，也不作任何成绩宣称。
