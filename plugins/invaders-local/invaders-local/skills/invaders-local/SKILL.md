# 星际防线

默认使用简体中文说明工具结果；用户明确要求其他语言时可以改用该语言。

1. 使用插件的实际 `create_invaders_game` 工具。`output_path` 是用户指定的已有目录中新建 `.html` 文件的绝对路径；可选 `seed` 为 0 至 2147483647 的整数。不要覆盖文件，不要替用户选择敏感系统目录。目录不存在时先请用户提供已有目录。
2. 报告真实返回的 `version`、网页路径与 SHA-256。提供可点击文件链接，让用户自行打开网页。工具不会自动启动浏览器或服务。没有调用工具时不得声称已导出或已游戏。
3. 开始游戏后先点击棋盘；左右方向键或 A/D 移动、空格射击、P 暂停或继续、Esc 暂停。切换窗口自动暂停。网页是独立游戏，不嵌入聊天窗、不监听模型回合。游戏本身无网络、无模型调用。
4. 同一浏览器和网页地址可自动续玩；恢复后保持暂停。存储被禁用时只能临时游玩。种子只保证相同按键和步数下的确定性，不保证真人每次得分一致。
5. 游戏结束、导出失败或工具不可用时如实说明，不要编造分数、波次、安装成功或人工测试通过。不要调用其他服务补造此游戏。
