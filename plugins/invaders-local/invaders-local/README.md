# 星际防线 v1.0.2

一个单人离线键盘射击游戏。插件的原生工具 `create_invaders_game` 导出自包含中文 HTML；用桌面浏览器打开即可玩，不需要 Node、账号、游戏服务器或额外 Python 包。WorkSwarm 自带的原生 Tool SDK 仅供工具注册使用。

## 安装与使用

Agentic Hub 规范 ZIP 使用 `<slug>/plugin.yaml` 加内层原生载荷。旧版本 WorkSwarm 如不支持此包装，使用交付说明提供的原生测试 ZIP；两个 ZIP 的内层文件逐字节一致。

在 WorkSwarm 的 Extensions → My Extensions → Create → Create from file 中选择适用 ZIP，确认安装。选择本插件，明确要求调用 `create_invaders_game`，传入已有目录中新文件的绝对路径，例如 `{"output_path":"/private/tmp/我的星际防线.html","seed":12345}`。路径已存在时会拒绝覆盖。请使用当前机器的真实已有目录。

不调用模型也可以从解压后的原生载荷运行：

```sh
python3 runtime/export_game.py /private/tmp/我的星际防线.html --seed 12345
```

工具返回版本、路径和网页 SHA-256。双击 HTML，点击“开始游戏”后点击棋盘：左右方向键或 A/D 移动、空格射击、P 暂停或继续、Esc 暂停。切换窗口或标签页自动暂停。击中敌人得分，清空一波进入下一波；敌人触底或生命耗尽时结束。护盾也会挡住自己的子弹。每 1500 分补充一条生命，最多五条。

“保存进度”将进度保存于当前浏览器；游戏运行时也定期保存。重新打开同一地址时恢复并保持暂停。“重新开始”从相同种子重置游戏，保留最高分。数据保存在浏览器本地，不发送到任何地方。存储无权限、被禁用或清理后不能保证续玩。不同文件地址、浏览器或端口的存档互不保证兼容；不支持旧 Claude 存档导入。

## 边界

- 不联网、不调用模型、不自动启动进程或浏览器；不拦截对话，不自动修改其他插件或配置。
- 游戏是独立网页，不是 WorkSwarm 内嵌窗；没有原 Claude 的回合暂停、推广提示或插件存储接口。
- 仅面向桌面键盘；移动触屏未适配。浏览器后台会暂停，性能较慢时游戏步进会变慢。
- 种子与相同按键/步数共同确定结果；不同真人操作不保证同分。
- 文件必须新建且父目录已存在，不接受经过符号链接的输出路径。
- 导出的网页含完整 MIT 许可；分享网页时请保留许可。
