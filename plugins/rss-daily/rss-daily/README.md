# 资讯晨报助手 1.0.0

真实工具插件：公开 RSS/Atom → 时间过滤与去重 → 中文编辑草稿 → 带出处日报 → 用户确认阅读 → 跨会话去重。

## 在 WorkSwarm 中使用

1. 在“扩展 → 我的扩展/插件”中导入本插件原生 ZIP，而不是把 ZIP 作为聊天附件。平台按钮可能随版本不同，以实际导入界面为准。
2. 点击“使用”，新建或重新打开选中本插件的对话。
3. 发送：“用演示材料生成中文晨报，展示全文后等我确认，不要替我标记已读。”
4. 检查三条带原始链接、来源和时间的演示日报。它们会明确标为**演示材料，非实时新闻**。
5. 阅读后另发一条：“我已经阅读，请确认当前这批演示日报。”然后再请求刷新，三条已确认材料不应重复出现。
6. 真实使用时发送：“读取过去 24 小时真实订阅源，生成带原文出处的中文日报，先不要确认阅读。”

不需要手动安装依赖，不使用 npm、pip、DSH 或 Conda。MCP 是 WorkSwarm 调用实际工具的接口，不是另一个需要你操作的平台。首次调用只创建用户数据目录，不下载或安装代码。

## 运行要求与数据

- macOS/Linux，宿主能够启动 `python3`，版本 3.9+。Windows 原生环境未支持；仅导入 ZIP 不代表系统已提供 Python。
- 使用 Python 标准库，以 stdio 提供五个 MCP 工具。无需网络即可运行演示；真实读取需要公网 HTTPS、正常 DNS 及有效 CA 证书。
- 默认真实订阅：少数派、Solidot、Hacker News。最多六个源，每源最多两条，每批最多十二条；支持最近 1–168 小时。无有效带时区发布时间的条目不纳入。
- 不下载全文；摘要依据订阅源提供的有限素材由智能体整理，不代表独立事实核查。来源错误会返回，不降低 TLS 校验。
- 状态默认在 `~/.cache/agentic-hub-rss-daily/{demo,live}/state.json`，文件权限为仅当前用户读写。只在明确确认后把选中的条目写入历史；去重窗口十四天、最多一千条。确认不是外部发送。
- 可由测试进程设置 `RSS_DAILY_STATE_DIR` 隔离测试数据，普通用户无需设置。缓存不是加密存储，不适合私密或登录订阅源。删除缓存会丢失历史，应由用户自行决定，不自动重置。
- 后台读取通常数秒，硬上限四十秒；异常退出后状态查询最晚六十五秒标为失败。请勿连续重新抓取。

## 故障处理

- 工具未连接：确认从扩展安装并在**新对话**选中插件，保留原始错误，不能用聊天中模拟日报代替。
- `python3` 不存在或版本过低：报告环境要求；本包不自动修改系统或全局环境。
- 某源失败：查看工具返回的 `source_results`。可以在完成当前批次后，明确要求替换真实订阅源；不要放宽证书或网络安全设置。
- 状态文件损坏：停止并保留原文件，不会静默覆盖；不要由智能体自动删除历史。
