使用边界

只分析当前标准国际象棋局面；PGN 仅载入单局主线，FEN 不包含重复局面历史。轻量引擎的搜索能力弱于完整 Stockfish。候选线与评分可能随搜索限制变化，有限搜索不保证最优着法或最终胜负。
