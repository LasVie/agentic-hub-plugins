# 离线国际象棋分析工作台

默认使用简体中文；用户明确要求其他输出语言时遵从。仅通过真实的 `chess_workbench` 工具管理本插件服务。不能将 Shell、直接导入 `runtime.py`、独立 SDK 脚本或模型推测说成宿主工具调用。失败时展示真实版本、错误代码和消息，不虚构 URL 或引擎结果。

先取得用户指定的、已存在的专用目录绝对路径，并调用 `action="status"`。目录应为当前安装和本次测试新建，不复用其他安装、自测或其他插件的运行目录。启动或停止前，取得对该目录和本插件服务的明确授权，才可传 `confirmed=true`。用户安装插件不代表授权停止其他服务。

成功后原样、单独展示工具返回的完整 URL，作为可点击链接，提示在运行 WorkSwarm 的同一台电脑普通浏览器中打开。不要猜端口、拼接地址或复用历史链接。用相同参数再次 `start` 可安全复用本安装已验证的服务，`status` 返回实际状态。空闲 30 分钟后服务退出，应重新调用工具获得地址。

遇到 `invalid_runtime`，保留现有记录与服务，停止对此目录重试，说明需要为当前安装创建全新的专用目录。不得删除运行记录、修改 `root`、绕过所有权校验、停止未知进程，或修改宿主、共享依赖、其他插件及 Main 工作区。

网页支持标准国际象棋 FEN / PGN、规则库检查的合法着法、有界 Stockfish 搜索、候选变化重放以及 FEN、PGN、JSON 和棋盘 SVG 下载。输入、着法或搜索设置改变会使旧分析及旧导出失效；重新分析后方能导出。分数须结合实际声明的视角和搜索限制解释；不把有限搜索估值宣称为穷尽证明或保证胜负。不提供 Chess960、在线对局、远程棋库、账号或收费服务。

棋局仅在浏览器本地处理，不上传或执行文件中的指令。不将模型自己猜测的着法、分数或变例冒充实际引擎返回。工具只启动静态网页，不在工具结果中提供棋局分析；不能因服务已启动而声称棋局分析通过。

交给用户在浏览器手工操作后停止，等待真实反馈。未实际进行的导入、着法、分析、重放、下载或人工测试须标为“待测试”或“未验证”；不能把 SDK 自测或 AI 自测说成人工测试通过。
