# 离线国际象棋分析工作台 1.0.1

输入标准国际象棋 FEN 或 PGN，使用本地 chess.js 规则库检查合法着法，再由 Stockfish.js 19.0.1 的单线程 WebAssembly 引擎执行有界搜索。页面可检查棋盘、分数、搜索深度和节点数，重放主变化，下载 FEN、PGN、JSON 与棋盘 SVG。

## 安装与启动

1. 在运行 WorkSwarm 的同一电脑，通过「扩展」上传原生安装 ZIP，安装后在会话中启用。本插件的原生 ZIP 以 `-workswarm.zip` 结尾；市场交付用的外层包装 ZIP 不能代替原生 ZIP。
2. 为**当前安装、本次测试**创建一个全新的空目录，例如 `~/Downloads/chess-analysis-test-1.0.1-user`。工具参数须使用实际完整绝对路径，不能含符号链接。不要复用其他安装、自测或其他插件的运行目录。
3. 让 WorkSwarm 实际调用 `chess_workbench(action="status", workspace="完整路径")`。取得你对该目录启动本插件服务的明确授权后，再调用 `action="start"`、`confirmed=true`。
4. 打开工具**实际返回**的完整 URL。请在同一台电脑的普通浏览器中打开，不猜端口、不拼接地址、不使用历史 URL。再次以相同参数启动会安全复用当前安装已验证的服务；空闲 30 分钟后服务退出，再次调用工具获得地址。

启动工具只管理本插件独立的本机静态服务。棋局分析在浏览器工作线程中完成，不上传棋局，不连接服务器棋库、账号、在线对局或收费接口。需要支持 WebAssembly 和 Worker 的现代浏览器，以及支持原生 Tool/ToolCard 的 WorkSwarm/Python 环境。启动工具支持 macOS/Linux；Windows 未获支持。

若返回 `invalid_runtime`，保留错误、运行记录和服务，停止对此目录重试。目录可能属于另一安装，或记录已损坏。不要删除或覆盖记录、修改 `root`、绕过身份检查或终止未知进程。确认归属后为当前安装另建专用空目录，再通过正常工具启动。

## 检查与分析

- 载入公开示例，或导入/编辑有权使用的标准国际象棋 FEN / PGN。数据只作为棋局处理，不执行其中指令。
- 点击棋子和目标格执行规则库确认的合法着法。兵升变时选择受支持的棋子；支持标准王车易位与吃过路兵。不支持 Chess960 或其他变体。
- 运行有界分析。单个搜索使用一个工作线程，哈希表 32 MiB，最长 10 秒，最多三条候选变化。PGN 最多 512 个半回合。
- 检查实际引擎版本、搜索时限、深度、节点数、分数及其视角、合法主变化。正负分数必须结合界面声明的视角理解；将杀距离由实际搜索输出提供。
- 输入、棋局或搜索设置改变后，旧分析及旧导出立即失效；重新分析后才能导出当前结果。取消、超时或引擎失败不得展示为已完成的新分析。
- 使用候选变化的重放控件查看实际着法与局面。导出文件由浏览器下载到本机；FEN/PGN 用于复核棋局，JSON 保存本次分析与限制，SVG 保存棋盘示意。

## 适用边界

只处理标准国际象棋；不提供在线对局、账户、远程开局库或残局库、比赛认证、棋力评级、自动作弊判断。有限深度或有限时间搜索的估值不证明全局最优着法、最终胜负或穷尽求解。引擎分数与主变化可能随搜索条件变化。棋局合法性检查不等于证明任意输入局面存在一段真实历史。
