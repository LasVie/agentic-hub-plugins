## 浏览器验收

以下为预期对照，不能冒充实际测试结果。页面应显示插件 `1.0.1`，引擎为 Stockfish.js `19.0.1` 的单线程 lite 构建。只支持标准国际象棋，不含 Chess960、联网对弈、账户、远程开局库或残局库。

| 测试 | 操作 | 预期 |
| --- | --- | --- |
| 真实搜索 | 载入初始局面，以 2 秒、最多三条候选线运行 | 显示引擎名称、实际深度/节点数、评价及合法主要变化；棋盘与当前 FEN 一致 |
| 一步将死 | 载入 `7k/8/5KQ1/8/8/8/8/8 w - - 0 1` 并运行 | 最佳着法 `g6g7`，SAN 为 `Qg7#`；逐步回放后黑王被将死，不编造额外着法 |
| 合法走法 | 初始局面点击 e2 后点 e4，再让黑方走 e7-e5；尝试初始 e2-e5 | 合法移动更新局面，非法移动不被执行；王车易位、吃过路兵和升变按标准规则处理 |
| 回放 | 选择另一条主要变化，前后回放 | 棋盘与所选变化步骤一致；回放不悄悄改写原始分析局面 |
| PGN | 导入或粘贴本地教学示例，应用后运行 | 合法主线得到最终局面并可导出；最多 512 个半回合，错误主线给出中文错误 |
| 输入变更 | 搜索完成后修改 FEN、PGN、棋盘或搜索设置，暂不重算 | 旧评价、变化与分析导出立即失效，不迟到展示旧线程结果；有效输入重算后恢复 |
| 取消 | 启动 10 秒搜索后立即取消，再运行短搜索 | 取消释放自己的工作线程，不保留未完成分析；后续正常恢复。若搜索先完成，应如实记录 |
| 错误恢复 | 输入 `not a fen`，再恢复有效局面；输入非法 PGN | 中文错误和代码可见，旧结果不可导出；恢复后实际搜索成功 |
| 特殊局面 | 检查已将死、逼和或子力不足的局面 | 明确区分终局与普通评价，不编造最佳着法或主要变化 |
| 四类下载 | 下载 FEN、PGN、分析 JSON 和棋盘 SVG，并打开 | 文本可重新导入；JSON 含当前输入、版本、搜索限制与真实分析；SVG 是当前棋盘，不含外部字体、图片或脚本 |

评价必须标明视角与单位，厘兵不等于胜率。有限时间搜索不是穷尽最优性或未来胜负保证；将死分数也应以实际合法变化核对。32 MiB 是引擎 Hash 设置，不是整个浏览器进程的内存上限。FEN 输入支持范围校验不证明该局面的完整历史可达性。
