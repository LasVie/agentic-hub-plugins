# 离线力学实验室 v1.0.0

编辑二维刚体与距离约束，在浏览器中使用随包 Matter.js 0.20.0 进行真实离线计算。查看自由落体、碰撞与摆动的逐帧位置、速度和轨迹；保存初态JSON并导出完整采样CSV。没有外网请求或模型调用，不能替代工程安全验证。

## 安装与启动

需要 macOS/Linux、Python 3.10+、支持原生 Tool/ToolCard 的 WorkSwarm 和桌面 Chrome。宿主已有 openJiuwen SDK；插件不安装依赖、不修改宿主。Windows 未支持。浏览器运行引擎，使用时无需 Node.js。

使用宿主「扩展」的本地 ZIP 导入/安装功能。若宿主只接受根目录 manifest.json，使用同版本 `-workswarm.zip`；其内层运行文件与标准包装完全相同。不要将ZIP解压后覆盖其他插件。

在对话中选择本插件，提供一个已存在、无符号链接的专用工作目录，明确授权后调用：

```json
{"action":"start","workspace":"/绝对路径/力学实验工作目录","confirmed":true}
```

工具名称为 `local_mechanics_lab`。随后以同一目录调用 `action=status`，核对 `ok`、插件 `version=1.0.0`、`engine_version=0.20.0`（界面计算结果中显示）、`running`、`session_id` 与工具实际返回的完整 URL。在同一电脑的独立 Chrome 标签页打开 URL。地址含本机会话凭据，请勿分享，截图隐藏地址栏。

工具只管理服务，不进行模拟。没有浏览器计算结果时，不能声称已取得运动数值。只读status不需要confirmed；关闭使用action=stop及confirmed=true。服务空闲30分钟关闭；保存场景仍保留。

## 实验步骤

1. 选择「自由落体」「等质量碰撞」或「固定点单摆」。调整物体位置、质量、速度、摩擦和恢复系数；通过物体表单添加矩形/近似圆，通过约束区域添加中心间距离或固定点约束。
2. 点击「计算实验」。工作线程以1/120秒固定步长求解；成功后才启用播放、时间滑块与CSV。动画是实际采样回放，可暂停、回首帧、切换所选物体并观察数值和纵向轨迹。
3. 修改输入会立即清除旧结果。拖动只编辑初始位置；已有结果时先点「编辑初始场景」。再次计算后比较变化。
4. 保存只写入指定工作目录的 `.offline-mechanics-lab/scene.json`；已有场景需明确确认替换。读取/导入仅恢复初始条件，必须重新计算。JSON导出及CSV由浏览器下载，不自动覆盖用户文件。
5. CSV每行是一个物体在一个采样时刻的实际数值。3秒、两个物体的碰撞实验应为361帧、722数据行（不含表头）。

## 重要边界

- 世界坐标1000×650用于显示，Y向下为正；坐标、质量为自定义单位。重力为单位/秒²，速度为单位/秒。最多32物体、16约束、10秒；输入时长需为1/120秒整数倍。计算超过8秒终止，不提供伪结果。
- 恢复系数是法向相对速度系数，不是能量保留比例。参考一维碰撞锁定转动：初速度±100、质量各1时，恢复系数1的最终速度应接近∓100；两物体都改为0.5时接近∓50。
- **Matter.js限制**：自由转动矩形多点碰撞可能有明显额外速度损失（相同参考场景解除转动锁定，约±45.45而非±100）。低速接触还受静止阈值影响；不能把所有恢复系数1的碰撞描述为理想弹性碰撞。圆是多边形近似。空气阻尼沿用引擎基准帧系数；约束与接触会有数值误差，高速小物体可能穿透。没有通用能量守恒保证。
- 不支持任意代码、凹形状、SVG、流体、3D、传感器硬件或现实安全验证。原生工具不会替用户自动开展浏览器实验。服务启动、格式检查和自测不等于用户人工测试通过。
