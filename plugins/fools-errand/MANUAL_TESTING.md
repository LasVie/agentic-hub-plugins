## 包与安装

规范包：`releases/agent-plugin/fools-errand/1.0.0/fools-errand-1.0.0.zip`，SHA-256 `5228e50c52c92de8a1b578592834007651b73f919ed941ff56386a277954fe7e`。

WorkSwarm 原生伴随包 SHA-256：`f62d3ba3d1c4714bfd91538605090e6d4abf1f2b2cb3be87bc851a6291e38b21`。可从仓库根目录运行以下开发侧命令生成，输出目录已有不同内容的同版本档案时会拒绝覆盖：

```sh
python plugins/fools-errand/build_local_test.py releases/agent-plugin/fools-errand/1.0.0/fools-errand-1.0.0.zip .research/fools-errand-native
```

开发命令所需 PyYAML 来自仓库开发依赖，不是用户游玩依赖。通过 WorkSwarm 扩展管理支持的 ZIP 导入入口安装原生伴随包，核对中文名与版本，点击使用并选择已有可用模型。不要仅把 ZIP 当普通聊天附件上传。本插件没有 MCP、安装脚本、外部服务或额外运行依赖，不需要 Conda、Node、npm 或 API 密钥。

## 按回合发送到 WorkSwarm 聊天框

下面不是终端命令；每次等待实际回复后再发下一条。游戏选项是动态生成的，不把固定字母绑定到固定行动。

### 1. 中文开局

```text
开始玩当前选中的《糊涂勇者历险记》1.0.0，请用中文主持。
显示农场、巫师撞车、起火和误认勇者的开场，以及初始数值和 A/B/C/D 选项。
给出选项后停止，等我选择，不要替我行动或连续推进多回合。
```

预期：金币 3、体面 5、奶酪 0，中文开场和自由行动入口；等待玩家。

### 2. 明确询问巫师

```text
我只向巫师询问：我究竟被选中做什么？请读出卷轴上的三项任务。
我还没有选择救火或安抚动物，不要替我执行这些行动。
只推进这一回合，显示当前数值、变化原因及任务状态，然后等我选择。
未完成的任务不要使用删除线。
```

预期：回应提问、公布三项未完成任务，不替玩家执行其他选项。数值若变化，应有本次实际行动依据。

### 3. 自由行动

```text
我不选字母。我先安抚农场的动物，再请邻居暂时照看庄稼和动物。
先商量，不要替我直接出发，也不要一次完成所有任务。
```

预期：承接自由输入和具名人物，通过交谈安排，允许邻居提出条件。

### 4. 只查看状态

```text
暂停推进剧情。请列出当前金币、体面、奶酪、物品和三项任务状态。
对照上一回合说明变化；只是查看，不要重置数值、发奖励、消耗物品或自动完成任务。
```

预期：状态可与已发生行动逐项核对，不凭空增加物品或完成任务。

### 5. 提前回家

```text
我决定不继续卷轴任务了，现在回家，结束这一局。
请给出回家的结局、最终数值、物品、任务真实完成情况和结识的朋友。
不要把未完成的任务说成完成，结局后不要继续给行动选项。
```

预期：允许未通关结束，说明真实任务状态，停止推进。

### 6. 新对话缺少旧局状态

另建并选中同一插件的对话，不粘贴旧局记录：

```text
继续我在另一个对话玩过的《糊涂勇者历险记》。
这个新对话没有旧局状态，请不要搜索历史记录或读取文件。
先说明能否可靠恢复，不要编造我的金币、物品或已完成任务，也不要未经我确认就开新局。
```

预期：如实说明无法可靠恢复，等待用户决定，不伪造存档。

### 7. 普通请求不误触发

```text
先不玩《糊涂勇者历险记》。只解释什么是文字冒险游戏，用两句话回答。
```

预期：正常解释，不开局、不输出游戏数值或行动选项。
