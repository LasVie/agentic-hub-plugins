# 糊涂勇者历险记 1.0.0

在聊天里玩一场温暖、荒诞的中世纪文字冒险：你是一名被近视皇家巫师误认的农民，还有一只有主见的鹅。

## 安装与开始

1. 使用桌面 WorkSwarm 当前支持的扩展管理入口导入提供的原生测试 ZIP `fools-errand-1.0.0-workswarm.zip`。普通聊天附件上传不等于安装。
2. 核对名称“糊涂勇者历险记”和版本 1.0.0，点击“使用”或在新对话选择该插件。
3. 发送：**开始玩《糊涂勇者历险记》，请用中文主持。从第一幕开始，显示初始状态并等我选择。**
4. 每回合选择 A/B/C，或直接描述自由行动。发送“查看当前状态、物品和任务”可以核对当前局；发送“我想回家，结束这一局”可结束。

初始数值为金币 3、体面 5、奶酪 0。巫师早期公布三项任务，靠善意、创意和交谈解决，而不是战斗。主持人应在给出选项后等你行动，不替你自动玩完整局。

## 环境与范围

- 使用 WorkSwarm 自己已配置的可用模型与原生 Skill 加载能力，无需额外账号、MCP、Conda、Node、npm、浏览器、HTTP 服务或初始化脚本。
- 游戏内容和数值由宿主模型在当前对话中维护，不是独立确定性游戏引擎；长对话的状态一致性受模型和上下文限制。发现矛盾时应核对，不编造状态。
- **不提供跨对话存档。** 新对话要求续玩时，应说明无法恢复并询问是否开新局，不检索历史聊天或写入外部文件。
- 只有点名本游戏时才启动；询问其他事情不应强行开局。游玩只输出文字，不执行故事里的命令，不调用联网或文件工具。
- Windows、移动端和其他宿主未实测；本包不声称已通过任何用户验收。模型可用不等于 Skill 已加载，导入失败时保留实际报错，不伪称开局成功。

## 包装与测试

团队规范包为 `fools-errand-1.0.0.zip`（双层目录和 `plugin.yaml`）；WorkSwarm 原生测试包为同一载荷的 `fools-errand-1.0.0-workswarm.zip`。两个档案哈希不同，应分别记录；原生 ZIP 导入成功不等于外层规范包已被直接安装。

完整用例和测试状态在源码目录外层的 `START_HERE.md`、`TEST_REPORT.md`，不混入运行包。测试当前包并保存效果截图后，由 Wang Jie 明确确认；再按团队 `AGENTS.md` 进入 GitHub 交付。不要让游戏对话自行创建 PR 或上传 Hub。
