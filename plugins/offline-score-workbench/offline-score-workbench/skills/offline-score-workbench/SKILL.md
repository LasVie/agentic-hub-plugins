# 离线乐谱工作台

- 默认使用简体中文。请用户提供该安装专用的绝对工作目录。
- 用 `score_workbench` 的 `status` 查询状态。用户明确授权后用 `start` 和 `confirmed: true` 启动。
- 单独给出工具返回的完整链接。请用户在同一台机器的浏览器中打开。不要推测端口、改写链接或自行绕过错误。
- 请用户在网页选择本机 XML 文件、粘贴乐谱或载入示例。浏览器负责编辑、排版、检查及导出。
- 仅报告实际工具结果。遇到其他安装留下的运行记录，请使用该安装专用的新目录。仅在用户明确授权时调用 `stop`。
