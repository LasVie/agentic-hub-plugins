# 离线乐谱工作台 1.0.0

使用随插件分发的 Verovio 6.4.0 在本机浏览器排版乐谱。可编辑 XML、切换谱页、检查音符，并导出当前页 SVG 或整份 MIDI。

## 安装与启动

1. 在 WorkSwarm 的「扩展」中导入原生安装 ZIP，安装并启用「离线乐谱工作台」。
2. 选用本次安装专用、已经存在的绝对工作目录。用 `score_workbench` 的 `status` 查询状态。
3. 在确认启动后，调用同一工具，参数为 `action: start`、`workspace: <绝对路径>`、`confirmed: true`。在同一台电脑的现代浏览器打开工具返回的完整地址。
4. 关闭浏览器标签页后服务会在空闲 30 分钟后退出。如需立即关闭，请先确认，再对同一目录调用 `stop`。

## 使用

- 点击「载入示例」，再点「排版乐谱」。《晨光练习曲》展示两个声部、休止符、升号和跨小节延音线。
- 选中第一个旋律音符 C4。示例显示 MIDI 音高 60、起始 0 毫秒、时长 500 毫秒。
- 将第一处 `<step>C</step>` 改为 `<step>D</step>`。旧谱面和导出会立即失效。重新排版后，该音符显示 MIDI 音高 62。可用「恢复导入原文」撤回编辑。
- 用「选择文件」载入未压缩的 UTF-8 MusicXML 或 MEI，也可以粘贴 XML。分页按钮仅在有对应谱页时启用。
- 「导出本页 SVG」下载当前谱页，「导出 MIDI」下载整份乐谱的演奏事件。源文件保持原样。

## 适用范围

本版支持有界的 MusicXML `score-partwise` 和 MEI 基础记谱子集，包括普通音符、休止、拍号、升降号和延音线。复杂版式、记号和重复演奏语义可能与原编辑器不同。MIDI 的时序取自引擎，延音线的后续音符可能没有独立事件。

每次最多 192 KiB、512 个音符、128 个小节和 16 页，浏览器排版限时 12 秒。请使用纯 XML 导出。拒绝文档类型声明、外部处理指令、外部资源和不支持的元素。暂不支持 MXL、PDF、扫描识别、图形音符编辑或音频合成。

插件只向本机浏览器提供静态资源。乐谱文件在浏览器中读取和处理，导出通过浏览器下载。使用不同安装时请选择新的专用工作目录。
