# 离线乐谱工作台 1.0.0 手工测试

1. 打开隔离的 WorkSwarm http://127.0.0.1:6395/ ，在「扩展」上传本任务的 `offline-score-workbench-1.0.0-workswarm.zip`，安装并启用。若该隔离实例已安装，可先核对版本再测试，或通过扩展界面重新导入同一 ZIP。
2. 为此安装选择新的专用工作目录。用 `score_workbench` 查询 `status`，再明确授权 `start`，传入 `confirmed: true`。用普通浏览器点击工具实际返回的完整地址。再调用一次 `start`，应复用相同地址。此隔离实例不带模型凭据，若从聊天调用，须使用您自己的授权配置。
3. 点击「载入示例」→「排版乐谱」，核对中文标题、两个声部、五线谱、休止符、升号和延音线。点击第一个旋律音符，应显示 60 / 0 / 500。
4. 下载 SVG 与 MIDI。将第一处 `<step>C</step>` 改为 `<step>D</step>`，观察旧结果和导出失效，再排版并检查该音符变为 62。恢复原文再排版，应回到 60。
5. 选择测试夹具 `tests/fixtures/双音符.mei`，核对两个音符及其检查结果。输入 `<mei` 或含外部 DTD 的 XML，确认中文报错且无导出，再载入示例确认恢复。
6. 请确认测试的是 1.0.0 的确切 ZIP，并保存原始截图。建议包含扩展名称与版本、正常排版和音符检查、编辑后结果及错误恢复。
