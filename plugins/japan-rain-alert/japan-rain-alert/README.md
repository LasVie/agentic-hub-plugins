# 日本雨量预警助手 1.0.0

用五个原生只读工具查询日本任意位置的天气灾害相关数据：最近观测站的雨量、所在市町村的警报与注意报、正上方 1 km 网格的解析雨量和キキクル（危险度分布）警戒级别，以及估算的暑热指数（WBGT）。无需账号、API Key 或登录，默认用简体中文整理。

> 非官方工具：与气象厅、国土地理院、环境省及邮编服务 zipcloud 无关联、未获其认可。速报值和估算值仅供参考，防灾、停工等决定请以气象厅发布的信息和现场实测为准。

本插件改编自 [okura1234/claude-plugins](https://github.com/okura1234/claude-plugins) 的 `amedas-rain`（MIT，版权 okura1234）：警报代码表、观测点数据读取方式、网格色块色阶、暑热指数公式和技能流程来自它，已翻译为中文并改为原生工具。PNG 解码、参数校验、限流、预报区解析等为本团队独立编写。上游依赖的 Pillow 已被标准库实现取代，所以**不需要安装任何东西**。许可与改动见 `THIRD_PARTY_NOTICES.md`。

## 安装与启用

在 WorkSwarm 的扩展导入入口选择 **native.zip** 测试包，安装后开启“日本雨量预警助手”，新建对话，再按下面的提示测试。仓库 `releases` 下另有带市场外层的交付 ZIP；两者内部运行文件相同。

要求 Python 3.11+ 和兼容的 openjiuwen 宿主，以及能访问下面“数据来源”中各网站的网络。只使用 Python 标准库，没有额外依赖；不自动安装依赖、不修改宿主配置、不读取或保存任何凭据，也不向磁盘写入任何文件。

## 五个工具

| 工具 | 用途 |
| --- | --- |
| jma_locate | 把邮编、地址、经纬度或观测站名解析成坐标，给出所属市町村、气象厅预报区和最近的雨量/气温湿度观测站 |
| jma_rainfall | 最近雨量观测站的最新 10 分钟/1 小时/24 小时降水量，以及最近 1～7 天的日降水量（速报值） |
| jma_warnings | 所在市町村当前发布中的警报、注意报（含级别），并附气象台展望原文（日语，需翻译） |
| jma_site_rain_risk | 正上方 1 km 网格的解析雨量档位，以及キキクル表面雨量、流域雨量、土壤雨量三个警戒级别 |
| jma_wbgt | 用最近的气温湿度观测站数据估算暑热指数（WBGT），4～10 月再用环境省官方实况做日射修正 |

位置（`place`）可以是邮编（`100-0005`）、经纬度（`35.681,139.767`）、日语地址（`長野県松本市丸の内3`）或观测站名（`東京`），都道府县名（日文或简体中文，如“冲绳”“東京都”）会按府县厅所在地的观测站处理并在结果里说明，想查县内其他地点请给邮编、地址或经纬度；也可以直接用 `station_code` 指定气象厅 AMeDAS 观测站代码。直接传入字段，不要套 arguments。观测站名匹配到多个站点时，工具返回候选，不会替你挑。

## 试用

- 查询东京最近 4 天的降雨量，并说明数据来自哪个观测站。
- 邮编 100-0005 所在的区现在有警报或注意报吗？
- 坐标 35.681,139.767 正上方 1 km 网格现在的降雨和土砂灾害警戒级别是多少？
- 估算东京今天 9:00 和 13:00 的暑热指数。
- 查询北海道旭川现在的警报和气象台展望，用中文概括。
- 查询邮编 999-9999 的雨量（应得到“查不到邮编”的明确错误）；再查询英国伦敦的坐标 51.5,-0.12（应得到“在日本以外”的明确错误）。

## 数据来源与隐私

| 服务 | 用途 | 发送的内容 |
| --- | --- | --- |
| 气象厅（jma.go.jp） | 观测站表、10 分钟降水量、警报与注意报、展望、解析雨量与キキクル瓦片、预报区表 | 观测站代码、时间、瓦片编号，不含个人信息 |
| 国土地理院（msearch.gsi.go.jp、mreversegeocoder.gsi.go.jp） | 地名检索（地址转坐标）、逆地理编码（坐标转市町村） | 你输入的地址，或坐标 |
| zipcloud（zipcloud.ibsnet.co.jp） | 邮编转地址 | 你输入的邮编 |
| 环境省热中症预防情报网站（wbgt.env.go.jp） | 暑热指数的日射修正（仅 4～10 月） | 观测站代码、年月 |

本插件没有自己的服务器，不收集、不保存你的输入；运行中只在进程内存里缓存最近 5 分钟的公开数据（观测站表、区域表缓存 24 小时），邮编查询不缓存。所有请求都经过本插件内置的限流，达到上限时直接报错而不是继续请求。气象厅、国土地理院、环境省的内容按其“公共数据利用规约（第 1.0 版）”使用：出典为各机构网站，经本插件编辑、加工后呈现，并非这些机构发布的内容。zipcloud 按其 API 利用规约使用，该服务可能随时限制访问。

## 做不到的事

- 日本以外的位置没有数据，工具会明确拒绝。
- 不预测降雨、不预测警报何时解除，不提供避难或防灾指挥建议。
- 雨量是最近观测站的值，不是你所查地点本身的降水量；1 km 网格只有档位，不是精确数值。
- 暑热指数是估算值，不是实测，也不是环境省发布的数值。
- 速报值只覆盖最近约 10 天；更早的统计请查气象厅的确定值。
