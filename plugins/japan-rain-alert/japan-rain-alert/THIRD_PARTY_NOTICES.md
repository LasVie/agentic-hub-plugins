- 气象厅（https://www.jma.go.jp/）：观测数据、警报与注意报、展望、解析雨量与キキクル瓦片、区域表，运行时匿名访问。内容按气象厅网站声明的“公共数据利用规约（第 1.0 版）”使用：使用时须注明出典（出典：气象厅网站），经编辑、加工的须另行注明，且不得表述为国家（气象厅）制作。本插件的每个结果都带有 `attribution_zh` 来源与加工说明。
- 国土地理院（https://msearch.gsi.go.jp/ 、https://mreversegeocoder.gsi.go.jp/）：地名检索与逆地理编码，运行时匿名访问；同样适用其网站声明的公共数据利用规约（第 1.0 版）和出典、加工注明要求。
- 环境省热中症预防情报网站（https://www.wbgt.env.go.jp/）：仅用于暑热指数的日射修正，读取其公开的实况 CSV；其“ご利用にあたって”写明按公共数据利用规约（第 1.0 版）使用，须注明出典。
- zipcloud（https://zipcloud.ibsnet.co.jp/）：邮编转地址的公开 API，按其《郵便番号検索API利用規約》使用：运营方可随时停止服务或限制访问次数，且要求展示最新信息，因此本插件不缓存邮编查询结果；规约禁止“只为提供该 API 功能而建的站点”使用，本插件是天气与警报工具，邮编转换只是定位的一种入口，且查不到时可改用地址或经纬度。
- 本插件不附带任何气象数据、地图、图片或标志。
