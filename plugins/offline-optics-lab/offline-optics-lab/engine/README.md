# 有界离线光学引擎

本目录是 Ray Optics Simulation v5.4.0 的选定数值算法移植，不是完整网页应用。可读的 ES 模块就是发布源码，无编译产物、npm 安装、在线服务或模型调用。保留的上游原文和 Apache-2.0 许可见 `../licenses/ray-optics/`；具体改动见 `../THIRD_PARTY_NOTICES.md`。

需要已安装的 Node.js 18 或更新版本。运行 `node engine/cli.mjs`，从标准输入接收一个 JSON 请求，从标准输出返回一个 JSON 结果：

```json
{"action":"simulate","scene":{"schema_version":1,"title":"光线测试","objects":[{"id":"光源","type":"SingleRay","p1":{"x":100,"y":100},"p2":{"x":200,"y":100}},{"id":"探测器","type":"Detector","p1":{"x":400,"y":20},"p2":{"x":400,"y":200},"bins":10}]}}
```

`action` 可为 `simulate`（默认）或只校验的 `validate`。所有未知字段均拒绝，包括远程 URL、背景图、模块、公式、GRIN 设置和上游完整场景格式。缺省参数可以省略，不能用 `null` 替代数值或布尔值。

## 场景格式

`schema_version` 固定为 `1`；`title` 是 1—100 字符的标题；`objects` 含 1—32 个对象，至少一个光源。每个对象需要唯一 `id`（以字母或汉字开头，最多 32 个字母、数字、下划线或连字符）。坐标是有限数值，范围 −2000—2000；两端点距离至少为 1。默认画布为 1000 × 650，画布外的对象仍参与计算。

| type | 几何与额外参数 | 含义 |
| --- | --- | --- |
| `SingleRay` | `p1`、`p2`；`brightness` 默认 1，范围 0.001—10 | 从 p1 沿 p1→p2 发射一条光线 |
| `Beam` | `p1`、`p2`；`brightness` 同上；`rayCount` 默认 9，整数 1—64 | 沿线段均匀中点采样；方向为 `(p2.y-p1.y, -(p2.x-p1.x))`；总相对功率不随采样数改变 |
| `Mirror` | `p1`、`p2` | 有限长、理想双面平面镜 |
| `IdealLens` | `p1`、`p2`；`focalLength` 默认 100，绝对值 1—2000 | 理想薄透镜；正值会聚、负值发散 |
| `PlaneGlass` | `p1`、`p2`；`refIndex` 默认 1.5，范围 1—3 | 无限直线边界；`cross(p2-p1, 点-p1)>0` 的半平面为玻璃。屏幕坐标 y 向下；从左到右画边界时，下方为玻璃 |
| `Glass` | `path` 为 3—16 个顶点，闭合边隐含；`refIndex` 同上 | 简单直边玻璃多边形，顶点不重复、边不共线、不自交。顺逆时针均可 |
| `Detector` | `p1`、`p2`；`bins` 默认 20，整数 1—100；`twoSided` 默认 true | 不吸收光线，统计有向相对功率与沿线分布；false 只接收 `cross(光线方向,p2-p1)>0` 的光线 |

光源总采样数不超过 256。半平面玻璃不能与其他玻璃同时使用。多个多边形玻璃必须互不相交、嵌套或接触。光源采样点不能落在光学边界或探测器上。光线直接命中共同边界或玻璃顶点会报错，不猜测法线。

## 输出与边界

成功结果含 `ok`、`version`、规范化 `scene`、`segments`、`detectors`、`stats` 与中文 `warnings`。段记录 `from`、`to`、`brightness`、`ray_id`、`source_id`、`object_id` 和对象 `type`；边界段可含 `interaction`。没有后续交点时，显示线段向前延伸 6000 个单位（`type=escape`），并不表示光线在该处物理终止。

探测器的 `power`、`normal`、`shear` 与 `binData` 保留上游有向约定，均是相对单位；不是瓦特或牛顿。`binPositions` 是各分箱起点距 p1 的距离，`binSize` 是分箱长度。端点命中计入最后一个分箱。反向传播可使功率为负；多次穿越会多次计数，不等同于独立光子数。光束离散采样的分箱图不是波动光学衍射或相干结果。

每条分支最多 80 次交互、每次求解最多 5000 段、引擎墙钟时间最多约 3 秒；低于 1e−6 相对功率的分支不再传播。被丢弃的相对功率累计到 `stats.lost_power`，并设置 `stats.truncated=true`、给出中文提示。不得把截断结果解释成完全收敛。数值交点任一坐标绝对值超过 1,000,000 时拒绝；发生错误不返回过期或部分成功结果。CLI 输入上限 128 KiB，外层服务另有限制与进程超时。

仅支持理想二维几何光学：镜面反射、Snell 折射、s/p Fresnel 功率分裂、全内反射与理想薄透镜。不包含色散、波长、衍射、干涉、偏振输入编辑、吸收、曲面/弧线、GRIN、公式求值、表面合并、器件损伤或工程/激光安全认证。入射光默认等量 s/p 分量。此引擎不读取或写入文件、不连接网络；保存与导入由插件自己的受限服务处理。
