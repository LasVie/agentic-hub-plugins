# 离线光学实验室

默认使用中文。用户明确要求其他语言时可切换解释语言，保留真实API键。所有数值结论必须来自本插件实际工具返回；不得用理论公式、模拟文本或自行编写的替代程序冒充执行。

## 工具与边界

- `simulate_optical_scene({scene, node_path?})`：只读运行真实有界引擎，不写文件、不联网。`ok`、`version`、`stats`、`detectors` 和光路预览是实际结果。明确区分理论预期与测得结果；同时报告截断标志。失败时展示原始错误，不猜测数据。
- `local_optics_lab({action, workspace, confirmed?, node_path?})`：选择已存在的专用绝对目录；`start` 或 `stop` 需要用户明确授权，随后设 `confirmed=true`。`status` 不需确认。只在目录中写入本插件私有状态。不要替用户删除记录或接管另一个安装的会话。
- 返回的完整URL仅用于同一电脑的独立浏览器。不要编造端口/链接、把token公开或把普通HTML预览器视作交互运行成功。启动成功和数值工具成功不等于用户已经完成浏览器人工测试。
- 需要已有 Node.js18+；缺失则如实说明，可由用户提供已安装的 `node_path`，不要安装软件或改变宿主配置。禁止付费模型调用、修改其他插件或宿主代码。

## 场景结构

只接受本插件受限结构，不接受上游任意项目、JS、URL或模块：

```json
{"schema_version":1,"title":"平行光束聚焦","objects":[
  {"id":"光束","type":"Beam","p1":{"x":100,"y":230},"p2":{"x":100,"y":420},"brightness":1,"rayCount":9},
  {"id":"透镜","type":"IdealLens","p1":{"x":400,"y":150},"p2":{"x":400,"y":500},"focalLength":150},
  {"id":"探测器","type":"Detector","p1":{"x":550,"y":100},"p2":{"x":550,"y":550},"bins":20,"twoSided":true}
]}
```

场景对象的ID必须唯一。`SingleRay` 从p1朝p2传播；`Beam` 从p1–p2线段离散发射，方向为 `(p2.y-p1.y, -(p2.x-p1.x))`；brightness为总相对功率。镜面和理想透镜是p1–p2线段；焦距可正可负，绝对值至少1。玻璃折射率1–3。`Glass` 使用 `path:[{x,y},...]` 而非p1/p2，首尾不重复。半平面方向和所有边界见随包 `engine/README.md`；不要猜测玻璃一侧。探测器为透射式，读数有方向符号。

更多已知输入在 `engine/examples.json`。使用真正的输入构造场景，不将预期结果嵌进输入。可读取README/示例说明能力，但执行必须调用工具。

## 推荐流程

先执行只读追迹并检查版本1.0.0；明确报告探测器命中数、相对功率、离散采样与截断。需要交互实验时取得本机服务启动授权，调用start后再用相同目录调用status核对session_id。指导用户在独立浏览器改焦距/折射率/几何位置并重新计算，保存/刷新，导出/重新导入JSON和CSV。清楚区分本次已执行的工具检查、界面观察及尚待用户执行的操作。

最多32对象、总256条发射光线、5000段、80次交互。拒绝非有限数值、不支持类型/URL、接触或嵌套玻璃和不唯一边界。仅理想二维几何光学；不推断波动、三维、实际功率、真实硬件安全或工程认证。用户报告人工测试后再记录其实际确认，不得自行宣布通过或交付发布。
