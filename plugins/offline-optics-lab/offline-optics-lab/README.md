# 离线光学实验室 1.0.0

编辑二维光学场景，观察真实计算的反射、折射、全内反射与理想透镜光路，并读取探测器的相对光强分布。光路来自随包 Ray Optics 数值算法移植，不是语言模型绘制的猜测图。

## 环境与安装

- macOS/Linux、Python 3.11+、支持原生 `Tool/ToolCard` 的 openJiuwen/WorkSwarm、桌面 Chrome。
- 需要**已安装的 Node.js 18+**；没有 npm 或其他运行时库依赖。依次读取现有 PATH、常见 Homebrew/本机路径，以及已存在的 Codex Node 运行时；也可向工具传入 `node_path` 绝对路径。插件不会安装或更新 Node、改写 PATH 或宿主文件。
- 在 WorkSwarm「扩展」中导入本插件的原生测试 ZIP，再安装启用。Agentic Hub 市场包装 ZIP 与原生 ZIP 的内部载荷相同，但外层布局不同；不要把市场包装当成原生目录。
- 本插件只包含自己的工具、技能、引擎和网页。无需改动宿主、SDK、其他插件或模型配置，也不会请求模型/API 服务。

## 使用

1. 只读追迹：调用 `simulate_optical_scene`，传入 `scene`；完整结构见 [引擎说明](engine/README.md) 与 `engine/examples.json`。
2. 选择一个**已存在、属于当前安装的专用目录**，明确授权后调用 `local_optics_lab`：`action=start`、`workspace=绝对路径`、`confirmed=true`。
3. 在同一台电脑的**独立浏览器标签页**打开工具实际返回的完整 `url`。WorkSwarm 产物预览可能禁止脚本；不要修改宿主预览器。
4. 选择示例或编辑对象：拖动/修改位置、端点、折射率、焦距或光源，再点击运行。修改后旧光路和导出数据失效，必须重新计算。
5. 「保存场景」仅更新该专用目录的 `.offline-optics-lab/scene.json`；刷新或读取已保存恢复场景。JSON 导出/导入用于携带场景，CSV 导出用于检查本次探测器数据。
6. `action=status` 无需确认；关闭时明确授权 `action=stop, confirmed=true`。空闲约30分钟自动关闭，保存场景保留。

不同安装位置或版本不要共用运行会话目录。发现外来会话时插件会拒绝接管并保留原记录；请选新目录，通过导出/导入迁移场景。完整本机URL含访问凭据，勿公开；测试截图请隐藏地址栏。

## 能力与限制

- 支持 `SingleRay`、`Beam`、`Mirror`、`IdealLens`、`PlaneGlass`、`Glass`、`Detector`。二维坐标、焦距和相对光强采用一致的任意单位；不是实际瓦特或长度标定。
- 上限32对象、每束64条光线、总发射256条、每次5000段、每条最多80次交互；多边形3–16个顶点。引擎有时间限额，外层进程超时10秒。低功率分支和达到限额的光线会明确计入截断；应检查 `stats.truncated` 和 `lost_power`。
- 折射包含菲涅耳反射/透射分支；探测器透过光线并输出带方向符号的相对功率、分箱分布。读数随端点方向改变符号，不是吸收屏幕或校准传感器。光束的 `brightness` 是总相对功率，`rayCount` 是离散采样数。
- 支持互不接触的均匀多边形玻璃；不支持相交/嵌套/接触玻璃，半平面玻璃不能与另一玻璃并用。命中重合最近边界或多边形顶点会拒绝计算，避免猜测法线。
- 不支持上游任意JSON、公式、脚本、模块、背景URL、GRIN、曲面、衍射/干涉、三维光学、实际镜头像差、波动光学、硬件安全或工程认证。不得把本工具结果用作这些能力已经实现的证据。
- 原生工具返回前12段光路预览，并明确标记预览截断；完整有界光路在本机界面中显示。输入错误、资源缺失或超时不会生成替代结果。
