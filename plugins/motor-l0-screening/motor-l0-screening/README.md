# 电机方案粗筛 1.0.0

本地生成电机方案矩阵、执行物理规则校验并按公式估算排序；仅用于相对粗筛，不是工程认证或仿真结论。

## 安装与使用

WorkSwarm 桌面端：扩展 → 本地上传，选择本包的 native ZIP；安装后点击使用，在新会话按下文调用。Agentic Hub 外层 ZIP 由项目负责人后续提交，不能与 native ZIP 混淆。

运行环境：WorkSwarm 原生 Python 工具 SDK；Node.js 22（可使用桌面端内置版本）。

询问额定功率 kW、转速 rpm、类型 induction/pmsm、电压 V、电源频率 Hz；用户未指定时明确告知默认 induction、380V、50Hz、20个候选。实际调用 motor_l0_screening screen，不用自写计算替代。
输出包含确定性参数矩阵、物理规则校验、通过/警告/失败计数和按公式估算效率的降序列表；只对没有失败规则且公式 feasible 的候选排序，警告必须保留。若没有可行候选，明确说无可推荐方案，不能把失败方案当作成功结果。
所有估算只是未标定的相对比较；confidence=0.5 是来源的通道标记，不是50%准确率。禁止描述为已完成电磁/热仿真、绝对效率保证、工程安全认证或可直接投产。后续工程决策需有资质人员使用实际仿真和试验验证。中文报告保存在用户工作目录，保留原始计算键和单位。
