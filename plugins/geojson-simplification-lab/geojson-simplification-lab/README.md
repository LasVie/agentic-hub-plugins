# 离线地图简化工作台

版本 **1.0.1** · 内部标识 `geojson-simplification-lab` · 几何引擎 Mapshaper **0.7.101**

在本机浏览器中减少 GeoJSON 多边形的边界顶点，对照原图与结果，查看只读属性，并下载 GeoJSON 或 SVG。相邻要素一起处理，保留引擎识别出的共享边界关系。原文件不会被改写，地图数据不会上传到服务或模型。

## 环境与安装

- WorkSwarm 所在机器为 macOS 或 Linux，宿主 Python 为 **3.11 或更新版本**。本版本不支持 Windows。
- 使用近期版本的桌面 Chrome；浏览器与 WorkSwarm 服务须位于同一台机器。远程机器或容器中的回环地址访问不在本版本支持范围内。
- 浏览器引擎已随包提供，不需要 GIS 软件、npm 安装、地图账号或模型 API 密钥。

在 WorkSwarm 的 **Extensions** 中，导入交付说明标注的本版本原生测试 ZIP 并启用插件。原生 ZIP 包含 `manifest.json`；交付用市场包装 ZIP 的结构不同，请按交付说明选择文件。若导入后看不到 `geojson_workbench` 工具，先检查插件启用状态和宿主导入提示。

为此插件准备一个**已存在的专用真实目录**，把其绝对路径提供给助手。目录及各级父目录不能是符号链接。首次使用或换到另一个插件安装位置时，使用新的专用目录；不要借用其他任务或插件的运行目录。

## 启动、查询和停止

可以对助手说：

> 请用我提供的专用目录启动离线地图简化工作台。

工具 `geojson_workbench` 接受 `workspace`、`action` 和可选的 `confirmed`：

| 操作 | 行为 |
| --- | --- |
| `status` | 只读查询该目录中的本插件服务，不需要启动或停止授权。 |
| `start` | 经用户明确授权后启动服务；只复用身份匹配的本插件安装实例。 |
| `stop` | 经用户明确授权后停止已验证的本插件服务，不操作其他进程。 |

打开工具实际返回的 `url`。端口由系统分配，不需要占用固定端口；不要手工猜测或拼接地址。服务空闲 **30 分钟**后自动退出。页面打不开或提示引擎加载失败时，先查询状态；需要重新启动时，用新返回的地址打开页面。

工具仅管理工作台服务，**没有自动分析地图的工具操作**。地图导入、比例选择、检查和下载在浏览器中完成。

## 简化与导出

1. 点击“载入相邻区示例”体验流程，或选择本地 `.geojson` / `.json` 文件；也可在“GeoJSON 原文”中粘贴内容。示例是虚构区域。
2. 设置 **1% 至 100%** 的目标保留比例，点击“运行简化”。比例按可简化顶点选择阈值；端点和形状保护会影响实际保留量，不保证精确达到目标比例。
3. 勾选或取消“原图”“简化结果”，观察同一范围内的边界对照。蓝色虚线表示原图，绿色表示结果。画面是经纬度等距示意，不是测量地图。
4. 检查前后顶点数、紧凑 JSON 字节数、要素数、环数和组成部分数。顶点计数不包含每个环末尾的重复闭合点；原文件字节数与紧凑 JSON 字节数分别显示。
5. 如出现环或组成部分减少提醒，重点检查小岛、孔洞和细小区域。通过要素选择框查看 `id` 和只读属性。
6. 确认结果符合用途后，点击“导出 GeoJSON”或“导出 SVG”。文件通过浏览器下载，不覆盖原文件。GeoJSON 保留解析后的要素 `id` 与属性；SVG 只包含几何及固定样式，不解释属性里的 HTML、样式或指令。

修改原文或比例会立即清除旧结果并禁用导出，必须重新运行。“取消计算”会终止当前任务；单次计算最长 **12 秒**。“恢复导入原文”重新载入最近导入的原文并把比例设为 100%，随后仍需点击运行。100% 不等于逐字节复制输入文件。

## 输入范围

| 项目 | 限制 |
| --- | --- |
| 顶层类型 | 非空 `FeatureCollection`，含 1 至 200 个 `Feature`。 |
| 几何 | 非空二维 `Polygon` 或 `MultiPolygon`；环精确闭合、至少 4 个坐标且不能为零面积。 |
| 坐标 | WGS84 经度、纬度；范围分别为 ±180°、±90°。不支持跨日期变更线或经度跨度超过 180° 的数据。 |
| 大小 | UTF-8 文本不超过 2 MiB；总坐标数不超过 40,000，包含闭合重复点；JSON 嵌套最多 24 层。 |
| 属性与标识 | `properties` 为对象或 `null`；可选 `id` 为唯一字符串或有限数字。数值按 JSON/JavaScript 数值语义解析，需要精确保留的大型编号应写成字符串。 |
| 明确拒绝 | 重复 JSON 字段、非有限数值、超出安全范围的整数、点线几何、Z/M 坐标、`crs` / `bbox` 等扩展字段、远程 URL。 |

共享边界需要具有精确相同的坐标。工作台不提供坐标投影转换、底图、Shapefile、栅格处理或任意 Mapshaper 命令。

## 结果边界

形状保护只尽力保留每个要素的一个主要环，**不保证保留每个岛屿、孔洞或组成部分**。界面报告环和组成部分数量的减少；它不是所有几何变化的完整清单。简化不会保证修复输入原有的交叉、缝隙、重叠或无效嵌套，也不承诺面积守恒、几何有效性认证或测绘精度。重要数据应保留原件并独立核查导出结果。

## 常见问题

- `invalid_workspace`：确认传入的是用户指定、已存在的绝对目录，路径中没有 `..` 或符号链接。
- `invalid_runtime`：保留现有记录并停止当前操作流程。它可能属于另一安装位置、权限不符或格式异常。不要删除、覆盖、改权限或强行停止未知服务；请为当前安装选择新的专用目录。
- `busy` / `runtime_changed`：另一操作正在使用或更新记录。保留现状，稍后查询，不抢占记录或端口。
- `input_limit` / `unsafe_number`：减小输入，或将大型整数编号改为字符串；不会静默截断数据。
- `engine_error` / `feature_loss`：当前结果不可导出。检查输入环与几何结构，或提高保留比例。
- `timeout` / `engine_load_failed`：减小输入并检查服务状态、浏览器和插件文件完整性；重新启动后使用工具返回的新地址。不要通过修改宿主或放宽浏览器全局安全设置绕过错误。

## 手动检查建议

先载入相邻区示例，以 20% 运行：应看到顶点减少、两区共享边界一致、要素及属性保留。切换原图/结果查看差异，导出 GeoJSON 后重新导入检查，打开 SVG 查看固定样式。再修改比例，确认旧导出立即失效；尝试未闭合环，确认得到中文错误且无法导出旧结果。含小岛或孔洞的数据还应对照数量变化和损失提醒。

这些是检查步骤，不代表用户已经完成测试。需要交付验收时，请核对实际测试 ZIP 的版本和 SHA-256，明确说明测试结果，并提供显示关键操作与结果的原始清晰截图。
