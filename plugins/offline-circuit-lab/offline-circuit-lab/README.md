# 离线电路实验室 v1.0.0

将真实的电阻、电容、电感和理想电压源连接为有界电路，在本机浏览器编辑拓扑、观察数值波形、保存电路并导出数据。数值核心适配自 CircuitJS1 的 RLC 伴随模型和稠密矩阵求解例程；不是把模型回答画成曲线，也不是完整的 CircuitJS 网页版。

## 安装与启动

要求：macOS/Linux、Python 3.11 或更高版本、支持原生 Tool/ToolCard 的 openJiuwen/WorkSwarm 和桌面 Chrome。没有额外 Python 包、Node 运行时、账号或外网服务依赖。通过 WorkSwarm「扩展」正常导入原生测试 ZIP 并安装；Agentic Hub 包使用仓库规定的外层包装。

1. 为本插件创建一个专用工作目录，明确提供绝对路径。
2. 授权后调用 `local_circuit_lab`：`action=start`、`workspace=该目录`、`confirmed=true`。
3. 在同一电脑的独立浏览器标签页打开工具实际返回的完整 URL。地址包含本机会话凭据，请勿公开分享。WorkSwarm 的内嵌 HTML 预览不运行脚本，请不要用它代替独立标签页。
4. `action=status` 查询会话；明确授权后使用 `action=stop, confirmed=true` 关闭。空闲30分钟自动关闭；保存的电路保留。

## 编辑、仿真与持久化

- 输入示例包括分压器、RC阶跃和RLC电路。编辑元件类型、两个端点节点、SI制数值可改变真实拓扑；节点 `0` 为地。电压源满足 `Va−Vb=value`，电流正方向为端点 `a→b`。
- 瞬态从电容电压和电感电流均为零开始；电压源在 t=0 阶跃。显示的 t=0 是阶跃前状态，不应把这一点当作分压器的直流结果。
- 点击运行后才生成真实计算结果。更小步长可用于收敛检查，粗步长得到的漂亮曲线不意味着准确。
- 「保存电路」只更新所选工作目录内 `.offline-circuit-lab/circuit.json`，会替换此前保存的那一份插件电路记录；不会修改导入文件。「读取保存」重新读取它。
- JSON 导入只读取用户选择的文件；JSON/CSV 导出通过浏览器正常下载。文件名冲突由浏览器处理，不静默覆盖任意路径。CSV是数值结果，不是摘要。
- `simulate_rlc_circuit` 可直接进行只读计算；为限制对话体积，工具仅返回首尾样本预览，并明确标记截断。

## 边界与失败

仅支持有界 R/L/C/理想电压源网络和固定步长仿真。输入范围、节点/元件/步数上限由运行时验证，超限、浮空、奇异矩阵、不一致理想约束及非有限数值会报错，不编造波形。电路的合理性仍需用户判断。

这不是通用 SPICE 导入器，不模拟半导体、寄生参数、温度、容差、击穿或器件额定值；不能用于硬件安全、医疗、供电或工程认证。误差随步长和数值条件变化。界面不联网、不调用模型、不含云导入、遥测、广告或第三方图标/字体。

保存目录包含本机会话凭据，保持私有权限；请勿把运行状态打包发布。关闭服务不会删除电路。查看来源、许可及改动说明请阅读 `THIRD_PARTY_NOTICES.md` 和 `licenses/circuitjs/`。
