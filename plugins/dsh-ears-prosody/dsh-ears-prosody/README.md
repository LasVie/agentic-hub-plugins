# DSH 韵律分析 1.0.1

离线测量本地 WAV 的音高走势、声音活动与停顿时序、能量变化和节奏代理指标。适用于演讲、朗读练习和声学对比。插件只读取音频，不会修改原文件。

## 运行环境

需要兼容的 WorkSwarm/openJiuwen Python 宿主，以及后端 `PATH` 中的 **Node.js 20 或更高版本**。插件不需要 npm 包、模型下载、账号、密钥或外部服务。修改后端 PATH 后，需要重启对应后端。

原生工具名称为 `analyze_wav_prosody`，只接受一个参数：

```json
{"path":"/绝对路径/朗读示例.wav"}
```

文件必须是后端可访问的普通文件，不能是符号链接。不支持网址或相对路径。报告不会回显源文件路径。也可直接运行随包命令：

```sh
node scripts/analyze.mjs /绝对路径/朗读示例.wav
```

成功结果包含 `ok`、`version`、`audio`、`activity`、`pause`、`pitch`、`energy`、`tempo` 和 `limitations`。字段名、错误码及枚举值保持稳定；说明和错误消息使用中文。失败时返回 `ok:false` 及错误码、说明。静音是有效输入，会返回零活动和不可用的音高。宿主适配器的执行时限为 30 秒。

## 输入限制

- WAV PCM 8/16/24/32 位或 IEEE 浮点 32/64 位；支持通过校验的 WAVE_FORMAT_EXTENSIBLE 头。
- 单声道或双声道，采样率 8–48 kHz，时长 100 毫秒–60 秒，文件不超过 12 MiB。
- 拒绝损坏或截断的头、不支持的格式、非有限样本值和超限文件。
- 浮点样本必须归一化至 [-1, 1]。扩展格式的有效位数必须等于容器位深；不支持缩减有效位数的布局。
- MP3、M4A、WebM、Opus 等格式需要另行转换；本插件不转码、不录音。

## 如何理解结果

活动检测依据能量，并非语音识别。音高估计范围为 70–400 Hz。时间结果来自音频帧，属于近似值。分析先进行抗混叠滤波，再使用 8 kHz 单声道信号；结果仍保留原始音频的格式信息。双声道会取平均，反相声道可能相互抵消。音乐、噪声、混响和多人重叠发声会影响估计。

节奏指标是每个活动秒内的能量峰数量，不是真实音节数或每分钟词数。绝对能量采用数字 dBFS，不是声压级。`energy.peakDb` 是最大的 25 毫秒均方根（RMS）帧值，不是单个样本峰值；`rangeDb` 是检测到的活动帧中第 95 与第 10 百分位之差。自适应活动门限可能漏掉很轻的声音。

`null` 表示测量不可用，不能解释为零。`steady`、`rising`、`falling` 等枚举只描述信号走势；`insufficient_data` 表示数据不足。插件不推断情绪、意图、说话人身份、健康状态或内容真伪，也不生成转写文本。宿主默认用中文解释结果；用户明确要求其他语言时，可按要求解释。

## 安装与测试

正式交付 ZIP 使用仓库约定的双层市场外壳。当前测试的 WorkSwarm 导入器需要另一份原生测试 ZIP，其根目录直接包含**完全相同的内层运行文件**。本地 Extensions 测试使用原生 ZIP，正式交付保留市场 ZIP。

在 WorkSwarm 中依次打开 **Extensions → My Extensions → Create → Create from file**，选择原生测试 ZIP，安装 **DSH 韵律分析**，然后在新的 Agent 对话中启用插件。界面入口名称随宿主语言设置变化。

示例请求：

```text
请调用 DSH 韵律分析的实际 analyze_wav_prosody 工具，分析 /绝对路径/朗读示例.wav。
用中文说明返回的版本、时长、活动段数、停顿、平均音高及节奏代理指标。
区分测量值与建议，不推断情绪或意图；工具不可用时如实说明，不编造结果。
```

请确认结果中的版本为 `1.0.1`，并用静音 WAV 检查零活动、不可用音高及相关说明。插件本身不会调用模型；宿主对话可能把返回的测量结果和文字发送至用户配置的模型服务。
