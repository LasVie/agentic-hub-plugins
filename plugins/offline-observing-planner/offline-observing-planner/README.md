# 离线观星规划台 · 1.0.0

输入地点和明确的 UTC 时刻，实际计算太阳、月球、水星、金星、火星、木星、土星的地平坐标、升落与曙暮光。中文界面提供可拖动时间的地平图、24小时高度曲线、数字读数、计划保存/恢复以及 JSON/CSV 导出。计算来自随包 Astronomy Engine 2.1.19，不是模型编造或联网查询。

## 安装与启动

需要 macOS/Linux、Python 3.11+、支持原生 Tool/ToolCard 插件的 WorkSwarm，以及桌面浏览器；不安装额外依赖。通过「扩展」正常导入与安装插件。仓库 canonical ZIP 含市场外壳；若当前 WorkSwarm 只接受根级 manifest，请导入同版本 `-workswarm.zip` 原生伴随包，其内层载荷完全相同。不要将测试源码或截图放入安装包。

在系统中先选定或创建一个专用工作目录，明确授权后调用 `local_observing_planner`：
`{"action":"start","workspace":"/已存在的专用目录","confirmed":true}`。
打开工具实际返回的完整 URL（仅127.0.0.1）。同目录 `action=status` 查询；`action=stop,confirmed=true` 关闭。地址含本机会话凭据，勿公开，截图隐藏地址栏。约30分钟无请求自动停止。只在专用目录 `.offline-observing-planner` 中保存状态；不同安装不要共用目录。原有损坏/不兼容记录不会自动删除。

## 计算与交互

选择日期、纬度（北正南负）、经度（东正西负）、海拔。输入时间必须为 `YYYY-MM-DDTHH:MM:SSZ`；固定显示偏移480表示UTC+08:00，不会推断夏令时或时区。

示例：新加坡纬度1.3521、东经103.8198、海拔0，起点 `2026-10-30T12:00:00Z`、24小时、30分钟采样。点击计算后拖动时间滑块，对照地平图与数字表；将起点推进6小时或改地点再算，观察结果变化。勾选天体控制要计算/显示的对象。

任意参数修改会清除旧结果；重新计算前不可导出旧 CSV。保存只保存参数，读取或导入 JSON 后须重新计算，避免将旧星历误认为新结果。已有保存计划须确认替换。CSV 包含实际采样点的UTC、固定偏移显示时间、天体、角度数值；不代表连续时间的精确极值。

原生只读工具 `compute_observing_plan` 接收 `request` 对象，例如：
```json
{"request":{"latitude":1.3521,"longitude":103.8198,"elevation_m":0,"start_utc":"2026-10-30T12:00:00Z","duration_hours":24,"step_minutes":30,"bodies":["Sun","Moon","Jupiter"],"display_offset_minutes":480}}
```
工具返回每个天体前3个及最后1个采样点、总点数与全部区间事件；`preview_truncated` 表示工具展示缩略，不是计算未完成。完整轨迹在本机界面和 CSV 中。失败时返回 `ok=false` 与中文错误，不会返回猜测或缓存值。

## 数值约定和限制

- 日期区间全部在2000–2100年，纬度±80°，经度±180°，海拔−500..10000米；时长1秒至24小时，采样间隔为5..60整数分钟，最多289个时刻。每次计算10秒硬限时，超限结束计算子进程。
- 高度/方位为站心、当日坐标，含光行时和光行差；高度是天体中心的**无大气折射**高度。方位从北向东计；接近天顶方位变化很快。
- 升落事件使用引擎的标准折射与地平模型，太阳/月球按上边缘，行星按中心；与曲线0°交点不同。曙暮光按太阳中心−6/−12/−18°。事件区间含起点、不含终点；轨迹含终点。没有区间事件不等于永久不升/不落。
- 未来 UTC 与动力学时间转换存在假设。独立参考检查中，2100年月球个例与 JPL 相差约1.4角分，采用一致时间尺度后差异显著缩小；不可宣称整个范围均达1角分或保证精度。上游维护活跃度下降。实际测试范围见仓库测试报告。
- 不含恒星/星图、卫星、食象、天气、光污染、山体地平线、望远镜控制、导航或太阳观测安全判断；在地平线上方不代表肉眼可见。界面点线为数值示意，不是实景或星图照片。
- 不联网、不调用模型、不改宿主、SDK、依赖或其他插件。网页仅向本机私有服务请求计算与保存。
