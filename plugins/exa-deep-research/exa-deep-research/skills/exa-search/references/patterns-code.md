# 查询模式：代码与文档

查询包含编程语言、框架或库名，并优先读取官方资料。

```json
{"query":"Stripe API Node.js 创建订阅 代码示例 官方文档","numResults":5}
```
```json
{"query":"React hydration mismatch 服务端 客户端 原因 修复","numResults":10}
```
```json
{"query":"GitHub [库名] 开源 示例项目 实现","numResults":10}
```

已知官方 URL 时，用 `exa_fetch` 阅读对应文档，核对版本和示例适用条件。
