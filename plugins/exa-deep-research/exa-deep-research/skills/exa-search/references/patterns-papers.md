# 查询模式：论文与出版物

使用 `category:publication` 辅助检索出版物。

```json
{"query":"category:publication 长上下文 Transformer 稀疏注意力机制","numResults":12}
```
```json
{"query":"category:publication [主题] 系统综述 文献回顾","numResults":10}
```
```json
{"query":"category:publication [作者姓名] [主题]","numResults":5}
```

近期进展查询应使用根据当前日期计算的年份或范围，不照搬示例时间。查找奠基论文时，先阅读综述，再提取并核验基础参考文献。区分预印本、正式发表版本和后续修订。
