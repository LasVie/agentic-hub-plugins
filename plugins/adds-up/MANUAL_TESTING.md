# 手工测试指南 — 文档数字核对 1.0.0

测试包：`test-packages/adds-up-1.0.0-native.zip`（原生安装包；名称、版本、SHA-256 见交付说明）。示例文件在 `tests/fixtures/manual/`，里面故意埋了错误。

## 安装和准备

1. 在 WorkSwarm 里导入这个 ZIP，安装“文档数字核对”。装好后应能看到一个技能 `document-number-check` 和两个工具 `adds_up_extract`、`adds_up_grim`。
2. 把 `tests/fixtures/manual/` 里的 6 个文件复制到本机一个读得到的目录（比如 `D:\测试\`）。提问时给出文件的完整路径。
3. 默认用中文提问；回答应当是简体中文，结论用词是“错误 / 冲突 / 待确认”。

## 建议的测试（每一项写了应当看到什么）
