# 视频频道日更流水线 1.0.1

让 AI 助手每天稳定地为视频频道（YouTube 等）产出当天的长视频 / 短视频：建立频道运营目录，按 7 步制作，防止同一天重复制作和重复提交付费生成任务，用本机 FFmpeg 渲染并做上传前机器检查，只把在平台上确认过的发布结果记为完成，并按 24 小时 / 72 小时 / 7 天记录指标。

这是一套“每天都能发出去”的工作结构，不是涨播放量的秘诀。

## 安装

WorkSwarm 桌面端：扩展 → 本地上传，选择本插件 ZIP；安装后点击“使用”，在新会话中使用。

运行环境：WorkSwarm 原生 Python 工具 SDK，Python 3.11 或以上，无第三方 Python 依赖。渲染与检查需要本机安装 FFmpeg（含 ffprobe）并加入 PATH，或用环境变量 `FFMPEG_PATH` / `FFPROBE_PATH` 指定。

## 使用

先告诉助手频道目录的绝对路径（在 WSL 上运行时可直接给 `D:\...` 这样的 Windows 路径），然后用自然语言：

- “在 D:\频道\世界新闻 新建一个频道”：助手一次性询问频道名称、主题、语气、长 / 短视频规格、配音与画面工具，生成目录
- “做今天的视频”：按 OPERATIONS.md 的 7 步制作，每步记录进度；今天已经发过的栏位会跳过
- “渲染 runs/2026-10-27/short”：用场景图片 + 旁白生成竖屏 MP4（横屏需说明）
- “检查 final.mp4 能不能上传”：输出分辨率、时长、音频有无 / 无声 / 削波、字幕结尾是否对齐，并列出人工检查项
- “短视频已经预约上了，视频 ID 是 abc123”：确认你已在平台后台看到后记录
- “记录 abc123 的 24 小时数据：播放 1229”
- “今天进度如何”

配音、画面生成、联网调研和平台上传需要你自己连接的工具和账号；没有这些工具时，助手只做到脚本、场景列表和生成提示词，并列出需要你来做的事。

## 频道目录

```
<频道目录>/
├── channel.json        频道设置；authorization.daily_upload / additional_payments 默认 false
├── OPERATIONS.md       每日作业指令（结果不满意就改这里的句子）
├── state.json          各日期栏位的视频 ID、进行中的 job、待记录指标
├── research/  content/
├── production/
│   ├── jobs.json       付费生成任务 job ID 记录
│   └── metrics.json    指标记录
└── runs/YYYY-MM-DD/
    ├── manifest.json   当天 7 步进度
    └── short/ long/    scenes.json、narration.*、final.mp4 等
```

插件只读写频道目录内的文件；本身不联网、不上传、不付费。

## 安全规则（由工具强制）

- 今天已有视频 ID 的栏位不能再记录制作进度。
- 同一 job ID 重复记录时提示“不要重新提交，用原 job ID 查询”。
- “上传”步骤不能记为完成；记录发布分两步：助手先问你是否已在平台看到该视频的预约 / 公开状态，你确认后才会记录。
- 多个记录同时写入同一频道时自动排队，不会互相覆盖。
- 修改上传 / 付费授权、覆盖已记录的视频 ID 需要你明确同意。
- 渲染场景路径不能越出运行目录；检查有 FAIL 时明确告知不要上传。

## 与上游的差异

- 上游是 Claude Code 插件（韩语，1 个技能 + 3 个斜杠命令 + 2 个脚本）；本插件改为 WorkSwarm 原生工具 + 中文技能。
- 状态、job、发布与指标记录由工具写入并校验，而非仅靠提示词约定；新增 metrics.json 与指标到期提醒。
- 模板、提示、检查结果全部简体中文；默认时区 Asia/Shanghai（可改）。
- 不包含上游 README 中的外部指南、模板与付费服务链接。

## 1.0.1 修正

- 新建频道只问一次，未提供的项直接留空。
- 修复并行记录步骤时后写覆盖先写、导致步骤丢失的问题（加频道写锁）。
- 发布记录改为工具强制的两步确认；未说明预约 / 公开时先问用户。
- 没有上传工具时不再声称会替用户上传；进度汇报按记录原样转述。

## 已知限制

- 人工检查项（发音是否自然、画面是否重叠等）无法自动判断，一律标为“未确认”。
- 指标需手动提供；插件不读取平台数据。
- 机器检查的阈值沿用上游：平均音量低于 -60 dB 视为无声，峰值高于 -0.5 dB 可能削波，竖屏超过 180 秒提示超出 Shorts 上限，字幕结尾与视频相差超过 3 秒提示。
