# 物理解题审校

版本：**1.0.1** · 内部标识：`physics-assumption-check`

先读清题图和条件，再列方程、检查单位与物理极限，最后列出答案依赖的假设。适用于力学、电路、热学、光学等学习题目，以及对已有解答的复核。

本插件包含一个中文解题技能和一个本地图像工具。解题与读图由宿主模型完成；图像工具负责实际裁剪、像素缩放和 PNG 保存，不识别电路节点、绳子连接关系或文字，不自动求解方程。默认输出简体中文，用户明确要求其他语言时遵从。

## 运行要求

- 支持原生 Plugin、技能加载和 Python 工具执行的 WorkSwarm 宿主。
- 本地图像工具需要 **Python 3.10+** 与 **Pillow 12.2.0**。应在本任务独立环境安装依赖，不修改其他插件的环境。
- 解题需要宿主已有的模型配置；带图问题还需要宿主的图像输入/查看能力。插件不附带模型，不自动注册服务、不添加 API 密钥，也不自行发起模型付费调用。
- 本地图像处理不请求网络。图片是否发送给宿主模型由宿主的模型配置和调用方式决定，不把本地处理等同于整个解题流程离线。

## 安装

1. 解压测试包 `physics-assumption-check-1.0.1.zip`。市场外层目录包含 `plugin.yaml`；其内层同名目录包含 `manifest.json`、本说明和实际运行文件。
2. 在分配给本任务的 WorkSwarm 实例中打开 Extensions，按该宿主支持的导入方式导入**包含 `manifest.json` 的内层插件载荷**。测试交接说明将给出该实例的地址与具体导入文件；不要更换到另一任务正在使用的实例。
3. 检查插件显示名称为“物理解题审校”、版本为 `1.0.1`，并能加载 `physics-review` 技能和 `prepare_physics_figure` 工具。若宿主报告缺少依赖，在该实例所用的独立 Python 环境中补齐 Pillow，再重新检查。

如需单独使用图像命令行，在内层插件目录运行：

```bash
python3 scripts/prepare_figure.py --help
python3 scripts/prepare_figure.py --path "/absolute/path/题图.png" --output "/absolute/path/题图放大.png" --width 1600
python3 scripts/prepare_figure.py --path "/absolute/path/题图.png" --output "/absolute/path/题图局部.png" --crop 10 20 210 180 --width 1600
```

将示例路径替换为真实绝对路径；裁剪坐标以 EXIF 方向校正后的原图像素为准。各次操作使用单独输出文件，不用输入文件作为输出。命令和工具参数名是兼容性标识，保持原样。

## 使用方式

可以直接提出中文题目，例如：

- “请用物理解题审校分析这道题。先列题目已知条件，推导旁标注假设编号，最后给出两项独立校验和假设清单。”
- “请检查这张电路图中交叉的两根导线是否相连。如果看不清，先放大局部，再分别说明两种连接方式会改变什么。”
- “请复核我给出的斜面题解答，只指出建模或单位错误，不要提前给完整答案。”

图幅小或连接点不清楚时，智能体应先调用工具并实际查看生成图片，再继续读图。工具调用示例：

```json
{
  "path": "/absolute/path/题图.png",
  "output": "/absolute/path/题图放大.png",
  "width": 1600,
  "enhance": false
}
```

`crop` 可选，格式为四个整数 `[x0, y0, x1, y1]`；`enhance` 默认 `false`。工具返回处理结果 JSON，并在所选路径保存 PNG。放大只能便于观察已有像素，不能恢复不存在的细节；增强图也不能证明一个模糊交点确实相连。

正常解答应包含：题意与图示解读、带 `S1`/`S2` 等编号的建模推导、结果及单位、量纲与另一项独立校验，以及按影响和不确定性排序的假设清单。条件不足时给出待确认项或条件分支，不承诺唯一答案。

## 手动测试建议

以下是待用户执行的测试，不表示本说明已经完成运行验证。

| 测试 | 操作 | 预期观察 |
| --- | --- | --- |
| 纯文字题 | 输入一个给定 `g`、无空气阻力的竖直运动题 | 使用题目常数，交代方向，输出单位检查和另一项独立校验，最后保留假设清单。 |
| 清晰带图题 | 提供一个绳端或电路节点明确的小图 | 需要时调用图像工具并查看结果；描述实际连接关系，再列方程。 |
| 模糊连接点 | 提供无法确认交点是否相连的图片 | 放大后仍无法确认时明确说明，列分支或请求具体信息，不补画成常见结构。 |
| 质疑已有答案 | 给出具体的新条件或图中细节 | 重新检查相关假设，若修正答案则指出变化依据；不只因用户坚持就改答案。 |
| 无效图像输入 | 使用不存在的路径或不合法裁剪范围调用图像工具 | 返回可读中文错误，不把失败声称为处理成功。 |

测试完成后，保留当前版本关键操作与结果的原始全分辨率截图，并按测试交接说明确认同一 ZIP 的 SHA-256。宿主安装成功、图片生成成功和物理解答正确是不同的验证事项。

## 已知范围与限制

- 题图过于模糊、文字缺失或条件矛盾时，插件可能只能给出条件化结论，需要用户补充原图或说明。
- 单位、极限与回代检查能帮助发现错误，但不能保证模型解答、读图或题设解释始终正确。
- 不包含符号代数系统、数值仿真器、OCR 服务或教材数据库；图像处理成功不能替代物理推导验证。
- 不提供工程设计认证；实际工程使用还需采用相应专业规范和验证流程。
