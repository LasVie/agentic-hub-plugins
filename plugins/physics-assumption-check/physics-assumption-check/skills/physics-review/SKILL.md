让用户能检查答案所依赖的图示、条件和假设。默认使用简体中文；用户明确要求其他语言时遵从。用户要求提示、分步辅导或只复核某一步时，保持该范围，不提前给出完整答案。

本技能依赖宿主模型进行读图、物理建模和推导。图像工具只裁剪、缩放与保存图片，不识别连接关系、不求解方程，也不证明解答正确。适用范围是学习题目和解答复核；不能把结果表述为工程设计认证。

## 1. 读题与数据

- 明确所求量、方向和比值顺序，例如 `m_A/m_B` 不能默认为倒数。
- 列出数据和单位，写明必要的单位换算。通常统一为 SI；保留题目指定的单位或常数并说明。
- 区分题目明示条件、清楚可见的图示、自己推断的条件和约定值。未写明“无摩擦”“质量可忽略”等条件时，不静默补入。
- 缺少决定答案的条件时，提出具体澄清；如果可以，先给出条件化推导或不同解释的分支，不虚构唯一数值。

## 2. 先检查图，再列方程

图幅较小（例如宽度不足约 600 像素），或绳端、节点、交点等细节不清楚时，先调用 `prepare_physics_figure`。使用实际存在的原图绝对路径，选择本次任务独立的 PNG 输出路径。不要猜测附件路径或复用其他任务的输出文件。

```json
{
  "path": "/absolute/path/题图.png",
  "output": "/absolute/path/本题放大图.png",
  "width": 1600,
  "enhance": false
}
```

必要时增加 `"crop": [x0, y0, x1, y1]`，坐标按 EXIF 方向校正后的原图像素指定（尺寸见 source.oriented_width / source.oriented_height）；先核对原图尺寸和目标区域，不把放大后的坐标用于原图裁剪。再次调用时使用新的输出文件名。

工具成功返回后，用宿主可用的图像查看功能实际打开生成的 PNG，同时对照原图。不能把工具返回的路径、尺寸或成功状态当作已经看过图片。若宿主无法显示输出，明确说明这一限制，不声称核实了图中细节。

默认保持 `enhance: false`。用户需要辅助观察时才考虑增强，并保留原图对照；插值放大和对比度、锐度变化不能恢复不存在的细节，也不能作为新连接点或文字的证据。

记录“题图解读”，按题目类型检查：

- **力学：**逐条追踪绳子的起点、绕经位置和终点，区分“绕过滑轮”与“系在轮轴”；识别固定或可动滑轮、物体的支撑/悬挂关系，以及角度相对于哪条线。
- **电路：**按节点识别连接，检查交叉处是否相连；两元件只有共享同一对节点才并联。记录电源极性、仪表接法和标出的电流方向。
- **光学：**记录物体、透镜或镜面、光轴及距离的起算位置。
- **坐标图：**记录坐标轴物理量、单位、刻度、正方向及原点，避免把示意图当作精确比例图。

放大后仍不清楚的连接关系必须保留为“待确认”。说明可能的解释 A/B 各自改变哪条约束或方程；不要用常见教科书图形补全。确需原图、局部截图或文字说明才能继续时，指出具体缺失细节。

## 3. 声明模型与约定

- 明确研究系统、参考系、坐标轴、正方向和零势能位置，推导中保持一致。
- 为重要假设分配稳定编号 `S1`、`S2`……，标明其来源。图示推断与题干明示条件必须分开。
- 明确理想化条件，如轻绳、不可伸长、理想滑轮、理想气体、忽略空气阻力等，并核对题目是否允许。
- 优先使用题目或课程指定的常数。未指定时说明所取的 `g`；`sin 37° ≈ 3/5`、`sin 53° ≈ 4/5` 是可选近似，不是恒等式，不能默认为所有题目的要求。
- 遇到易混淆条件，按领域查阅 [常见建模与计算陷阱](references/common-errors.md) 中的相应部分。

## 4. 建模、推导与复核

- 先写物理关系，再代数求解。按题目需要给出受力分析、绳长约束、能量平衡、节点/回路方程或光路关系。
- 尽量保留符号到最后，便于追踪依赖；只在最后代入数值和统一单位。
- 在首次使用每条关键假设的方程附近标记对应编号，例如 `T_1 = T_2 [S2：轻绳与理想滑轮]`。编号在全篇保持一致。
- 区分“代数成立”与“模型适用”。守恒定律必须说明适用系统和条件；不能因为计算顺畅就跳过建模检查。
- 结果包含单位、方向或正负号含义，保留与输入精度相符的有效数字。无唯一答案时给出条件化结果，并明确待确认事项。

## 5. 至少两项独立检查

提供单位/量纲检查，并再选择至少一项能独立发现错误的检查。对于无量纲结果，说明两边为何无量纲。重复抄写同一套计算不算第二项检查。

- **极限情况：**如 `μ → 0`、角度趋于零或某质量趋于零；只在原模型仍适用的范围内讨论，指出奇异或失效的极限。
- **另一关系或解法：**用能量、牛顿定律或等效电路等不同路径交叉核对；说明两种方法各自适用的条件。
- **数量级与物理方向：**检查结果是否符合已知的上界、下界、符号或运动趋势，并写出依据。
- **原方程回代：**把结果代回原始的独立约束或守恒式，报告残差/平衡关系。不要只代回已化简的同一个结果公式。

无法完成某项检查时说明原因，不能写“验证通过”代替实际检查。检查降低漏错风险，不能保证题图解释正确。

## 6. 输出与假设清单

按用户要求控制详细程度，通常采用下面的顺序；简单题可以合并中间部分。最后始终保留简短的假设清单，方便用户查错。

```text
题意与题图解读：所求、已知数据、关键连接关系、未确认细节。
模型与推导：系统与约定，方程旁标注 [S1]、[S2] 等。
结果：含单位/方向；条件不足时给出分支或条件化结论。
校验：量纲检查，以及至少一项独立检查及其依据。
假设清单：按“错误时对结论的影响和当前不确定性”从高到低排列。
```

清单每条通常一行，保留推导中使用的编号，不因排序重新编号。使用来源标签：

| 标签 | 含义 |
| --- | --- |
| 待确认·解释 | 来自推断、模糊图示或缺失条件，说明若不成立会改变什么。 |
| 题图 | 原图中清晰可见的事实，避免把推断写成观察。 |
| 题干 | 题目明确给出的条件。 |
| 约定 | 使用的符号、常数或已声明的理想化近似。 |

示例：

```text
假设清单
- S3｜待确认·解释：A 的绳端系在下方滑轮的轴上；若实际绕过滑轮，绳长约束与受力方程需重写，当前数值不能沿用。
- S1｜题图：标出的角度是斜面与水平线的夹角。
- S2｜题干：接触面无摩擦，滑轮质量可忽略。
- S4｜约定：向上为正，取 g = 9.8 m/s²；该数值可按课程要求替换。
```

若不存在待确认解释，明确写“未增加待确认解释；所用条件来自题干、清晰图示和已列明的约定”，不要因此省略对关键条件的记录。

## 用户质疑答案时

先回看高风险假设、原图和所求量，再检查代数；图形误读不能仅靠重复计算排除。分开报告“物理关系的适用性”和“题图解释的确定程度”。

不要因用户坚持而改变正确的推导，也不要未复查就坚持原答案。根据新图示、遗漏条件或具体错误修正，说明改了哪条假设/方程，并更新结论和清单。与参考答案不同时，先核对是否只是倒数、方向、单位、常数近似或四舍五入不同。
