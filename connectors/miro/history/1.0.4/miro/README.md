# Miro 白板连接器

读取授权的 Miro 白板，并在用户指定的白板中创建可编辑的图形或便签。

安装包后在 WorkSwarm 打开连接器卡片。在 WorkSwarm 点连接并打开本机授权页，在连接页点开始连接，随后在同一浏览器进入 Miro，选择测试白板所在团队。使用 WorkSwarm 自带或已安装的 Node.js 和 npm。从卡片进入后先列出工具，按实时工具参数读取和写入白板。

需要 Python 3.9 或以上，Windows 卡片命令使用 Python Launcher 选择 Python 3.12。需要访问 Miro。服务免费额度、组织授权策略和可用操作由提供商及账号决定。 首次启动需访问 npm registry。

聊天中选择该连接器及其技能，明确给出目标 ID、操作和目标内容。按目标对象的 ID 回读写入结果。
