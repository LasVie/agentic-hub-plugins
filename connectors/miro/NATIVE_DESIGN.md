# Miro 1.1.0 设计

移除运行载荷的 Python 依赖，使用 WorkSwarm 自带 Node/npm 自动准备经核验的固定标准客户端。OAuth/DCR/PKCE/缓存/刷新由标准 SDK 管理，本机引导只转交精确官方地址和白板读写范围。父 IPC 断开、信号、总超时均结束授权 worker，避免依赖宿主长驻 MCP 缓存。

业务已按实际授权后 schema 独立适配，只暴露 searchBoards/readCanvas/createStickyNote 三个本地受限操作。读取按控件 ID 或明确矩形；新建从文本、标记和坐标生成一张固定黄色便签，不接受原始 SVG/已有控件 ID/其他类型或用户字段。官方端实际仍有 47 种工具，本包仅使用 4 个已核对接口作为内部读取、格式资料和创建传输。

创建前读取目标区域，区域非空、读取不完整或格式协议变化即停止。唯一标记包含在用户已同意的文本中，原子本地记录避免并发重复；未确认提交禁止自动重试。记录仅保留白板、标记、坐标、正文摘要和成功时控件 ID，不存令牌或全文。创建响应不当作独立回读，聊天必须按新 ID 另读并核对全文。14 项检查及最终包在原版 WorkSwarm 0.2.8 本地目录夹具上的卡片授权、聊天读取、单次创建和独立全文回读已通过；官方拒绝、卡片取消、断开与父进程结束也已检查。其他平台、正式 Hub 安装和自然过期未实测，详见 TEST_REPORT.md。
