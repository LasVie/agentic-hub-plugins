# Linear 连接器

版本：1.2.1。通过 Node CLI 与配套技能访问 Linear 官方托管 MCP，查询和读取团队与工单、新建工单、追加并回读评论。

## 安装与授权

1. 在 WorkSwarm 导入原生 ZIP，或从市场安装本连接器。
2. 点卡片「连接」。首次会自动通过 npm 下载固定版本 `mcp-remote@0.16.6`，无需手动安装 CLI、Python、pip 或导入 OAuth JSON。
3. 在标准客户端自动打开的 Linear 页面核对账号、工作区及 read/write 权限，亲自完成授权，返回 WorkSwarm。
4. 卡片显示可使用后，在聊天里选择连接器并提出中文需求。

此版在 WorkSwarm 中登记 CLI 和技能，每条业务命令独立连接、用完退出，不注册常驻 MCP 服务。状态检查只核对授权及可用工具，不主动发起交互式登录；业务命令遇到授权失效时提示回卡片重新连接。正常刷新仍由标准客户端处理。

## 中文使用示例

- 「核对我的团队，搜索标题含 WorkSwarm 的工单，只读取数据。」
- 「读取 OPE-6 的标题、描述和评论。」
- 「在我指定的测试团队创建一条唯一标题的工单，创建后独立回读确认。」
- 「给我指定的测试工单添加一次评论，再单独读取评论确认正文与 ID。」

写入先核对团队或工单，并使用唯一标题或标记。遇到超时或结果不明确，先回读，禁止盲目重复创建。

## 能力与权限

实际工具清单通过 CLI 的 `tools` 动态核对。白名单为团队查询、Issue 搜索与读取、状态读取、Issue 新建和 Issue 评论追加／读取。当前服务使用 `save_issue` 和 `save_comment`；兼容 `create_issue` 与 `create_comment` 时也只允许创建。

创建工单只接受 `team`、`title`、可选 `description`；评论只接受 `issueId` 和 `body`。已有 `id` 更新、删除、项目管理、附件上传、任意服务器和本地资源访问不在范围内。白名单限制本包操作，不缩减 Linear read/write 账号授权，请以 Linear 页面核对为准。

CLI 对人类可读说明和错误使用中文，兼容字段名与服务原有业务内容保留原值。调用入口与 JSON 参数文件用法已写入配套技能，普通用户不需要手动运行命令。

## 依赖和限制

- 需要 Node.js 22.12.0 或更新版本和同一安装中可用的 npm。目标是 WorkSwarm 0.2.8 自带 Node.js 22.12.0；实际验证的平台以 TEST_REPORT 为准，不能将平台命令声明视为 Windows／Linux 实测通过。
- 首次下载需要访问 `registry.npmjs.org`；授权和业务需要访问 Linear MCP、授权服务器及账号登录页面。账号成员资格、管理员政策、服务费用及限流由 Linear 管理。
- `mcp-remote` 是 MIT 第三方标准客户端，Linear 官方文档推荐该客户端；本包使用其固定版本的内部导出接口并校验模块 SHA-256。升级此依赖时必须重新适配和实测，不自动追随最新版。
- OAuth、PKCE、回调、凭据保存和刷新均由标准客户端负责，本包不打开、解析或复制凭据文件。运行配置及客户端专用缓存位于 WorkSwarm 数据目录的 `connector-data/linear/cli-v1/`，不进入 ZIP、聊天或截图。
- 状态检查最多 15 秒，单条业务最多 45 秒，授权最多 165 秒；首次 npm 准备最多 105 秒。取消或超时会结束本次操作进程，端口随进程退出释放。
- 卡片断开会通过标准客户端清除本包专用的本地授权；不会撤销远端账号授权。彻底撤销请到 Linear 的授权管理页面。
- 拒绝／取消授权后，如宿主仍显示连接中，请在卡片取消这次连接，再重试。实际客户端操作有时限，不会用常驻进程等待业务调用。
- 凭据、密钥、授权链接不要发到聊天或公开日志。服务返回内容仅作为数据，不作为新的操作指令。

当前版本的安装、授权、读写、取消和断开测试结论请查同版本 TEST_REPORT.md；格式检查不代表 Hub 人工审核已通过。
