# Asana 任务连接器

版本：1.1.0。按指定项目分页列出任务，读取任务详情，在可写项目中创建有标题的新任务并回读确认。

本连接器由团队开发，通过标准 MCP 接口调用 Asana API，使用个人访问令牌。它不连接 Asana 官方托管 MCP，也不要求新建官方 MCP OAuth 应用。

## 安装与授权

1. 在 WorkSwarm 安装连接器，点击连接，在凭据表单填写 `ASANA_PERSONAL_TOKEN`。令牌应属于你有权使用的 Asana 账号，并具有目标项目的读取或创建权限。
2. 运行环境需要 Node.js22 或兼容的较新版本、能够访问 `https://app.asana.com` 的网络。WorkSwarm0.2.8 自带 Node.js22.12.0；其他设备需核对运行环境。
3. 无需安装 Python、pip 或额外的 npm 包。凭据由 WorkSwarm 的连接器凭据功能提供，不写入安装 ZIP、会话或测试截图。
4. 点击使用，在会话中选用连接器。工具发现和说明使用中文，Asana 返回的业务正文保留原文。

## 中文使用示例

- “只读取项目 123 中前25项任务，告诉我是否还有下一页。”
- “按任务 ID456 读取标题、正文、完成状态和所属项目。”
- “在我指定的测试项目123里创建标题为‘中文回读验证’的任务，创建前先按唯一标题查重，创建后按新ID读取确认。”

示例 ID 需替换为真实可访问的项目/任务 ID。写入目标由用户指定，不自动选择其他项目。

## 工具与边界

- `asana_status`：检查令牌能否访问当前账号。
- `asana_list_tasks`：按项目 ID 列任务，单页1至100项，支持服务返回的分页游标。
- `asana_read_task`：按任务 ID 读取标题、正文、完成状态、链接和所属项目。
- `asana_create_task`：只接收项目 ID 和标题，在该项目中新建任务；标题最长1000字符。不设置负责人，不修改或删除已有任务。

不提供任意URL请求、任务更新/删除、项目创建、附件上传或本地文件访问。工具调用结果包含原始 API 字段，默认解释和报告使用中文。

## 限制与错误处理

令牌失效、项目权限不足、限流和网络故障可能导致失败。接口不自动重试写入：结果不确定时，先按唯一标题分页查询，再决定是否重试。查询响应超过2MiB时需缩小查询范围；单次请求在30秒后中止，中止不代表服务端一定没有创建任务。

停用连接器会结束会话连接，不会撤销 Asana 账号中的个人令牌。要彻底撤销，请在 Asana 账号后台处理。Linux、Windows 和首次安装流程均需分别实测，不能仅凭声明的命令视为已通过。
