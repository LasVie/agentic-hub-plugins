# Source and distribution review

- Outlook Calendar for Microsoft 365 work/school accounts → Outlook 工作日历连接器 → `outlook-work-calendar`. Task `AH-20261124-outlook-work-calendar`, owner Song Haoran. Candidate Not Applicable. The public [Microsoft Personal 1.0.0](https://agentichub.openjiuwen.com/assets/071cc66a5004472ba7263e429c48d9f7?version=1.0.0) catalog entry describes personal-only device-code sign-in with broader scopes. This package targets the distinct organizational Outlook mailbox path.
- Native integration from Microsoft public specifications as reviewed on 2026-11-24: [desktop registration](https://learn.microsoft.com/en-us/entra/identity-platform/scenario-desktop-app-registration), [OAuth 2.0 code flow](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow), [calendarView](https://learn.microsoft.com/en-us/graph/api/user-list-calendarview?view=graph-rest-1.0), and [event get](https://learn.microsoft.com/en-us/graph/api/event-get?view=graph-rest-1.0). Microsoft redistributable code and media are outside the package; only public API behavior informed the implementation. The Softeria source and packages were not used.
- Team-owned reuse from [Google Calendar 1.1.0 at fe4744c](https://github.com/LasVie/agentic-hub-plugins/tree/fe4744ce839b2a28d9fcf4c34ca6fdce3453a20e/connectors/google-calendar): native CLI invocation/manifest and private atomic file access. Microsoft authorization, scopes, token refresh, Graph request and event mapping are implemented separately. No external SDK, credential, logo or npm package is bundled.
