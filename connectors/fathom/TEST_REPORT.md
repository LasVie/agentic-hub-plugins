# Fathom 会议连接器 1.0.1 测试记录

2026-11-24，macOS，原版 WorkSwarm 0.2.8 和自带 Node.js 22.12.0。使用独立本机数据目录和本机 Hub 测试目录，改动集中在 Agentic Hub 包。

- 官方 Agentic Hub CLI 0.0.1（`c8ee4ef44be0453470114aa5a19f4e1017462907`）在干净 staging 通过 `validate` 和 `pack`。Node 可读源码、运行目录及两个确切 ZIP 通过仓库 preflight。5 个安装文件与两个 ZIP 和源码逐文件匹配。
- `node --test connectors/fathom/tests/test-fathom.cjs` 通过 10 项，包括鉴权、日期和标题匹配、游标、摘要、分享链接过滤、逐字稿分页、无效参数、凭据及权限、网络错误和原包 stdio 工具发现。可控错误响应包括未授权、无权限、找不到资源及限流。
- 原版 WorkSwarm 加载器接受 manifest。1.0.1 从干净环境的卡片安装，用户在卡片填写个人 API Key，卡片切换到「使用」并发现四个 MCP 工具。用已安装的同版 MCP 和刻意无效的测试密钥访问 Fathom API，得到预期的无效凭据提示。
- 用 Fathom 桌面端音频模式录制专用会议 `WorkSwarm Fathom QA 20261124`。主要内容来自 macOS 朗读的虚构台词。Fathom 生成摘要和逐字稿，录制保留在测试账号。逐字稿还含录制开头的一声短促语气词。
- 1.0.0 的实测发现 Fathom 在摘要内生成录制分享链接。1.0.1 保留摘要文字并去掉这类分享链接。最终包的真实 MCP 回执中核对了摘要决策和周五复核的内容以及链接过滤。
- 最终版中文聊天从卡片的「使用」发起，真实 MCP 调用鉴权返回 `connected: true`。完整标题匹配一场测试会议，独立读取该录制的摘要。逐字稿两页分别回传 8 条和 6 条，末页游标为空。聊天引用 `00:01:31` 的决策句及 `00:01:42` 的周五复核句。两页工具回执与 Fathom 原始逐字稿一致。
- 4 张本机原图已存，分别是 Fathom 测试录制的逐字稿、空白密钥表单、最终包连接及工具发现、中文聊天验收。正式 Hub 下载、Windows/Linux、远程宿主以及真实账号权限撤销后的恢复待测。
