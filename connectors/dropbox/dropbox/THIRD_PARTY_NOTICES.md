# 第三方品牌标志与接口

本包运行代码使用 Node 内置模块，按公开 Dropbox API 接口独立实现，不捆绑第三方 SDK、MCP、CLI、插件代码或提示词。不是 Dropbox 官方 CLI，也不表示 Dropbox 背书。

`icon.png` 是原样官方 `DBX_Tab_128.png`，SHA-256 `77dc1afb3d82c5fcbde086580a7648e216cda8760629dad3f8079e62f25f24c8`。商标归 Dropbox，仅在安装的 WorkSwarm 连接器卡片识别对应服务；外层 Hub wrapper 不使用该商标。未作修改，未将商标重许可为代码许可证。
