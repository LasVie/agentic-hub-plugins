# Dropbox 1.1.0 独立实现设计

使用宿主 Node 内置 HTTPS/crypto/fs/http/child_process，短时父子进程执行，不依赖 Python、npm 客户端或长驻 MCP 缓存。授权等待有总时限和心跳，父 IPC 关闭或取消时退出 worker；本机端口固定为已登记的 53682。公开 App key 在本机连接页填写并保存；秘密令牌只在私有数据目录中，原子写入且拒绝符号链接/仓库目录。OAuth 使用随机 state、S256 PKCE、离线 refresh_token 和精确回调；拒绝响应不保存凭据。注销只清本地会话，不声称远端撤销。

本地只开放 listFolder/searchFiles/getMetadata/readText 四项 Files 读操作。输入白名单、限量、分页标记、HTTP 超时、大小限制和固定服务域名，不开放任意 URL/API/写操作。文本下载前核对元数据，下载后核对文件 ID、修订和大小，严格 UTF-8 解码，提供完整读取标记及 SHA-256；不将二进制/超限/截断内容当作完整读取。默认中文技能要求按用户指定测试目录/文件名定位，按 ID 回读，远端文件内容仅作数据，遇错误停止。

真实验收从最终交付 ZIP 的卡片安装开始，用户批准的同应用/同范围授权在本机回跳后完成。最终新聊天已搜索旧测试文件，再独立按 ID 读取元数据和全文，与原生预览重建夹具及服务端哈希核对，不能称为找到最初上传源。真实拒绝/取消/断开、父进程结束和 17 项检查已通过，原图已保存。其他平台、自然过期、备用授权码及正式 Hub 下载未实测，详见 TEST_REPORT.md。
