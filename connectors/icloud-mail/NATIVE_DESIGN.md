# 原生实现设计

以 WorkSwarm 卡片收集 iCloud 邮箱地址和 Apple 生成的 App 专用密码，再让本机 stdio MCP 进程通过标准 IMAP 访问收件箱。网络连接仅指向 `imap.mail.me.com:993`，校验 TLS 证书和主机名。

连接检查用只读方式打开收件箱。搜索输入是主题或发件人片段。搜索输出提供邮件主题、发件人、日期和用于跟进读取的 UID、UIDVALIDITY。读取以这两个值为定位依据，读取前校验 UIDVALIDITY。使用 `EXAMINE` 和 `BODY.PEEK` 避免修改已读状态。聊天工具返回文本，附件和发送操作不开放。

运行时通过安装环境中的 Python 3.9 及以上版本调用标准库。凭据沿用宿主的卡片字段注入，连接器不设置单独的凭据文件。软件包不使用其他邮箱连接器的实现或 Apple 的图标。
