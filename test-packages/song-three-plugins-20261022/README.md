# Confirmed native WorkSwarm test packages

These are the exact Chinese 1.0.0 native ZIPs confirmed by Song Haoran and tested in WorkSwarm. Install these through WorkSwarm Extensions; each archive directly contains its native plugin directory and manifest.json. SHA-256 values and original test evidence are in [PR #26](https://github.com/LasVie/agentic-hub-plugins/pull/26#issuecomment-6338329798).

Canonical Agentic Hub wrapper ZIPs remain under releases/agent-plugin/<slug>/1.0.0/. The native test ZIPs here are separate host-installation archives; they do not replace that fixed delivery format.
